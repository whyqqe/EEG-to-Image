## 1. 结论先行：SAMGA 的 inter 设计弱在哪

### 1.1 SAMGA 的 inter 优势实际来自哪里（代码级审计）

| 机制 | 位置 | 测试时是否生效 |
|---|---|---|
| MMD 边缘分布对齐 | `train.py:608`，batch 级 EEG↔图像教师 | 仅训练 |
| 被试感知多层视觉目标（router） | `train.py:508-539`，唯一调用点 | **否——被丢弃** |
| 粗到细两阶段 | `train.py:571-584` | 仅训练 |
| 逐被试 MVNN / z-score | `preprocess_eeg.py:205-212` | 对，但这是预处理 |

关键事实：`SubjectAwareLayerMixer` 计算 `logits = global_logits + subject_bias[subject_ids]`（`train.py:62-70`），但评测时 `force_global = (not training) and router_eval_mode == 'global'`（`train.py:531`），而 `inter.sh` 显式传 `global` ⇒ **`subject_bias` 被完全跳过**。且 router 只作用于图像侧，`TSConv.forward(self, x)` 根本不接收 `subject_ids`。

⇒ **SAMGA 训练出一个被试特异的映射，却在推理时扔掉。** 它的 inter 泛化完全依赖 MMD + 预处理归一化。

### 1.2 两个结构性缺陷

**(a) 空间粒度被压掉。** `TSConv` 的形状流：

```text
[B,63,250] → Conv2d(1,40,(1,25))   → [B,40,63,226]
           → AvgPool2d((1,51),(1,5)) → [B,40,63,36]
           → Conv2d(40,40,(63,1))     → [B,40,1,36]    ← 63 个电极被核高 63 压成 1
           → view(B,-1) → Linear       → [B,1024]
```

**没有电极拓扑、没有位置编码、时间轴被无条件拉平。** 对检索够用；对重建是结构性缺陷——PixCorr/SSIM 恰恰依赖空间布局（我们 PixCorr 0.1257 vs 被试内 0.159，相对差距比 CLIP 更大）。

**(b) MMD 对齐的是边缘分布，而错配的本质不是边缘分布。**

### 1.3 决定性证据：错配的本质是「坐标系旋转」

SCORE（arXiv 2608.19134，2026-08）做了**我们在 v1 里没有做的诊断**，结论是本文档的转折点：

> 不同被试**保持相似的概念关系，但沿不同的坐标方向表达**。

证据（THINGS-EEG2，同一 LOSO 折）：

- 源与被试被试的 EEG RSM 相关性 = **0.687 ± 0.035** ⇒ 概念**结构**是共享的。
- 用留出概念做 3 折交叉验证，把 target EEG 映射到 source EEG：

| 对齐方式 | Top-1 | Top-5 |
|---|---:|---:|
| 直接匹配 | 16.89 | 41.95 |
| Ridge 映射 | 20.01 | 47.15 |
| **正交映射** | **28.22** | **59.16** |

**正交映射（仅旋转+反射，保距保角）比 Ridge（任意线性）高 8.21 Top-1。** 约束更强却效果更好，说明这个变换**本质就是一次坐标旋转**，而 Ridge 的额外自由度只是在过拟合。

⇒ **跨被试差距的主要部分不是「分布不同」，而是「同一个形状被放在不同朝向的坐标系里」。** MMD 只能间接、隐式地学这个旋转；而 SCORE 证明它可以**在部署时用闭式解直接拟合**。

### 1.4 最要命的数字：同一个编码器上 +27.01 Top-1

SCORE 用**我们的 SAMGA 编码器**做主干，双方编码器全冻结、目标被试零标签：

| 源训练 | 部署方法 | Top-1 | Top-5 |
|---|---|---:|---:|

## 2. inter SOTA 图谱（2026-09）

| 方法 | inter Top-1/Top-5 | 核心机制 | 一句话 |
|---|---:|---|---|
| ATM (NeurIPS 2024) | 5.5 / 20.0 | 对比学习 + 粗先验 | 原始跨被试基线 |
| SATTC (CVPR 2026) | 14.8 / 38.4 | 相似度矩阵上的无标签测试时校准 | SAW 白化 + 自适应 CSLS + 结构 PoE |
| SAMGA (ESWA 2026) | 34.4 / 64.8 (论文, 5 seeds) | 被试感知多层视觉目标 + MMD | 我们当前的主干 |
| NeuroBridge (AAAI 2026) | 19.0 / 45.9 | CPA + 双向共享语义投影 | 非对称模态增强 + 协同自适应 |
| SIMON (2026) | 19.6 / 49.9 | 显著性感知多视角 | 中心裁剪偏差造成几何-语义解离 |
| HyFI | 16.4 | 双曲对比学习 | 概念层级结构 |
| **SCORE (2026-08)** | **53.23 / 83.55** | **正交坐标恢复 + 恢复感知训练** | **当前 SOTA，超出次优 17.45** |

### 2.1 SCORE 的完整机制（最值得借鉴）

**训练侧**

1. **Multi-positive 对齐**：同一图像对应的**不同源被试** EEG 互为正样本（双向），不再互相推开。
   $$p_{ij} = 1/|\mathcal{P}(i)|,\quad \mathcal{P}(i)=\{j: y_j = y_i\}$$
2. **模拟坐标恢复（source-only episodes）**：每个 mini-batch 把**一个源被试当作临时 target**，隐藏其 EEG-图像匹配，跑一遍部署时的恢复流程，然后才揭示匹配算损失，**梯度不穿过映射**。

**部署侧（全冻结、全无标签）**

1. **矩匹配**：逐维对齐 EEG 与图像特征的均值/方差（正交映射管不了平移）。
2. **Landmark 选择**：用 **CSLS** 打分（抑制 hubness），只保留**互最近邻**对作为 landmark；用 top-1 与 top-2 的**间距**给每个 landmark 加权（EEG 信噪比低，不确定的对应该权重小）。
3. **正交恢复**：
   $$R^\star=\arg\min_{R^\top R=I}\ \|W^{1/2}(\tilde X R-\tilde Y)\|_F^2+\lambda\|R-I\|_F^2$$
   闭式解 $R^\star = UV^\top$，其中 $M=\tilde X^\top W\tilde Y+\lambda I=U\Sigma V^\top$（广义 Procrustes）。
   **identity 正则不可省**：部署 batch 只有几百个 query，landmark 数 $m \ll$ 维度 $d$，无约束方向上是欠定的；$\lambda$ 让无证据的方向留在 identity。$\lambda=\rho\|\tilde X^\top W\tilde Y\|_2$，$\rho=0.1$。
4. **在恢复后的空间重算 CSLS 检索**。

**泛化性证据**

- 跨编码器：NICE 27.60→54.85，EEGNet 15.95→46.95，ShallowFBCSPNet 10.63→30.73。
- 扩大 gallery：200→1854 张时 SCORE 仍最优（17.03 vs CSLS 13.33），**不依赖闭集假设**。
- **冻结映射可迁移到不相交的 100 概念 gallery**：39.53 →（冻结映射+CSLS）**64.16** ⇒ 恢复的是**可复用的被试-图像关系**，不是对特定概念的拟合。

### 2.2 SATTC 的可借鉴部分（以及一个反面教训）

**反面教训**：在弱编码器（ATM）上 SATTC 从 9.2→14.8，但在**强编码器（SAMGA）上 26.12 < 26.22，反而变差**。SCORE 明确指出「完整的 SATTC 算子对冻结的强表征贡献极小」。

⇒ **只借鉴它的 SAW，不要借鉴它的结构 PoE。**

**SAW（subject-adaptive whitening）**：用该被试**无标签** embedding 估均值与协方差，
$$W_s=(\Sigma_s+\lambda I)^{-1/2},\qquad \tilde z = \frac{W_s(z-\mu_s)}{\|W_s(z-\mu_s)\|_2}$$

- SATTC 自己的消融：standard 9.2/30.5 → **+SAW 13.7/36.4**，是「cross-subject 泛化的关键成分」。
- SCORE 在 SAMGA 编码器上的受控测量：26.22 → **30.98（+4.76）**。
- 编码器无关：四个异构编码器上 Top-1 +4~8、Top-5 +8~16。
- 校准窗口极省：**N=50 个无标签试次就达到 N=200 上界的 94.8%**。

**它严格泛化了我们现有的归一化。** 我们当前的 identity 臂做的是「居中 + L2 归一化」（一阶 + 尺度），SAW 是**全协方差白化**（二阶去相关）。

### 2.3 SIMON 的可借鉴部分：目标空间而非编码器

SIMON 的洞察：**固定中心裁剪的视角与 EEG 实际编码的内容驱动注意力不匹配**，造成「几何-语义解离」。它用前景分割 + 显著性预测选注视中心，生成**多视角 foveated 表征**。

对我们的意义：这是**目标空间（conditioning target）的改造**，不是编码器改造。我们的 CLIP 目标是单张中心裁剪的 `image_embeds`；若改成多视角 foveated 目标，条件会更贴近 EEG 编码的内容，且 foveated 视角**携带物体的位置/尺度**——这正是 PixCorr/SSIM 需要的。

### 2.4 四篇论文收敛的通道拓扑结论（未被利用的架构杠杆）

| 通道 | UBP | HyFI | NeuroBridge | SIMON |
|---|---:|---:|---:|---:|
| OP (17) | 12.9 | 14.6 | 14.9 | 17.2 |
| **ALL (63)** | **13.7** | **16.4** | **19.0** | **19.6** |

SIMON 的解释：**后部通道捕获强被试特异的视觉信号，而更广的空间覆盖提供跨被试不变的信息**。且**被试内是相反的**（加前部通道掉 12-18 点，InternViT 82.6→70.9）。

⇒ 这暗示 **前部通道承载「被试不变的锚定信息」**，后部承载「被试特异的视觉细节」。

而 SAMGA 用**一个** `Conv2d(40,40,(63,1))` 把所有 63 个电极一起压掉，**没有区分通道角色**。这是一个**四篇论文支持、且 SAMGA 未占据**的架构杠杆。

## 3. 可借鉴性分析：哪些能迁移到「重建」（本文档的核心判断）

⚠️ **必须先说清一个事实：SCORE、SATTC、SIMON、NeuroBridge、HyFI 全都是检索方法。**

SATTC 明确把「retrieval-then-generation 或 EEG/fMRI 重建」列为 future work；SCORE 同。**跨被试「重建」的 SOTA 不存在**，所以下面每一行的迁移判断都是**设计假设，不是已验证结论**。

| 组件 | 检索中的作用 | 迁移到重建 | 代价 | 依据 |
|---|---|---|---|---|
| **Multi-positive 对齐** | 同刺激不同被试互为正样本 | **强迁移**。而且我们有一个**已确认的实现缺陷**（见 §4.1） | 极低 | SCORE +2.41；缺陷已代码确认 |
| **CSLS** | 相似度重标定，抑制 hubness | **双向迁移**：(a) landmark 选择必需，(b) 我们的邻域库是裸 `argsort`（见 §4.1） | 极低 | SCORE 单项 +9.75 |
| **SAW** | 被试 embedding 全协方差白化 | **强迁移**，严格泛化我们现有的居中+L2 | 低 | +4.76（同编码器受控测量） |
| **正交坐标恢复** | 目标被试坐标系恢复到图像帧 | **强迁移**，这是核心。维度细节见 §4.3 | 低-中（闭式） | +7.18~+21.86；跨编码器 |
| **模拟恢复 episode** | 让模型对恢复算子鲁棒 | **迁移**，近似元训练 | 中 | 单项 +0.70，且放大恢复收益 |
| **Foveated 多视角目标** | 匹配 EEG 的内容驱动注意力 | **迁移**，且对重建可能比对检索更有价值（带位置/尺度） | 中 | SIMON inter 19.6 |
| **双向对齐（NeuroBridge）** | 协同自适应，EEG↔图像互校 | **部分迁移**：cycle-consistency 思路可用 | 中 | 19.0 |
| **结构 PoE（SATTC）** | 秩/MNN/流行度重排序 | **弱迁移**：是相似度矩阵算子，改不了条件向量 | 低 | ⚠️ 强编码器上**变差**（26.12<26.22） |
| **双曲空间（HyFI）** | 概念层级结构 | **弱迁移**：利于语义排序，不利于像素保真 | 中 | 16.4 |
| **EA（Euclidean Alignment）** | 参考协方差归一化 | **弱**：+1.23，且跨折不一致（sign test p=0.585） | 低 | SCORE Table 2 |
| **通道角色分解** | 前部=不变锚定，后部=特异细节 | **强迁移且未被占据**：同时服务 CLIP（不变）与 PixCorr（细节） | **高（需重训编码器）** | 4 篇论文收敛 |

## 4. 修订后的架构

### 4.1 首先修两个已确认的缺陷（零成本，最高优先级）

**缺陷 A：同一刺激的 9 个源被试行被当作负样本推开。**

`scripts/recon/train_gen_head.py:59-75` 把 9 个源被试的特征 `np.concatenate(xs, 0)` 成行；同一 `(object_idx, image_idx)` 有 **9 行共享同一个 CLIP 目标**。而：

```python
# train_gen_head.py:95-98
def info_nce(pred, tgt, temp):
    logits = pred @ tgt.t() / temp
    labels = torch.arange(pred.shape[0], device=pred.device)   # 实例级标签
    return 0.5 * (F.cross_entropy(logits, labels) + F.cross_entropy(logits.t(), labels))
```

`arange` 意味着第 $i$ 行只认第 $i$ 行匹配 ⇒ **9 个被试对同一刺激的响应被强制互斥**。这与跨被试目标直接矛盾。改为 multi-positive：

```python
# 建议实现：按 stimulus id 构造正样本集合 P(i)={j: y_j=y_i}，权重 1/|P(i)|
```

**缺陷 B：邻域库无 hubness 校正。**

`eeg-brainit/scripts/erdc_ras_closed_loop.py:64-71` 的 `retrieve_neighbors` 是裸 `np.argsort(-sim)`；`erdc_official_atm_pipeline.py:329` 直接调用它。

这同时给出 **FID 反常的一个具体机制**（参见 v1 §1.4：我们 LOSO 的 FID 171.72 优于被试内 176.70/182.19，但语义指标全面更差）：hub 主导的邻域选择 ⇒ 大量 query 拉向同几张热门图 ⇒ 生成图多样性塌缩 ⇒ **FID 下降但语义变差**。两个 SOTA 方法都把 hubness 列为这类跨域检索的核心病理。

**这是一个便宜且可证伪的假设**：在 `retrieve_neighbors` 里换成 CSLS 打分，看多样性/FID/语义是否同时改善。

### 4.3 维度问题：在哪个空间拟合正交映射

SCORE 在 $d$ 维空间做 $d \times d$ 正交映射，要求两侧同维。我们的空间有两个候选：

| 方案 | 拟合空间 | 锚（图像侧） | 代价 |
|---|---|---|---|
| **A（忠实 SCORE）** | SAMGA 512-d 共享空间 | gallery 图像的**图像教师** 512-d 特征 | 需计算图像教师（router 在评测时是 global，可算） |
| **B（廉价叠加）** | CLIP ViT-H 1024-d | gallery 的 `clip_h14_test.npy` | **无需重训，可直接叠加在已有 609259 产物上** |

**建议先做 B**：它不需要任何重训，能立刻在现有产物上验证「坐标恢复对重建是否有效」这一核心假设。若 B 有效，再做 A（更忠实、更可能拿到完整收益）。

### 4.4 重建特有的诚实性问题：映射拟合不能用评测对

⚠️ **这是本文档最重要的方法论警告。**

在检索里，gallery 是候选集；SCORE 用 target EEG 与 gallery 之间的 CSLS 互最近邻构造伪配对来拟合 $R^\star$。SCORE 专门处理了这个闭集疑虑（Table 5 扩大 gallery、Table 6 冻结映射跨不相交 gallery），后者在**不相交的 100 概念 gallery** 上仍把 39.53 提到 64.16。

但**重建的风险更大**：重建的评测指标是「生成图 vs 被试真实看过的图」。如果我们用**同一批 200 个概念**拟合同时又用它评测，$R^\star$ 可能拟合到那 200 个特定配对上，**抬高 PixCorr/CLIP 却无真实泛化**。

**因此协议必须是：**

- **主协议**：概念集切成不相交的 A/B（各 100）。用 A 拟合 $R^\star$，**冻结**，作用到 B，在 B 上生成并报告全部指标。这直接复刻 SCORE Table 6 的设定，而该设定下增益**更大**（+24.63 Top-1）。
- **辅助报告**：全 200 概念拟合的做法只作为参考行，**必须标注**，不得作为主结果。
- 拟合只用**无标签**量：无被试标签、无配对真值。

### 4.5 分层组件设计

**L1 训练侧（编码器 + 头）**

- L1.1 **Multi-positive 对比**（修正 A）。正样本 = 同一 stimulus 的所有源被试行。
- L1.2 **SAW 作为一致的归一化**，在训练与评测用同一算子，保持一致特征空间（SATTC 的做法）。
- L1.3 可选 **模拟恢复 episode**：把一个源被试当临时 target，走一遍恢复再算损失，梯度不穿映射。
- L1.4 可选 **通道角色分解**（P3，需重训编码器）：把 63 通道按前/后部拆两个分支，后部走细节、前部走不变锚定，融合后再进 projector。依据是 §2.4 的四篇论文收敛结论。

**L2 部署侧校准（全无标签、闭式）**

严格按 SCORE 四步：SAW → 矩匹配 → CSLS landmark + margin 加权 → weighted Procrustes + identity 正则。无参数训练。

**L3 生成**

- L3.1 保留 SDXL-Turbo + IP-Adapter（ViT-H, 1024-d `image_embeds`）。
- L3.2 **邻域库换 CSLS**（修正 B）。
- L3.3 条件不确定度驱动候选数。

**L4 目标空间（可选，P2）**

- L4.1 借鉴 SIMON：把 CLIP 目标从「单张中心裁剪」改为**多视角 foveated 目标**（前景分割 + 显著性选注视中心）。这是对**条件目标**的改造，且能携带位置/尺度。

**L5 空间保真（探索性）**

- L5.1 空间分支（复用 SAMGA `model.py` 里未接线的 `SpatialChannelStem` / `TemporalPatchStem`）输出粗布局，经结构条件注入。
- ⚠️ **无文献支持**：所有 SOTA 都是检索方法，没有跨被试重建的空间方案可借鉴。这一层是纯探索。

## 5. 评测协议

### 5.1 四行基准（当前仓库的缺口）

仓库里**没有任何跨被试重建基线**（`eeg-brainit` 的重建臂是被试内：其 ATM 检索 34.5% ≫ 跨被试的 5.5%），所以现有数字无法自答「好不好」。

| 行 | 作用 |
|---|---|
| 随机条件 | 下界，扣掉生成器自带能力 |
| **oracle（真 CLIP 条件）** | 上界，分离条件误差与生成器饱和 |
| 被试内上界 | 用**同一套指标代码**跑被试内，量化 inter 代价 |
| 本方法（LOSO） | 待评 |

我们已有的锚点：oracle 0.456/0.164，head 0.3435/0.1257，identity 0.2502/0.0478（CLIP cosine / PixCorr）。

### 5.2 分层报告 + oracle 归一化

条件层（CLIP cosine、检索 Top-1/5）与像素层（PixCorr、SSIM、FID、2WC）**必须分开报**，否则条件层改进会被生成器饱和掩盖。

$$\text{score}_{\text{norm}}=\frac{\text{score}-\text{chance}}{\text{oracle}-\text{chance}}$$

### 5.3 其余口径

- **2WC 必须标注干扰池**：`erdc_twoway_metrics.py` 用完整 200-way / 199 干扰项，与常见的 2-way（1 个干扰项）**不可比**。
- **统计功效**：sub-08 单折 CLIP 的 CI 约 ±0.014，而待检测增益可能只有 0.02–0.03 ⇒ **≥5 折**。
- **checkpoint**：继续用 `checkpoint_last.pth`。SAMGA 发布代码按测试集选 checkpoint，SCORE 用 final epoch（我们跟随）。

## 6. 优先级与首批实验

| 优先级 | 项 | 预期 | 代价 | 依据 |
|---|---|---|---|---|
| **P0** | 修正 A（multi-positive） | +2.4 量级 | ~10 行 | 缺陷已确认；SCORE +2.41 |
| **P0** | 修正 B（邻域库 CSLS） | 可能同时改善 FID 与语义 | 低 | 裸 `argsort` 已确认；CSLS +9.75 |
| **P0** | 补 §5.1 四行基准 | 建立可比性 | 低 | 当前无基线，最阻塞 |
| **P1** | SAW（替换现有居中+L2） | +4.76 量级 | 低 | 同编码器受控测量 |
| **P1** | 正交恢复，**方案 B**（CLIP 空间，无需重训，叠加在 609259 产物上） | 最大单点杠杆 | 中 | +7.18~+21.86 |
| **P1** | A/B 概念切分协议（§4.4） | 使上项诚实 | 低 | SCORE Table 6 |
| **P2** | 模拟恢复 episode | 放大恢复收益 | 中 | +0.70 |
| **P2** | 多视角 foveated 目标（SIMON） | 提升 PixCorr/SSIM | 中 | SIMON inter 19.6 |
| **P3** | 通道角色分解 | 同时服务 CLIP 与 PixCorr | 高（重训） | 4 篇论文收敛 |
| **P3** | 多折扩展（≥5） | 统计功效 | 中 | 队列限 8 并发，需滴灌 |

**建议的第一个里程碑：P0 三项 + P1 的 SAW 与方案 B 恢复。**

理由：P0 里有两项是**已确认缺陷的修复**（不是改进，是纠错），代价近乎为零；P1 两项是全文档证据最强的杠杆（+4.76 和 +7.18~+21.86），且方案 B **不需要重训**，可以直接叠加在刚跑完的 609259 产物上验证核心假设。这四项做完就能回答「坐标恢复对重建到底有没有效」，再决定是否投入 P2/P3。

## 8. 风险

| 风险 | 症状 | 备选 |
|---|---|---|
| **正交恢复在重建上不迁移** | 条件层 CLIP 提升但像素层不动 | 回到 L5 空间分支；或改用方案 A（512-d 空间） |
| **映射过拟合到 200 概念** | A/B 切分后增益消失 | 已用 A/B 协议强制暴露；若消失则说明恢复不可用 |
| **foveated 目标与生成不匹配** | 条件 CLIP 对齐变差 | 保留原中心裁剪目标作对照 |
| **通道分解需重训** | 成本高、收益未验证 | 先在小规模（1 折、短 epoch）验证方向 |
| **hubness 假设错误** | 换 CSLS 后多样性不动 | 那 FID 反常需要另找机制（量化类内/类间多样性） |
| **多折统计功效不足** | CI 宽于增益 | ≥5 折；先 3 折看方向 |
