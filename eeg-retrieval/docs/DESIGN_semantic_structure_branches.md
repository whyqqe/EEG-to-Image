# 语义 / 结构双支路编码器设计方案

> 写于 2026-09-18。本文档设计一套「语义支路 + 结构支路」的 EEG 编码器，目标是
> 语义侧服务检索、结构侧服务生成（SDXL），两条支路**不共享目标空间**。
>
> 阅读顺序建议：第 1 节（三个必须先澄清的事实）→ 第 3 节（骨干选型）→ 第 5 节（对齐目标）
> → 第 8 节（风险）。第 1 节里的三件事如果不先处理，后面全部会做错。

---

## 0. 结论速查

| 决策点 | 选择 | 关键理由 |
|---|---|---|
| **语义侧骨干** | **CLIP ViT-L 的视觉塔**（32 层 / **1280**-d / 双向） | 文本塔是**因果注意力**，对 EEG 双向耦合是错的（§4.2）。视觉塔双向 + patch 原生 |
| **结构侧骨干** | **DINOv2-L**（24 层 / 1024-d / 518 输入 / 37×37 token） | CLIP 被训练来**丢弃**结构，用它做结构目标是自毁 |
| **结构侧生成目标** | **SDXL VAE 潜变量**（4ch，`scaling_factor=0.13025`） | 生成原生目标；但**必须回归、不能对比** |
| **主干** | **无共享主干 —— 两路完全独立** | 不是取舍：CLIP ViT-L（1280）与 DINOv2-L（1024）**宽度不同，物理上无法共享**（§4.1） |
| **两支分离方式** | 各自独立的 patch_embed + 预训练块 + 投影头 | 两路损失数学性质不同（尺度不变 vs 尺度敏感），训练配置必须独立（§4.4） |
| **多层融合** | 每支各一套「全局先验 + 被试残差 + 双重 dropout」路由 | SAMGA 的做法；但**两支的层偏好必须分别扫描** |
| **损失平衡** | 学习式不确定性加权（Kendall） | 4 个损失尺度差异极大，手工权重不可靠 |
| **caption 用途** | **仅训练期**辅助目标 | 测试集 caption 由测试图派生，推理期用 = 泄漏 |
| **caption 版本** | **`captions_sub08_*`（短句）** | `detailed` 版的指令前缀占满 75/77 token，正文全被截断，编码结果恒为同一向量（§1.3 坑 2） |
| **不共享主干** | 两路完全独立，各自 patch_embed + 预训练块 | CLIP ViT-L 宽 1280、DINOv2-L 宽 1024，无法共享参数（§4.1） |

**本地资源全部就绪，无需下载**（见第 9 节）。

## 0.5 实测结果：阶段 1 闸门**未通过**，已定位原因（sub-08）

阶段 1 的判据是「**两支都应呈现倒 U 形；若复现不出倒 U，停下来找原因**」。
sub-08 的 ViT-B/16 全层扫描结果**是平的**，闸门触发。以下是定位过程与结论。

### 实测数字

| 层 | test top1 | test top5 | mean rank |
|---|---|---|---|
| 2 | 20.00 | 50.00 | 13.1 |
| 4 | **21.50** | 51.00 | 11.6 |
| 6 | 17.00 | 55.50 | 11.4 |
| 8 | 21.00 | 48.00 | 13.0 |
| 10 | 18.00 | 49.00 | 13.4 |
| 12 | 20.50 | 49.00 | 14.2 |

**没有任何层间趋势。** n=200 时 top1 的标准误约 2.8 个百分点，
而全距（17.0–21.5）只有 4.5 个百分点 —— 即**整个层扫描的差异都在噪声内**。
这本身就说明：当前瓶颈不是「选哪层」，而是编码器根本没有学到足够的东西让层选择体现出差异。

### 原因一：严重过拟合（主因，已用曲线确证）

`scan_b_l10` 的训练轨迹（`train_top1_inbatch` 是 batch 内 512 路 top-1）：

| 轮 | loss | train_top1_inbatch | val_top1 |
|---|---|---|---|
| 8 | 4.1493 | 13.54 | **12.67** ← 峰值 |
| 16 | 2.0718 | 70.72 | 8.00 |
| 24 | 1.1793 | 95.70 | 7.33 |
| 30 | 1.0025 | **97.93** | 10.67 |

训练集被**完全记住**（98%），验证集在第 8 轮见顶后**崩溃**。泛化间隙约 87 个百分点。
30 轮 × 29 step = 仅 **880 步**，过拟合在第 ~230 步就开始 —— 说明有效容量远超数据量。

### 原因二：**闭式线性 ridge 打败了整个深度流水线**

同一个 200-way test、同一套特征与指标，`scripts/nwret/baseline_ridge.py`：

| 方法 | test top1 | test top5 | mean rank |
|---|---|---|---|
| **线性 ridge（闭式解）** | **25.00** | **52.50** | **13.1** |
| ViT-B/16 深度编码器（最佳层） | 21.50 | 51.00 | 11.6 |
| 随机基线 | 0.5 | 2.5 | 100.5 |

**一个闭式线性映射超过了整条深度流水线。** 这直接否证了「当前深度编码器在赚取它的复杂度」，
也说明数据/指标/目标这套管道本身是通的（ridge 远超随机），**问题纯粹在训练机制**。
在此前提下继续扫描更大的骨干（DINOv2-L 300M、CLIP ViT-H-14 632M）只会**加大容量、加重过拟合**。

### 原因三：与参考实现在两个关键点上不一致

**(a) SAMGA 不用预训练 ViT 的 blocks 编码 EEG。** 其前向是：

```python
eeg_feature_batch = model(eeg_batch, subject_id_batch)   # ATM/EEGNet/EEGProject/TSConv/EEGTransformer —— EEG 专用小网络
eeg_feature_batch = eeg_projector(eeg_feature_batch)
eeg_feature_batch = share_encoder(eeg_feature_batch)
```

6B 的 InternViT **只用于产出图像特征当冻结教师**。我们的设计把 EEG token 穿过了预训练视觉 blocks，
既让 block 处于严重分布外，又引入了 86M 可训练参数砸在 15040 个样本上。

**(b) SAMGA 默认开着 EEG 增强，我们一个都没有。** `--eeg_aug_type` 默认 `'noise'`，
可选项 `RandomTimeShift / RandomGaussianNoise / RandomChannelDropout / RandomSmooth`，
在训练集上真实生效（`module/dataset.py`）。这是 SAMGA 主要的抗过拟合机制之一。

### 两个实现缺陷（与过拟合正交，但必须修）

1. **softplus 加错了位置。** SAMGA 的 `--softplus` 作用于**温度**：
   `logit_scale = self.softplus(self.logit_scale)`（`module/loss.py:93-94`）。
   我们在 `model.py:96` 把它作用到了 **EEG 嵌入本身**，使嵌入恒为正、
   经 L2 归一化后全部挤进正卦限，任意两条余弦相似度都偏高，对比学习的分辨力被压缩。

2. **选点任务与报告任务不是同一个。** `TestDataset.__init__` 用 `eeg[:, 0]` / `image_feat[:, 0]`。
   对 test (200,1,…) 无害，但 val 是 (150,10,…)，于是 **val 只用了 10 张图里的第 0 张、
   是 150-way**，而报告指标是 200-way 且 test 是 80 次叠加（信噪比约高 4.5 倍）。
   用任务不同、噪声也不同的 val 去做 checkpoint 选择，选出的轮次对 test 未必最优。
   （注：这也解释了为何 val 数值低于 test —— 不是 bug，是信噪比与 way 数双重差异。）

### 结论与下一步

**当前状态不构成「与 SOTA 比较」的资格**：深度模型（21.5%）低于线性基线（25.0%），
而参考值 SAMGA 为 91.3%。在把深度模型推到**明显超过 ridge 的 25%** 之前，
任何骨干/层/融合的扫描都无法解读。

因此下一步不是继续扫骨干，而是**先建立能工作的训练机制**。

## 0.6 已实施的修复（第二轮 sub-08 的改动清单）

上面的五个问题里，有四个是**保真度缺陷**（与参考实现不一致），一个是**协议缺陷**。
全部已修复，并有回归测试 `scripts/test_fixes.py`（每条测试对应一个曾静默失败的缺陷）。

### 修复 1：softplus 位置（正确性）

| | 作用对象 | 初始有效 logit 尺度 |
|---|---|---|
| 修复前（错） | EEG **嵌入** `z = softplus(z)` | — |
| 参考 SAMGA | 温度 `logit_scale = softplus(logit_scale)` | **2.73** |
| 无 softplus | `logit_scale.exp()` | 14.29 |

除了位置错误，这个修复还有个**意外收益**：softplus 让 logit 尺度比 exp 软 **5.2 倍**，
直接给对比目标加了正则。实测该错误对几何的破坏是可量化的——
对 256 条随机嵌入，两两余弦均值从 **0.000 → 0.707**（全部挤进正卦限），
对比学习的分辨力基本被抹平。

### 修复 2：两阶段 MMD 调度（保真度）

原流水线 `--mmd-start 0 --mmd-end 0`，即 **MMD 被完全禁用**。
SAMGA 的实际设定（`train.py` 默认值）：

| 参数 | SAMGA | 我们（修复后） |
|---|---|---|
| `num_epochs` | 50 | 50 |
| `stage1_epochs` | 20 | 20 |
| `stage1_mmd_start` | 0.9 | 0.9 |
| `stage1_mmd_end` | 0.2 | 0.2 |
| 对比权重（stage 1） | `1 - mmd_w`（**互补**） | `1 - mmd_w` |
| stage 1 后的 lr | 5e-5 | 5e-5 |

两个细节值得单独指出：

1. **互补加权**。SAMGA 在 stage 1 用 `mmd_w*MMD + (1-mmd_w)*contrastive`，
   而不是简单相加。简单相加会让总梯度量级随 `mmd_w` 变化，
   等于每个 epoch 偷偷改了有效学习率。
2. **早停不能与 stage 1 冲突**。stage 1 里 MMD 权重 0.9→0.2、
   对比权重被压到 0.1→0.8，val Top-1 完全可能在整整 20 轮里不改善。
   若把这种停滞当成「无提升」，早停会在 stage 2（真正产生检索增益的阶段）
   开始前就杀掉训练。因此早停计数在 stage 1 内被**挂起**。

### 修复 3：EEG 增强（保真度）

新增 `scripts/nwret/augment.py`，移植 SAMGA 的四个 transform
（`RandomTimeShift / RandomGaussianNoise / RandomChannelDropout / RandomSmooth`），
并额外提供组合版 `full`。三处刻意偏离，均已在代码中注明：

- **幅度按我们的数据尺度重设**。我们预处理后的 EEG 标准差约 **0.50**，
  而 SAMGA 默认 `RandomGaussianNoise(std=0.001)` 在这个尺度下**数值上等于没有增强**。
  噪声改为 10% 信号标准差（实测噪声 std 0.050）。
- **不再原地修改输入**。SAMGA 的 `RandomChannelDropout` / `RandomSmooth` 会就地改写传入数组；
  我们的 EEG 是跨 epoch 复用的缓存数组，就地改写会污染后续所有轮次。这是修 bug，不是改行为。
- **平滑向量化**。用前缀和盒式滤波替代逐样本 Python 循环，结果一致，快约三个数量级。

增强**只作用于训练集**；`TestDataset` 与验证路径都不增强——这是选点信号保持诚实的前提。

### 修复 4：选点协议（统计有效性）

`TestDataset` 原本无条件用 `[:, 0]`。对 test (200,1,…) 无害，
但 val 是 (150,10,…)，于是 **val 只用了 10 张图里的第 0 张**，浪费了 90% 的留出集，
使每轮的 val Top-1 噪声大到「第 8 轮见顶、之后 22 轮漂移」。

修复后 `evaluate_selection` 扫全部 10 个 slot 并对指标取平均：
同等的任务难度（仍是概念级、每概念 1 张图，与 200-way test 可比），
**选择噪声降低约 10 倍**。同时输出 `top1_std`（跨 slot 标准差）作为诚实的误差棒。

### 修复 5：容量与早停（过拟合）

- 加入 `--patience`（默认 12，stage 1 内挂起），
  对付「第 8 轮见顶、继续训 22 轮纯损失」的浪费。
- F 阶段专门测「冻结预训练块、只训 tokenizer+融合头」
  （**0.64M 可训练 / 86.44M 全部**）这一容量对照。

### 修复 6：实验顺序（本轮最重要的一步）

原流水线**先扫骨干与层**。由于当时每个臂都在 17–21.5%、
全部低于 ridge 的 25.0%，这一扫描实际上是在**给过拟合程度排名**，
新增多少臂都不会变得可解释。

新流水线改为按**前置条件**排序：

```
P0  ridge 基线（闭式）      —— 确立每个臂必须越过的下限
P1  机制搜索 F1–F5          —— 增强 × 两阶段 MMD × 容量
P2+ 宽扫描（层/骨干/tokenization/融合）—— 全部在 P1 胜出的机制下运行
```

P1→P2 的机制交接通过 `EXTRA` 环境变量透传，且**只依据 VALIDATION Top-1 选择**
（`best_flags.py`）。这一点是硬约束：若用 test 来选机制，后续每个扫描都会继承一次选择泄漏，
最终数字会乐观到任何误差棒都揭示不出来的程度。

### 修复 7：计时（回答「为何慢」）

新增分项计时，写入每个臂的结果 JSON：`train_seconds` / `val_seconds` /
`steps` / `ms_per_step`。这让「慢在哪」成为可测量的问题，而不是猜测。

## 0.7 第三轮：扫描轴搞错了（本轮真正的问题）

### 症状

第二轮把过拟合压下去了，但**没有任何一个臂越过 ridge 下限**：

| 臂 | 配置 | val Top-1 | test Top-1 | 泛化间隙 |
|---|---|---|---|---|
| F1 | 对照（未修） | 13.65 | 20.00 | 86.3 |
| F2 | 仅增强 | 17.73 | **21.00** | 76.0 |
| F3 | 仅 softplus + MMD | 13.18 | 16.50 | 83.6 |
| F4 | 全部修复 | 13.55 | 17.00 | 12.0 |
| ridge | 闭式线性 | — | **25.00** | — |

F4 把间隙从 86.3 压到 12.0，**却让 test 更差**（17.00 < 20.00）。
这说明：**过拟合不是主瓶颈**，修过拟合反而伤性能；而且
`softplus + MMD` 这一对是**有害的**（F3/F4 都比对应控制臂低 3.5–4.0 点）。

关键的是 **F4 的间隙只有 12 点**——是**欠拟合**，不是过拟合。
在欠拟合的状态下把目标函数变软（softplus，~2.7 vs ~14.3）、
再让前 20 轮走弱对比项（MMD 0.9），方向完全反了。

### 根因：扫描的轴是错的

设计文档 §5.3 与 §7 阶段 1 写的都是**扫 CLIP 的 32 层**
（候选 `{12, 20, 28, 32}`，中心 20–24），即**图像侧的对齐目标层**。
实现扫的却是 **EEG 通路的深度**（`--layers` 传给 `LayerFusion`）。

这是两个完全不同的轴，而且：
- 我们缓存的图像特征是 **1024 维 = `visual.proj` 的输出宽度**，
  即**只有最后一层**。没有任何一个实验臂碰过这一层之外的对齐目标。
- 因此文档里定价为「最大单一杠杆」的那个量，**从未被真正测试过**，
  层扫描必然是平的。

### 已实施的修复

**1. 对齐目标层变成可选项**（`train.py`）

新增 `--target-features` / `--target-layer`，默认仍是缓存的最终层
（保持与历史臂可比）。并加了**形状硬校验**：特征与 EEG 的
concept/slot 维度必须一致，否则直接报错——因为错位的数据
看起来仍然像「结果」，只是全是噪声。

**2. 分层特征提取**（`scripts/nwret/extract_layers.py`）

一次前向拿到全部 33 个目标（32 个 block 的 CLS + 最终 `_pooled`），
所以扫 32 层的代价和扫 1 层相同。已验证
`_pooled == ln_post(cls) @ proj`（差异 0.0），
且提取结果与已发布特征逐行核对是**硬门禁**：不一致就退出。

**3. 用闭式 ridge 做层探针**（`scripts/nwret/probe_layers.py`）

这是让本轮变便宜的关键。**为每个候选层训一个深度模型要花数小时；
ridge 每层只要几十秒**，因为：

- ridge 是闭式的 → 不需要训练，不可能过拟合
- **分解只依赖 EEG（X），不依赖目标（Y）**
  → 一次分解服务所有层

每层还扫 λ（层与层的尺度和各向异性不同，固定 λ 会把
「这层更好」和「这层恰好适合这个正则强度」混在一起），
λ 与层都在 val 上选，test 只在选中的 (层, λ) 上打一次分。

**4. 修掉 val 定义漂移（协议 bug）**

`baseline_ridge.py` 的 val 原来只评 slot 0（注释说「对齐 train.py」），
但 train.py 修好后已改为扫 10 个 slot。三者（ridge 下限 / 探针 / 深度模型）
的 val 定义不一致 → **选出的 λ 不可比**。已统一为扫 10 个 slot 取平均。

**5. 实验顺序：探针先行**

原来 19 个臂（backbone / layer / tokenization / fusion 全扫）要跑 6–8 小时，
而且**全在 ridge 下限以下**，排名排的是过拟合程度。
现在改成：`P0 ridge → P1 提特征 → P2 探针定位最优层 → P3 只训该层 + 对照`。
backbone / tokenization / fusion 的大扫描**等有配置越过 ridge 下限之后再上**。

### 顺带查清的两件事

- **CLIP 编码器的 `permute(1,0,2)` 是多余的，但不是 bug。**
  `ResidualAttentionBlock` 自身带 `batch_first`，其内部 transpose 正好抵消它。
  实测「整批跑 vs 逐个跑」差异 5e-6（纯浮点噪声），无 batch 间泄漏。
- `alignment/scripts/extract_features.py` **跑了 11 分钟却保存 0 层**
  （manifest 里 `"layers": {}`）。那是另一个研究（neural visibility）的脚本，
  不在本次范围内，但它一直没有可用输出。

### 判据（写死在 pipeline 输出里）

- 探针：若存在**中间层**在 val 上超过最终层 **>2.8 点**
  （200-way Top-1 的标准误约 2.8 点）→ 轴找对了，这是杠杆。
  若无中间峰 → **层不是症结**，下一个嫌疑是 EEG 通路本身。
- 深度臂：`PA`（探针层）vs `F2`（最终层）的 test 差
  >+2.8 → 杠杆对深度模型同样成立；
  <-2.8 → 探针的偏好**不迁移**，瓶颈在 EEG 编码器；
  落在噪声内 → 同样指向 EEG 编码器。

## 0.8 第四轮结果：**对齐目标层是真杠杆，过拟合不是**

### 结论

| 臂 | 对齐目标 | val Top-1 | **test Top-1** | test Top-5 | mean rank | vs ridge |
|---|---|---|---|---|---|---|
| `align_block26` | **block26** | 23.47 | **34.00** | 65.50 | **8.6** | **+9.00** ✓ |
| `F2_aug_only` | `_pooled`（最终层） | 17.73 | 21.00 | 51.00 | 14.3 | −4.00 |
| `F1_control_unfixed` | `_pooled` | 15.47 | 20.00 | 48.00 | 14.6 | −5.00 |
| `F4_all_fixes` | `_pooled` | 17.87 | 17.00 | 45.50 | 14.3 | −8.00 |
| `F3_mmd_only` | `_pooled` | 15.07 | 16.50 | 41.00 | 16.5 | −8.50 |

**`align_block26` vs `F2`：+13.00 点 test Top-1**，且两者**只差对齐层这一个变量**
（相同的 backbone、EEG 层深、增强、`exp` 温度、MMD 关闭）。
这是 200-way 上约 **4.6 倍标准误**（SE ≈ 2.8）的效应。

**并且这是第一个越过 ridge 下限（25.00）的臂**：+9.00。
mean rank 从 14.3 改善到 **8.6**（chance 100.5）——在 Top-1 远未饱和时，
mean rank 是更敏感的温度计。

### 探针的正确与不足

探针**方向对了**：倒 U 形复现（4.87 → 17.33 → 16.47），
峰值 `block26`，且 `block21..block32` 这连续 10 层**全部**高于最终层。
深度模型选中的 `block26` 正落在这个带内。

但探针对**幅度严重低估**：探针在 block26 上只比最终层高
**+2.50 test / +1.93 ± 1.19 val**（在噪声内），而深度模型实际拿到 **+13.00**。

原因很清楚：ridge 是**线性**的，它衡量的是「该层特征里有多少信息能被线性读出」；
深度模型可以学非线性映射，所以**层间的相对排序由线性可读性给出（方向有效），
但层间差异的幅度对深度模型会放大**。所以：

> 探针用于**定序**（选哪一层）可靠；不要用它的**幅度**去预测深度模型的收益。
> 代价仍然是极低的（每层几十秒 vs 每小时级），所以它作为**筛选器**继续有价值。

### 过拟合不是约束（重要修正）

把「泛化间隙」和「test 性能」放在一起看：

| 臂 | 泛化间隙 | test Top-1 |
|---|---|---|
| `F4_all_fixes` | **12.0**（最小） | **17.00**（最差之一） |
| `align_block26` | 74.0（仍很大） | **34.00**（最好） |

**间隙最小的臂 test 最差**。所以之前第二轮「压过拟合」的方向本身没有错，
但它**不是瓶颈**：`align_block26` 依然严重过拟合（间隙 74 点），
却因为**对齐目标更好**而拿到远更好的 test。

这也解释了第二轮的反常：F3/F4 把间隙压下去了，却因为
softplus + MMD 预热让对齐**变弱**，所以 test 反而更差。
**决定性能的是「对齐到哪个表示」，不是「过拟合多少」。**

### 对后续的意义

按设计文档 §7，**阶段 1（层扫描）的闸门现在通过**，因此：

1. **阶段 2（加权融合）可以开始了**。探针给出的候选带是
   `block22..block28`（val 峰值邻域），融合的目标是把
   「单层 34.00」往上推。文档给的参照是 固定层 → 均匀 → 可路由
   各值 +1.3 / +2.2。

## 1. 三个必须先澄清的事实

这一节是整个设计的约束来源。三条都经过实测核实。

### 1.1 VAE 潜变量是**空间张量**，不是向量 —— 所以只能回归，不能对比

实测 SDXL VAE 配置：

```
latent_channels    : 4
block_out_channels : [128, 256, 512, 512]    # 3 次下采样 → 8× 降采样
scaling_factor     : 0.13025
sample_size        : 1024
```

所以对于一张 512×512 图，潜变量是 **4×64×64 = 16384**；1024×1024 则是 **4×128×128 = 65536**。

**这带来一个决定性的方法学后果**：

> VAE 潜空间**没有对比结构**。同一个概念的两张**不同**图像，其潜变量差异巨大；
> 不同概念的两张**相似**图像，潜变量可能很近。
> 因此**不存在正样本对**，`InfoNCE` 在这里无定义。

**结论：VAE 对齐必须用回归损失（MSE / L1），不能用对比损失。**

这一点必须和「CLIP 对齐」区分开——后者是**对比**（正样本 = 同一张图/同一概念），前者是**回归**。
你在文档里写的「结构侧和 VAE 编码对齐」，实际上要落成**回归任务**，而不是一个对比头。

### 1.2 语义侧的真优势：CLIP 图文**本身就在同一空间**

这是选择 CLIP 作为语义侧基础（而不是任何其他视觉骨干）的**唯一核心理由**：

- CLIP 的图像编码器和文本编码器**输出共用同一个投影空间**（ViT-H-14 为 1280-d）
- 所以「对齐到图像 CLIP」和「对齐到 caption 文本 CLIP」**可以放在同一个头里**，不需要跨空间映射
- 你甚至可以用一个**插值目标**：`z_sem = λ·z_img + (1−λ)·z_cap`（这也是 BrainVis 的做法）

DINOv2 做不到这一点（它没有文本塔）。所以：

> **语义侧用 CLIP 是因为它自带图文对齐；结构侧不用 CLIP 是因为它被训练来丢弃结构。**
> 这两条不矛盾，是两个不同的需求。

### 1.3 caption 资源可用，但有三个坑

实测本地 `/project/peilab/why/data/captions/`：

| 文件 | 条目数 | 粒度 | 正文长度（剥离指令后） |
|---|---|---|---|
| `captions_detailed_train.json` | **1654** | **按概念** | mean 459 字符 |
| `captions_detailed_test.json` | **200** | **按概念** | mean 416 字符 |
| `captions_shared_*.json` | 同上 | 同上 | 与 detailed 长度一致 |
| `captions_sub08_*.json` | 1654 / 200 | 按概念 | **每概念 3 条短句**（如 `['an armadillo walks on dirt ground in a zoo', ...]`）|

**三个坑**：

**坑 1 — caption 是「按概念」而非「按图像」。** 1654 条对应 1654 个概念，不是 16540 张图。
→ 这意味着 caption 目标是**概念级原型监督**，在概念内**恒定**。
→ 它与图像 CLIP（逐图、16540 个不同值）提供的信息**不在同一层级**。见第 5.1 节的处理方式。

**坑 2 — 【致命】所有条目都带同一段指令前缀，而它恰好填满 CLIP 的整个 77-token 窗口。**

实测：指令本身 = **75 token**；CLIP `context_length` = **77**；含指令时**所有条目的 token 序列逐位相同**
（前 50 条只有 1 种序列）。

推导（确定性，无经验成分）：

```
SOT(1) + 指令(75) = 76 个 token       ← 窗口已用完
第 77 位被 EOT 占据                    ← tokens[-1] = eot_token_id
→ 正文一个 token 都进不去
→ 1654 条 token 序列逐位相同
→ 送进确定性模型，输出向量逐位相同，余弦相似度恰好 = 1.0000
```

CLIP 的截断逻辑（[源码](https://github.com/openai/CLIP/blob/a1d071733d7111c9c014f024669f959182114e33/clip/clip.py)）

```python
if len(tokens) > context_length:
    tokens = tokens[:context_length]   # 从头保留，砍尾部
    tokens[-1] = eot_token_id
```

是**从尾部砍**，而指令在**最前面**，所以被砍掉的是真实描述内容。

**后果：这 1654 条 caption 编码出来的不是"高度相似的向量"，而是同一个向量。**
信息量恰好为 0，梯度信号为零。这不是"稀释方差"，是**清空**。

⚠️ **需要回头审查**：若 NW 任一版实验用过 `captions_detailed_*` 做文本条件，
那路信号是**恒定的**，相关结论需重新审视。

**三个对策**：

| 方案 | 做法 | 评价 |
|---|---|---|
| **A 剥离指令** | 剥掉前缀再编码 | 正文 token 均值 65 / max 75，能放进窗口；**但仍有条目顶到 75 被轻微截断**（丢描述尾部） |
| **B 用 `captions_sub08_*`（推荐）** | 每概念 3 条短句，约 10 token | **永不截断**，且天然提供**多正例**（同概念 3 条），正好匹配 §5.1 的多正例设计 |
| **C 换长上下文编码器** | T5-base(512) / BART-base 先编码，再蒸馏进 CLIP 空间 | 459 字符描述 CLIP 物理上装不下；但更复杂，且失去"图文直接同空间"的便利 |

⚠️ **编码前必须在代码里断言**：剥离后的 token 序列在概念间**确实不同**。
即 `assert len(set(seqs)) > 1`。这一条断言就能挡住本坑再次发生。

**坑 3 — caption 有退化条目。** 实测 `detailed_train` 有 **14/1654**、`detailed_test` 有 **3/200**
在剥离指令后正文 < 30 字符（甚至为空）。这些必须丢弃或回退到概念名。

**坑 4（协议）— 测试集 caption 绝不能在推理期使用。** 测试 caption 是从测试图派生的，
推理期拿到它等于拿到了答案。**caption 只能作为训练期辅助目标。**

## 2. 为什么两条支路不能共享目标空间

这一点值得单独说，因为它是整个设计的骨架。

你的生成器是**冻结的 SDXL**，而 SDXL 有**两条不同的条件注入通路**：

| 注入通路 | 期望的输入 | 应该由哪支提供 |
|---|---|---|
| **IP-Adapter / cross-attention** | CLIP 图像嵌入（语义向量） | **语义支路** |
| **潜变量初始化 / img2img 低锚** | **VAE 潜变量**（空间张量） | **结构支路** |

> **两支需要不同目标空间，不是因为「语义和结构是两件事」，
> 而是因为它们喂给生成器的是两个物理上不同的入口。**

这带来两个好处：

1. **架构分离是自然产生的**，不需要人为设计解耦损失
2. **你已有的 `band-anchor`（低频锚）就是 VAE 回归的粗糙版本** —— 这条设计路线是在把你已有的东西做成原理化的版本，而不是另起炉灶

## 3. 骨干选型

### 3.1 结构侧：DINOv2-L（**不要用 CLIP**）

你的判断是对的。理由要写得清楚：

**CLIP 被训练来对纹理、布局、几何做**不变性**——它主动压缩结构信息。**
所以用 CLIP 编码 depth/edge 图当结构目标，是在用一个**被优化来丢弃目标信息**的编码器，
等于自己削弱自己的监督信号。

**实测本地 DINOv2-L 权重**（真实权重，非占位）：

```
DINOv2-L (vit_large_patch14_dinov2.lvd142m)        blocks=24    dim=1024   patch=14
DINOv2-L + reg4 (vit_large_patch14_reg4_dinov2)    blocks=24    dim=1024   patch=14   +4 registers
  pos_embed: [1, 1369, 1024]   → 37×37 = 1369 token（518 输入）
```

**DINOv2 相对 CLIP 的三个结构侧优势**：

1. **自监督目标**（图像自蒸馏）天生保留纹理与空间结构，语义不变性压力远小于 CLIP
2. **空间分辨率高得多**：518 输入 → **37×37 = 1369 patch token**；而 CLIP ViT-H-14 是 224 → 16×16 = 256 token。**差 5.3 倍**
3. **patch token 是空间网格**，可以直接当**空间目标**用（见 3.3）

### 3.2 语义侧：CLIP ViT-L 的**视觉塔**（注意：不是文本塔）

**实测本地**：

```
CLIP ViT-H-14 (laion2B-s32B-b79K)   视觉塔 32 层 / d=1280    文本塔 12 层 / d=512
   visual.proj      [1280, 1024]   ← 视觉 → 联合空间
   text_projection  [1024, 1024]
```

⚠️ **关键：语义侧的 EEG 编码器基础应该用**视觉塔**，不是文本塔。**

理由（详见 §4.2）：CLIP 文本塔**默认带因果掩码**（`no_causal_mask=False`），
而 EEG 的 0–1000ms 各段是**双向耦合**的，因果掩码等于人为砍掉一半注意力方向。
视觉塔是**patch 原生 + 双向**，且其 `patch_embed` 接口可被 EEG patch 直接替换。

**"文本 CLIP"是对齐目标，不是编码器基础。** CLIP 图文在投影后**共用联合空间**，
所以用视觉塔做编码器，输出照样能对齐文本——不需要用文本塔。

选 ViT-L（而非 ViT-B-32）的理由：宽度 1280（容量大）、视觉塔 32 层（层选择空间大）、
且**本地已有对应的图像特征缓存**（`clip_img1280_*.npy` / `clip_img1024_*.npy`，16540/200 行）。

⚠️ **注意两个实测到的缺口**：`timm--vit_large_patch14_clip_224.openai` 和
`timm--eva02_large_patch14_clip_224...` **只有空目录，没有权重**。不要把它们写进计划。

### 3.3 结构侧的一个额外红利：空间目标

因为 DINOv2 patch token 是 **37×37 空间网格**，结构支路**不必只输出一个全局向量**：

| 输出形态 | 用途 |
|---|---|
| `cls_token` (1024-d) | 全局结构向量，可做对比学习 |
| `mean(patch)` (1024-d) | 全局外观向量 |
| **patch grid (37×37×1024)** | **空间结构图 → 可喂 ControlNet 式空间条件** |

**第三项是结构侧最有价值的形态**：你现有的结构条件（depth/edge 的 CLIP 向量）是**全局向量**，
而 ControlNet 类通路需要的是**空间图**。用 DINOv2 patch 网格可以直接补上这个缺口。

⚠️ **分辨率对齐提醒**：DINOv2 是 37×37，VAE 潜变量是 64×64（512 输入）。两者**不等**，
必须显式重采样并在代码里断言，不要依赖隐式广播。

## 4. 整体架构

> **本节于 2026-09-18 重写。** 原设计有一个**违背核心主张**的错误：它用「共享的**冻结通用 EEG 基础模型**（LaBraM / CBraMod）主干 + 两个头」。
>
> 两个问题：
>
> **(1) 该删。** LaBraM / CBraMod 是在**别的任务**（TUAB 异常检测、掩码 EEG 建模）上预训练的。
> 它们的表征不是「更好的起点」，而是**为另一个问题优化的表征**；冻结它还封住了上限。
> 更关键的是——**「到别人的冻结主干里搜一个可用层」这个行为本身就是病症**：
> 如果需要搜，说明这个主干没给到你要的表征。
>
> **(2) 它根本构造不出来。** 见下。

### 4.1 「两路独立」不是取舍，是被核心创新逼出来的

核心创新是「把预训练**语言/视觉**模型改造为 EEG 编码器」。但两类目标**架构不兼容**（实测）：

| | 层数 | 宽度 | patch |
|---|---|---|---|
| CLIP ViT-L | 32 | **1280** | 14 |
| DINOv2-L | 24 | **1024** | 14 |

深度不同**且宽度不同** → **无法共享任何参数。「共享主干 + 两个头」在结构上不可构造。**

所以两路独立是**核心主张的必然推论**，不是一个可选的设计偏好。

⚠️ 顺带澄清一个张力：**「轻量级」与「改造 ViT-L」是矛盾的**。
CLIP ViT-L 与 DINOv2-L 各约 **0.3B 参数**。除非把「轻量级」定义为
**可训练参数少**（冻结主体 + adapter / LoRA），而非模型小。这两件事必须分开讲。

### 4.2 语义侧必须用 CLIP 的**视觉**塔，不能用文本塔

实测 `open_clip 3.3.0` 源码：CLIP 文本塔**默认带因果掩码**

```python
transformer.py:961     no_causal_mask: bool = False
transformer.py:1019    if no_causal_mask:
transformer.py:1022        self.register_buffer('attn_mask', self.build_causal_mask(), persistent=False)
```

**为什么对 EEG 是错的**：因果掩码下位置 \(i\) 只能看 \(\le i\)。对文本合理（生成式）。
但 EEG 的 0–1000ms 各段是**双向耦合**的（晚期成分受早期成分调制）。
用因果掩码 = **人为砍掉一半注意力方向**。

**正确选择：CLIP 视觉塔做 EEG 编码器**，三个理由：

1. **双向注意力**（patch 原生 Transformer，无因果掩码）
2. **patch 原生** —— 输入本就是 patch 序列，EEG 的「时间窗 × 通道组」序列
   可**直接替换**其 `patch_embed`，接口天然对齐
3. **决定性**：CLIP 图文在投影后**共用同一联合空间**
   （实测 `text_projection [1024,1024]`、`visual.proj [1280,1024]`）
   → 用视觉塔做编码器，**输出照样能对齐文本 CLIP**

**结论：区分「编码器基础」与「对齐目标」**

| 角色 | 选择 |
|---|---|
| **编码器基础**（语义路） | CLIP **视觉**塔（双向、patch 原生） |
| **对齐目标** | CLIP **联合空间**（同时容纳图像嵌入与文本嵌入） |

### 4.4 三个让该设计成立的条件

**条件 1 — 「独立」必须独立到优化层面，不只是架构层面。**

两路损失的**数学性质不同**，最优训练配置必然不同：

| | 语义路 | 结构路 |
|---|---|---|
| 主损失 | InfoNCE（对比、**尺度不变**） | MSE/回归（**尺度敏感**） |
| batch 依赖性 | **强**（负样本来自 batch 内） | **无** |
| 有效 batch | 越大越好 | 无关 |
| 主要失效模式 | 对比塌缩 | **回归到条件均值** |
| 需要的正则 | 温度、特征散度 | **方差下界** |

所以「分别训练」不是图省事，而是**必须** —— 不存在一个 batch 尺寸能同时最优。

**条件 2 — 结构路必须放弃「回归完整 VAE 潜变量」。**

理论：MSE 的最优解是条件均值 \(E[z \mid \text{EEG}]\)。而 VAE 潜变量的高频分量在给定 EEG 下
**几乎不可预测**（EEG 的信噪比与空间分辨率远低于 4×64×64 潜变量承载的细节）。
故拿完整 16384 维当目标时，**绝大多数维度的最优预测就是那个均值** ——
你会得到一张模糊图，而且是**数学上正确**的模糊图。

三条出路：(a) 只回归低频/粗粒度部分；(b) 加方差下界防塌缩；
(c) 放弃回归，改用 DINOv2 全局向量走 IP-Adapter。

**条件 3 — 接口替换处要按「分布匹配」设计，不能随手接个 Linear。**

被换掉的 `patch_embed` 原始输入是归一化图像像素。EEG 的**尺度、时间相关性、通道间相关结构**
与之完全不同。预训练块期望的输入统计特性（每维近似单位方差、合理的 token 间相关性）
若不被满足，第一层的 LayerNorm / attention 会处在**分布外**，预训练权重的价值被浪费。

→ `patch_embed` 后必须做标准化；「第一层冻 vs 解冻」应是**显式消融变量**。

## 5. 对齐目标设计

这是你问题的核心部分，逐个给公式与陷阱。

### 5.1 语义支路

**目标 A：图像 CLIP（逐图，试次级）**

\[
\mathcal{L}_{\text{img}} = \tfrac{1}{2}\left(\mathcal{L}_{E\to I} + \mathcal{L}_{I\to E}\right),
\quad s_{ij} = \frac{\mathrm{sim}(z^{E}_i, z^{I}_j)}{\tau}
\]

标准对称 InfoNCE，正样本 = 同一张图。16540 个训练样本，**逐图监督**。

**目标 B：caption CLIP（逐概念，概念级）**

关键问题：caption 在概念内**恒定**（10 张图共享 1 条 caption）。

> ⚠️ **入口前提**：必须用 `captions_sub08_*.json`（每概念 3 条短句，约 10 token）。
> **绝不能用 `captions_detailed_*`** —— 其指令前缀占满 75/77 token，正文全被截断，
> 1654 条编码成同一个向量（§1.3 坑 2）。

所以对 caption 而言，**同概念的 10 个样本互为多正例**，硬负样本是**错误标注**。

因此用**多正例形式**（你已实现过的 SCM-Loss）：

\[
\mathcal{L}_{\text{cap}} = (1-w)\cdot\underbrace{-\log\frac{e^{s_{ii}}}{\sum_{j\neq i} e^{s_{ij}}}}_{\text{硬正例}}
\;+\; w\cdot\underbrace{-\log\frac{\sum_{j: c_j=c_i} e^{s_{ij}}}{\sum_{j\neq i} e^{s_{ij}}}}_{\text{多正例}}
\]

**⚠️ 三重警告**：

1. **你上一轮测过 SCM，结论是零结果**（depth/edge 偏好 `w=0`）。所以 `w` **必须作为网格变量**，且**包含 `w=0` 的硬正例对照**，不要预设多正例更好。
2. **caption 是概念级、恒定的，它会稀释试次特异性。** 你踩过同一个坑：NW-v6 的 fusion「helped val, not test」。所以 caption 损失**必须用 `dev_corr` 这类试次级指标做闸门**，不能只看整体准确率。
3. caption 只作**训练期辅助**，推理期不可用。

**可选精化：插值目标**（BrainVis 做法）

\[
z^{\text{sem}}_{\text{tgt}} = \lambda\, z_{\text{img}} + (1-\lambda)\, z_{\text{cap}}, \quad \lambda \in [0,1]
\]

好处：单头单损失，`λ=1` 退化为纯图像对齐（天然对照）。
风险：`z_cap` 概念内恒定，插值会**把试次方差按 `(1−λ)` 的比例拉平**。λ 必须扫描。

### 5.2 结构支路

**目标 C：DINOv2 多层特征（对比，逐图）**

\[
\mathcal{L}_{\text{dino}} = \tfrac{1}{2}\left(\mathcal{L}_{E\to D} + \mathcal{L}_{D\to E}\right)
\]

**可以用对比**，因为 DINOv2 特征**逐图不同**（这正是它与 VAE 潜变量的本质差别）。
所以这是本设计里**第二个可以安全使用 InfoNCE 的目标**。

**层选择**：DINOv2-L 有 24 层，候选 `{6, 12, 18, 24}`。**必须扫描**——见 5.3。

**目标 D：VAE 潜变量（回归，逐图）**

**这一个是回归，不是对比。** 回到第 1.1 节的结论。

\[
\mathcal{L}_{\text{vae}} = \big\| \hat{z}^{\text{vae}} - z^{\text{vae}} \big\|_2^2
\]

**四个必须做的处理**：

**(1) 降维 —— 不要直接回归 16384 维。**
EEG 的信息量撑不起 4×64×64。建议先做空间池化，例如池到 **4×8×8 = 256 维**，
或对训练潜变量做 PCA 保留前 R 个主成分（R ≈ 128–512）。
直接在原始维度上回归，结果必然是"预测条件均值"，即一张模糊图。

**(2) 方差恢复（variance restoration）—— 否则一定回归到均值。**

这是**你已经踩过并修复过的坑**。当时的原话是：

> "regression-to-the-mean collapsed trial-specific variance"

VAE 回归会**原样复现**这个失效模式，因为条件均值正是 MSE 的最优解。

对策（你已有的算子）：

\[
\hat{z}^{\text{restored}} = \underbrace{\bar{z}^{\text{train}}}_{\text{GT 训练均值}} + a \cdot \text{l2n}\!\left(\hat{z}^{\text{vae}} - \overline{\hat{z}^{\text{vae}}}\right)
\]

其中尺度 `a` 解到与 GT 的**能量占比（energy split）**一致。
**没有这一步，VAE 回归会退化成一张模糊图。**

**(3) 预测"偏差"而非"原值"。** 让目标变成 `z_vae − concept_mean(z_vae)`，
强制模型去学试次级信息，而不是概念级均值。这从**目标定义**层面防止均值坍塌。

**(4) 考虑对齐到带噪潜变量。** SDXL 的 img2img 是从某个步 `t` 的**加噪潜变量**出发。
把回归目标设为 `z_vae(t)`（在某个固定 `t` 上加噪）比回归 `z_vae(0)` 更贴近生成路径。
可作为一个消融。

### 5.3 多层融合

**两支必须分别扫描层偏好。** Shallow Alignment 的倒 U 形结论是在 **CLIP** 上得到的；
**DINOv2 的最优层相对深度可能不同**（自监督模型的层语义分布与 CLIP 不同）。
不要假设两者一致。

| 支路 | 骨干 | 总层数 | 初始候选 | 备注 |
|---|---|---|---|---|
| 语义 | CLIP ViT-H-14 | 32 | `{12, 20, 28, 32}` | 沿用 Shallow Alignment 的中间层偏好，中心约 20–24 |
| 结构 | DINOv2-L | 24 | `{6, 12, 18, 24}` | DINOv2 的密集任务常偏好中段（12 附近） |

**融合路由**（用 SAMGA 的形态，但**每支独立一套参数**）：

\[
\alpha_n = \mathrm{softmax}\!\left(\frac{q + r_n\, b_{s_n}}{\tau_r}\right),
\qquad r_n \sim \mathrm{Bernoulli}(1-p_s)
\]

- 全局先验 `q`：可学习 logits，**初始化成中心落在扫描出的最优点**（不要从均匀开始）
- 被试残差 `b_{s_n}`：每个训练被试一组偏移
- **被试 dropout** `p_s`：保证"只用全局先验"这条路径在训练中被真正优化过（推理期用的就是它）
- **层 dropout** `p_ℓ`：防止路由塌缩到少数层

**投影器用线性的。** SAMGA 的消融明确显示 **MLP 反而更差**——层级特征进公共空间只需换坐标系。

### 5.4 损失平衡

四个损失的尺度差异极大（两个 InfoNCE、一个逐图 InfoNCE、一个 MSE）。
用你已实现的学习式不确定性加权（Kendall）：

\[
\mathcal{L} = \sum_m \left[\frac{1}{2\sigma_m^2}\mathcal{L}_m + \log \sigma_m\right],
\qquad \sigma_m = \exp(\mathrm{clamp}(ls_m, -4, 4))
\]

clamp 到 ±4 防止某个模态被静音；**同时保留「等权平均」作为对照**。

**不要硬凑跨支路共享目标。** 你的 SCM 实验（depth/edge 偏好 `w=0`）已经证伪了这条路。

## 6. 一个必须做的诊断实验：VAE 目标到底可不可学

在做完整架构之前，先花很小成本回答一个问题：

> **EEG 对 VAE 潜变量的可预测性有多高？**

**做法**（不需要训练生成器）：

1. 取 16540 条训练 EEG 特征（你已有导出）
2. 计算对应的降维 VAE 潜变量（例如池化到 256 维）
3. 在 `fit` 上拟合**岭回归** EEG → 潜变量，在 `val_a` 上评估
4. 报告指标：**`dev_corr`（去掉均值后的试次相关性）** 和能量恢复率

**判据（预登记）**：

| `val_a` 的 `dev_corr` | 判断 | 行动 |
|---|---|---|
| < 0.15 | VAE 目标**信息量不足** | 放弃 VAE 回归，改用 DINOv2 全局向量走 IP-Adapter |
| 0.15 – 0.30 | 有信号但弱 | 做，但必须做方差恢复 + 只当低锚用 |
| > 0.30 | 值得投入 | 完整实现 |

**为什么先做这个**：你的结构支路历史给出了一个警示——`dev_corr 0.352` 只买到约 5% 的 GT 增益，
而 `dev_corr 1.0` 买到 +0.128。**嵌入空间的指标会骗人**，所以这个诊断只能筛掉明显无望的，
不能证明有效。**最终裁决仍然是生成实验。**

## 7. 分阶段实施计划（每阶段带判据）

### 阶段 1：层扫描地基（**最优先，最便宜**）

**做什么**：固定单层，把 CLIP 32 层和 DINOv2 24 层各扫一遍，画「层深 vs 检索 Top-1」曲线。

**为什么先做**：这是最大的单一杠杆（+31.7，被试内 50.9 → 82.6），
且是后面所有实验的基准。不做这一步，后面所有数字都没有参照。

**判据**：两支都应呈现**倒 U 形**。
**若复现不出倒 U，停下来找原因**——说明实现与文献有系统性差异。

### 阶段 2：加权融合

**做什么**：把扫描出的 top-k 层做融合。先**均匀融合**（验证多层有互补信息），再上**可学习路由**。

**预期参照**：SAMGA 的消融是 固定层 87.8 → 均匀 89.1 → 可学习 91.3。
即「多层本身」值 +1.3，「自适应组合」再值 +2.2。

### 阶段 3：接口替换（把预训练块接成 EEG 编码器）

**做什么**：丢弃两个骨干的 `patch_embed`，换成 EEG 投影；接上双向预训练块；
`patch_embed` 后做标准化（§4.4 条件 3）。

**为什么**：这是核心创新的落地步骤 —— 把预训练语言/视觉模型改造为 EEG 编码器。
与阶段 1–2 正交、可叠加。

**消融变量**：第一层「冻结 vs 解冻」；`patch_embed` 的容量。

> ⚠️ **不再接通用 EEG 基础模型**（原阶段 3 设计已废弃）。
> LaBraM / CBraMod 是在别的任务上预训练的，冻结它们既违背核心主张、又封住上限（§4.1）。

### 阶段 4：结构支路加 VAE 回归

**做什么**：在 DINOv2 对比头之外，加一个 VAE 潜变量回归头（降维 + 方差恢复 + 偏差目标）。

**前置条件**：阶段 0（第 6 节的诊断）通过判据。

**判据**：`dev_corr` 相比纯 DINOv2 基线**有提升**，且生成侧不退化。

### 阶段 5：caption 辅助目标

**做什么**：接 caption text CLIP 对齐（剥前缀 + 丢退化条目 + 多正例网格含 `w=0`）。

**判据**：**必须用试次级指标（`dev_corr`）把关**，不能只看概念级准确率。
若概念级涨、试次级跌，说明它在前述的坑里，应降权或关闭。

## 8. 关键风险与对策

| 风险 | 为什么会发生 | 对策 |
|---|---|---|
| **VAE 回归退化成模糊图** | MSE 的最优解就是条件均值 | 方差恢复 + 偏差目标 + 降维（第 5.2 节） |
| **caption 稀释试次特异性** | caption 概念内恒定 | 多正例含 `w=0` 对照；用 `dev_corr` 把关 |
| **两支梯度冲突** | 硬共享解码头/瓶颈的已知问题（QMATE 实测梯度余弦为负） | **两路完全独立**（§4.1）；无共享主干，故无共享冲突面 |
| **层偏好照搬 CLIP** | Shallow Alignment 的结论是在 CLIP 上得到的 | 两支**分别**扫描 |
| **caption 指令前缀污染** | 42% 的文本完全相同 | 显式剥离，并在代码中断言剥离成功 |

## 11. 必做的对照实验

这些不是可选项。缺失任何一项，结果都无法解释。

| 对照 | 回答什么问题 | 判据 |
|---|---|---|
| **单层扫描** | 层偏好是否复现倒 U | 两支各自成立 |
| **均匀融合 vs 可学习路由** | 「多层」和「自适应」各值多少 | 分离出两个增量 |
| **`w=0` 硬正例（caption）** | 多正例是否真的更好 | 你上次的答案是「否」 |
| **λ=1（纯图像 CLIP）** | caption 是否净增益 | 若 λ<1 不更好，关掉 caption |
| **VAE 回归 w/o 方差恢复** | 均值坍塌是否复现 | 应显著变差 |
| **零样本合法性** | 推理期是否用了测试信息 | 硬断言：不加载测试 caption |
| **DINOv2 vs CLIP 做结构** | 你的核心假设 | 这是本设计最该被证伪的一条 |

**统计纪律**（沿用项目既有规范）：

- leak-free 划分（`fit` 14890 / `val_a` 830 / `val_b` 820 / test 只评一次）
- **绝不按 test 选 checkpoint**，代码里加硬断言
- 配对检验（Wilcoxon），**10 被试 exact p 值下限 0.00195**
- 每个断言配**负控制**（且验证负控制确实产生了变化）

## 12. 一句话总结

**两路完全独立，不是设计偏好，而是核心主张的必然推论** ——
CLIP ViT-L（宽 1280）与 DINOv2-L（宽 1024）**宽度不同，物理上无法共享参数**。
「共享冻结 EEG 主干 + 两个头」既违背核心主张，也在结构上不可构造。

**语义侧用 CLIP 的视觉塔当 EEG 编码器**（双向、patch 原生），**不是文本塔**
（文本塔带因果掩码，对 EEG 的双向耦合是错的）；而「文本 CLIP」只做**对齐目标** ——
因为 CLIP 图文在投影后共用联合空间，用视觉塔照样能对齐文本。

**结构侧用 DINOv2**，因为 CLIP 被训练来丢弃结构（iBOT 掩码目标则强制保留结构）。

**VAE 潜变量是空间张量、没有对比结构，所以只能回归**；
而 MSE 的最优解是条件均值，所以**必须**降维 + 方差下界，否则退化成一张模糊图——
**而且是数学上正确的那张模糊图**。

**最大的单一杠杆不是骨干，而是「对齐到哪一层」（+31.7）。所以阶段 1 的层扫描必须先做。**

**最该被证伪的一条是「DINOv2 比 CLIP 更适合做结构目标」——这是本设计里唯一真正新的假设。**
