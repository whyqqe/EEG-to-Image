# EEG-to-Image 解码：UCK 与 EEG Patch 接口模型

---

## 1. 任务与数据

### 1.1 两条读出

给定被试看到某张图后产生的 EEG，恢复其所看的视觉内容。恢复的强度有两种：

| 读出 | 输出 | 需要的信息 |
|---|---|---|
| **检索** | 200 个候选中给出排名 | 主要是**语义**（区分"猫"与"狗"） |
| **重建** | 像素 | **语义 + 结构**（姿态、位置、轮廓） |

重建包含检索：重建得好的模型必然检索得对，反之不成立。

### 1.2 数据：THINGS-EEG2

| 项 | 内容 |
|---|---|
| 被试 | 10 人 |
| 训练集 | 1654 概念 × 10 图 × 4 重复，平均后 `(1654, 10, 63, 250)` |
| 测试集 | 200 概念 × 1 图 × 80 重复，平均后 `(200, 1, 63, 250)` |
| 概念重叠 | **训练与测试概念完全不重叠**（零样本） |
| 电极 / 采样率 | 63 导联 / 250 Hz |
| 时间窗 | 刺激后 0–1000 ms |
| 预处理 | MVNN 白化（逐试次多变量噪声归一化） |

两条事实决定了模型该怎么设计：

**零样本。** 1654 个训练概念在测试时一个都不出现，所以模型必须学"如何解码"，而不是"记住什么"。

**测试集的重复平均次数远多于训练集。** 训练平均 4 次、测试平均 80 次。平均 \(N\) 次把噪声标准差降到 \(1/\sqrt{N}\)，测试信噪比因此是训练的 \(\sqrt{80/4}\approx 4.5\) 倍，测试集只有 **200 行**而不是 16000 行。这是这个领域的共同口径。

### 1.3 评测口径

| 项 | 设置 |
|---|---|
| 检索指标 | 200-way Top-1 / Top-5 / mean rank（随机 mean rank = 100.5） |
| 重建指标 | PixCorr、SSIM、AlexNet(2)、AlexNet(5)、Inception、CLIP、SwAV、FID |
| checkpoint 选择 | 概念级留出（150 个**训练**概念），测试概念不参与任何决策 |

**选择必须用留出的训练概念，不能用测试集。** 用测试集挑 checkpoint 会让报出的成绩包含"挑得最好那一次"的运气，且这个偏差无法事后扣除。

## 2. UCK：语义–结构双塔

### 2.1 原理：为什么必须分两条支路

重建把冻结的 SDXL 当解码器。SDXL 有三条影响结果的入口，它们的**输入类型不同**：

| 入口 | 期望输入 | 携带什么 | 不能携带什么 |
|---|---|---|---|
| **IP-Adapter** | CLIP 嵌入，一个**向量** | 全局语义（"一只橘猫"） | **空间布局**——向量没有空间维度 |
| **ControlNet** | 空间图（深度/边缘），一个**张量** | 何处有物体、什么形状 | 这是什么物体 |
| **img2img 低锚** | VAE 潜变量，一个**张量** | 全局低频布局 | 细节（会被重新生成） |

所以 UCK 分成两个塔：**语义塔**给出向量条件，**结构塔**给出一组空间条件。

如果两个塔各自独立训练，会出现一个架构性缺陷：**它们的输出可能互相矛盾**——语义塔说"一只坐着的猫"，结构塔画出一只站着的猫，SDXL 同时收到这两者，只能给出一个折中结果。UCK 的对策是让两个塔**共享一个中间表示**，从架构上杜绝矛盾：

- **一个表示**：全部信息只来自一个表示 \(z\)；
- **两个视图**：\(z\) 派出语义、结构两个读出；
- **一张空间场**：结构侧输出一张共享的空间场，深度图和 VAE 潜变量都由它派生——二者描述的是同一张图，独立生成就会互相打架。

### 2.2 架构

```
UCK
│
├─ 输入 z (B,1024)               ← 预训练好的 EEG 编码器的输出，训练 UCK 时固定不变
│
├─ 语义塔（向量条件）
│   ├─ 查询网络：MLP(1024 → 1024)  ⇒ q
│   └─ 概念图库软检索（可微 top-k）
│        q 与 1654 个训练概念的 CLIP 图像均值求相似度，取 top-k 加权
│        ⇒ 条件向量 (B,1024) ────→ IP-Adapter
│
├─ 结构塔（空间条件）
│   ├─ 升维 + 上采样卷积塔        ⇒ 共享空间场 F (B,32,64,64)
│   ├─ 深度头（sigmoid）          ⇒ 深度图 (B,64,64) ──→ ControlNet
│   └─ VAE 头（零初始化）         ⇒ VAE 潜变量 (B,4,64,64) ─→ img2img 低锚
│
└─ 解码：冻结 SDXL（ControlNet-Depth + img2img），UCK 只提供条件
```

**输入为什么冻结。** UCK 拿到的 \(z\) 来自一个单独训练好的 EEG 编码器，训练 UCK 时不更新它。原因是样本量：训练集只有 16540 对，如果让编码器和 UCK 联合训练，前段没有足够信号约束，会去拟合噪声。

### 2.3 训练

| 项 | 值 |
|---|---|
| 优化器 | AdamW，lr 1e-3，weight decay 1e-4 |
| 预算 | 30 epoch × batch 128 |
| 梯度裁剪 | 范数上限 1.0 |
| 采样 | 一部分训练概念出梯度，另一部分留作选择 |
| 选择分数 | `文本 Top-1 + 图像 Top-1 + 0.1 × 深度图相关系数` |
| 可训参数 | 约 1272 万 |

**四项损失，等权：**

| 损失 | 目标 | 作用 |
|---|---|---|
| InfoNCE（文本图库） | 1654 个训练概念的文本 CLIP | 语义 |
| InfoNCE（图像图库） | 1654 个训练概念的图像 CLIP | 语义 |
| `L1 + 0.5 × 梯度损失` | 深度图 | 结构（ControlNet） |
| L1 | VAE 潜变量 | 结构（img2img） |

四个设计点：

**语义为什么要同时对齐图像和文本 CLIP。** 两者互补：图像 CLIP 更细（具体外观），文本 CLIP 更粗（类别语义）。只用图像会过拟合到视觉细节，只用文本会丢掉外观信息。两者处在同一个联合空间里，所以可以共用一个查询向量去对齐。

**深度损失为什么要加一阶差分项。** 纯 L1 对离群值鲁棒，代价是不惩罚边缘模糊——一片均匀灰和一张有清楚轮廓的深度图，在纯 L1 下可能得分相近。一阶差分项显式要求边缘保住。

**VAE 头为什么要零初始化。** 训练开始时结构条件恒为 0，等于"不提供信息"。这样训练从纯语义条件出发，结构信息只在确实降低损失时才被引入。若随机初始化，一个随机的结构场会把噪声烧进模型，而模型没有机会先学好语义。

**选择分数为什么给深度图只算 0.1 权重。** 相关系数是连续值，量纲与两个 Top-1 不同。同权会让它主导选择，而最终指标更依赖语义正确性。

### 2.4 语义塔：检索，而不是回归

**查询向量 \(q\) 是一个好的排序器，却是一个差的回归输出。** 在 200 个测试样本上（chance = 0.005）：

| 条件 | 200-way Top-1 | 与真实图平均余弦 | 相对平凡解（0.6275） |
|---|---|---|---|
| 原始查询 \(q\) | **0.265** | 0.2297 | **−0.398** |
| 检索后的条件 | 0.140 | **0.6568** | **+0.029** |
| 噪声输入（走同一条代码路径） | 0.000 | 0.5382 | −0.089 |

**逐图 CLIP 嵌入里大部分方差是不可恢复的**：确切姿态、背景、光照、纹理。逼模型去拟合这些方向，结果会比"一律输出均值"这个平凡解更差——它在追一个永远命不中的目标。检索把这个问题换成排序问题：\(q\) 不需要精确，只要离正确概念的邻居更近，top-k 加权就能把结果拉回正确概念附近，**从平凡解下方 0.398 变成上方 0.029**。

**这个交易有代价，必须一起说。** 把条件向量对应回它自己那一行的能力（`row_identity_top1`）从 **0.265 掉到 0.140**。原因在行间余弦：\(q\) 彼此几乎正交（0.108），检索后升到 **0.753**——图库存的是概念均值，同一概念的所有实例被压成一个点，所以检索**抹掉了概念内的实例差异**。它换来"落在正确概念邻域"，失去"落在正确的那一张图"。这条测量直接指出改进方向：这个条件提供概念级语义，实例级信息需要另找出口。

另外，检索不能用全 softmax：在 1654 维的平坦相似度分布上它会**塌到图库均值**，实测检索结果与真实图的余弦只有 0.64，而一个常数向量就有 0.61。

## 3. EEG Patch 接口模型

### 3.1 原理：注意力对空间结构不可知

自注意力

\[
\text{Attn}(X) = \text{softmax}\!\left(\frac{XW_Q (XW_K)^\top}{\sqrt{d}}\right) XW_V
\]

是**置换等变**的：对输入 token 做行置换 \(P\)，输出集合不变，只是顺序跟着变（\(\text{Attn}(PX) = P\,\text{Attn}(X)\)）。**"token 5 在 token 6 左边"这件事，注意力本身完全不知道。**

空间结构只能从两个入口进入：

| 入口 | 机制 |
|---|---|
| patch 嵌入的卷积 | 相邻 patch 覆盖相邻像素，相邻 token 天然相关 |
| 位置编码 | 显式告诉每个 token"你在哪" |

**由此得到本模型的核心判断：一个 ViT 编码器的能力，很大程度上取决于 token 是怎么造出来的，而不是骨干有多少层。** 骨干对输入的空间结构不可知，它只处理一个 token 集合。

这也解释了为什么"换更大的骨干"收益有限：模型容量的瓶颈不在那儿，**把 EEG 转成预训练权重认识的输入形式**才是杠杆。

### 3.2 思路：把 EEG 重排成一张图像

预训练 ViT 的 patch 嵌入是一个 16×16 的卷积。它要能用，输入就必须是一张**每个 16×16 小块都有局部意义**的图像。于是把一个 EEG 试次重排成一张 "EEG 图像"：

- **纵向 = 解剖分区。** 63 个电极按神经解剖分成 5 组，从后到前：枕 8、顶 9、颞 10、中央 21、额 15。区内电极空间相邻、信号相关，分组保留了有生理意义的空间相关性。分区顺序就是真实的头-尾轴。
- **每组内插值到 16 个位置。** 之所以是 16，**因为 16 就是 patch 尺寸**——每个分区恰好变成 1 个 patch 行，5 个分区就是 5 个 patch 行。各区电极数不同（8 到 21），用相邻电极间的线性插值统一到 16，它假设头皮电位在相邻电极间连续变化，对这个物理量是合理的。
- **横向 = 时间。** 250 个采样点均匀重采样到 `14 × 16 = 224` 列，每个 patch 覆盖 `250/14 ≈ 17.9` 个采样点，即约 **71 ms**。
- **复制成 3 通道**，满足 3 通道卷积的接口形状。

结果是一张 `(3, 80, 224)` 的图像，切成 **5 × 14 = 70 个 token**，**每个 token 就是「一个脑区 × 一个约 71 ms 的时间段」**。时间不与空间混进同一轴，因为时间耦合单向推进而空间是二维的，混在一起会混淆两种结构。

两个必要的处理：

**z-score 用逐通道一个标量**，不用逐时间点。输入已做过 MVNN 白化，白化本身已把各时间点的尺度拉平；再对每个时间点单独做 z-score，等于除以一个噪声估计，会把低信噪比的采样点放大。统计量只从训练概念上估计。

**区内电极在插值前按 montage 的横向坐标排序。** 插值沿"给它的那个一维顺序"进行，只有左右顺序才能让插值在空间上有意义，否则会插出左右电极之间的电位差。

### 3.3 架构

```
EEG Patch 接口模型
│
├─ 输入：EEG (B, 63, 250)
│
├─ ① EEG 图像构造（无参数，固定插值矩阵）
│   └─ (B, 3, 80, 224)
│
├─ ② 复用预训练 patch 嵌入（16×16 卷积，权重可训）
│   └─ (B, 70, 768)：70 个 token = 5 patch 行 × 14 patch 列
│
├─ ③ 位置与特殊 token
│   ├─ 位置编码：源网格 14×14 → 目标 5×14，双三次插值（不重学）
│   └─ cls 槽 = 位置编码[0] + 预训练 cls token
│
├─ ④ ViT 骨干（12 层），取中间层 {8, 10, 12}
│   └─ 每层先过最终 LayerNorm，再取 cls token
│
├─ ⑤ 层融合：每层过一个线性层换坐标系，再等权相加
│
└─ ⑥ 投影到共享维度  ──── 对称 InfoNCE ────  冻结的 CLIP 图像特征
```

四个必须做对的细节：

**预训练卷积要保持可训。** 它正是"复用预训练"这件事的载体。冻结它就等于只保留了形状、丢掉了内容。

**要显式解除输入尺寸断言。** 预训练 patch 嵌入按 224×224 构建，会拒绝 80×224。放宽后只要求能被 patch 尺寸整除，而卷积本身与输入尺寸无关。

**位置编码用插值，不重学。** 把源网格 14×14 重采样到目标网格 5×14，直接搬用预训练学好的相对几何。注意不同 checkpoint 的位置编码长度不同（有的含 cls 位、有的不含），必须按**源网格**去比对。

**cls 槽必须是「位置编码[0] + 预训练 cls token」两项之和。** 只放位置编码那一项会丢掉预训练 cls token（它根本没进入前向计算），且 cls 槽在初始化时对每个样本完全相同、不含样本信息。这类缺陷不报错，只是让"复用预训练"悄悄打折。

**每层池化前要补最终 LayerNorm。** 标准前向以最后一层 LayerNorm 结束，但取多层特征必须绕过它。最后一层需要它是因为那个 LayerNorm 就是为它标定的；中间层需要它是因为不同深度处于不同的归一化状态、量纲不可比——而层融合恰恰要把几个深度的特征放在一起比较和混合。

### 3.4 两条支路的设计

与 UCK 一样，这个模型也按语义、结构两条支路设计，区别在于**复用的位置**：UCK 复用预训练模型的**输出空间**（CLIP 联合空间、VAE 潜空间），这个模型复用预训练模型的**输入形式**（patch 卷积的局部感受野、位置编码中的相对几何）。

| | 语义支路 | 结构支路 |
|---|---|---|
| 骨干 | **CLIP** 视觉塔 | **DINOv2-L** |
| 对齐目标 | CLIP 图像特征（**对比**） | DINOv2 多层特征（**对比**）或 VAE 潜变量（**回归**） |
| 下游用途 | 向量条件 | 空间条件（DINOv2 的 37×37 patch 网格可直接作空间图） |

三个设计约束：

**两条支路不共享主干，这不是取舍。** CLIP ViT-L 宽 1280、DINOv2-L 宽 1024，宽度不同，**物理上无法共享参数**。所以这里是两套各自独立的 patch 嵌入加预训练块，而不是一套骨干上的两个头。

**结构侧不能用 CLIP。** CLIP 是被训练来**丢弃**结构的（语义不变性正是它的目标），拿它当结构目标等于自毁；DINOv2 才是结构保持的。

**结构侧主要落成回归，不能全用对比。** VAE 潜变量是空间张量，且**没有对比结构**：同一概念的两张不同图像潜变量差异巨大，不同概念的两张相似图像潜变量可能很近——不存在有意义的正样本对，InfoNCE 在这里没有定义，只能用 MSE/L1。而 DINOv2 特征逐图不同，可以用对比。

语义侧当前只对齐 **CLIP 图像特征**（取 ViT-H-14 的中间层，因为最终层为了语义不变性主动压掉了局部纹理，而 EEG 恰好保留了低层结构信息）。文本 CLIP 与图像 CLIP 本就在同一个联合空间，追加文本对齐是一个可以并上的选项。

### 3.5 训练方法

| 项 | 值 |
|---|---|
| 损失 | 对称 InfoNCE（可学习温度）＋ MMD，两者**互补**加权 |
| 分层学习率 | 预训练骨干 5e-5，随机初始化的接口与头部 5e-4；warmup 后 cosine 退火 |
| 增强 | 随机时间移位、高斯噪声、随机平滑、通道丢弃 |
| 其他 | AdamW，weight decay 1e-4，batch 512，梯度裁剪 1.0 |

四个要点：

**骨干学习率要低一个数量级。** 预训练权重已经在好的解附近，用和随机初始化模块相同的学习率会把它们推离那个解；而接口的输入分布变了，需要更大的步子。调度实现为**对配置学习率的乘子**，这样组间比例（骨干 : 接口 : 头部 = 1 : 10 : 10）在整个训练过程中保持。

**增强的四个变换各自对应一个物理事实**：时间移位建模诱发电位的延迟抖动（同一刺激在不同试次的波形不在同一毫秒出现）；高斯噪声建模电极噪声；随机平滑建模低通滤波（诱发成分主要在低频）；通道丢弃建模坏电极与被试间电极覆盖差异。另外噪声幅度要用数据自己的单位——这套数据逐通道标准差约 0.5，直接照搬文献的固定小幅度会完全不起作用。

**增强的顺序有含义**：先移位，再噪声，再平滑，最后丢通道。如果先丢通道再平滑，平滑会在被清零的通道处造出人造阶跃边缘，把增强变成注入伪影。

**MMD 的带宽必须自适应，否则它等于一个被关掉的损失。** MMD 用 RBF 核 \(\exp(-d^2/2s^2)\)，而在 512 维已归一化嵌入上，两两距离在几十的量级：距离 30、带宽 1 时 \(d^2/2s^2 = 450\)，核值下溢到 0——每一项都下溢，MMD 恒等于 0、梯度恒等于 0。日志上"损失不动"和"这个机制没用"看起来一样，含义却相反。修法是用两两平方距离的**中位数**定带宽，并围绕它取几个倍数，让核在多个尺度上都有支撑。MMD 与 InfoNCE 的权重之和固定为 1，而不是各自独立相加——直接相加会让总梯度量级随权重变化，等于隐式改了学习率。

### 4.1 检索线：一条"改目标"的演进史

**EEGiT 的消融给"接口"这件事定了价**（THINGS-EEG，被试内 10 被试均值 Top-1）：

| 预训练权重 | EEG patch 接口 | Top-1 |
|---|---|---|
| ✗ | ✗ | 41.8 |
| ✗ | ✓ | 54.0 |
| ✓ | ✗ | 63.6 |
| ✓ | ✓ | **70.4** |

这张表有两种读法，必须分开说。按**单独贡献**，预训练权重 **+21.8** 大于 patch 接口 **+12.2**；按**边际贡献**（在已有另一项之上再加），接口 **+16.4** 大于权重 **+6.8**。所以"接口比权重值钱"只在边际读法下成立。正确的表述是**两者互补且都必需**：只有预训练权重，模型仍在吃原始时序 EEG（63.6）；只有接口，token 的几何对了但没有视觉先验可迁移（54.0）；两者同时具备才有 70.4。

### 4.3 对比时的三个口径陷阱

| 陷阱 | 具体表现 |
|---|---|
| **电极数不同** | SAMGA 的**被试内**实验只用 17 个枕顶电极，被试间才用全部 63；UCK 与 EEG Patch 接口模型都用全部 63（EEGiT / UBP 也用 63）。所以跨论文算出来的百分比混合了两种协议，只能当量级参考 |
| **选择方式不同** | SAMGA 用测试集 Top-1 选 checkpoint；这里不用。二者不可逐位对比 |
| **论文之间不可相减** | 不同论文的"零样本""被试内"定义可能有细微差别。只有同一篇论文同一张表的数字严格可比 |

### 4.4 三条规律

#### 规律一：最大的收益都在「监督目标 / 接口怎么构造」，不在「编码器怎么设计」

| 改的是什么 | 效应 |
|---|---|
| 对齐到**哪一层**（最终层 → 中间层） | **+31.7 点**（UBP 50.9 → Shallow Alignment 82.6） |
| 目标图**长什么样**（普通 → 8-blur 多层级） | **+21.6 点**（61.2% → 82.8%） |
| 加**预训练权重**（随机初始化 → ImageNet-21K） | **+21.8 点**（EEGiT 2×2 表，单独贡献） |
| 输入**怎么变成 token**（随机投影 → 预训练卷积 patchify） | **+12.2 点**（单独贡献）/ **+16.4 点**（边际贡献） |
| 结构信息走**哪条通道**（→ ControlNet） | 生成线 SSIM 的主要修复方向 |

这五个"改"的落点不同：在哪学、学什么、输入长什么样、输出走哪条路。共同含义是**模型容量不是主要瓶颈，"在哪里学、学什么"才是**。

由此得到两条复用预训练模型的途径，也正是 UCK 与 EEG Patch 接口模型的分界：

| 复用途经 | 做法 | 用它的模型 | 复用了什么 |
|---|---|---|---|
| **输出端** | 把 EEG 对齐到预训练模型的**输出空间** | UCK | CLIP 联合空间（语义）、VAE 潜空间（结构） |
| **输入端** | 把 EEG 重排成预训练模型的**输入形式** | EEG Patch 接口模型 | patch 卷积的局部感受野、位置编码的相对几何 |

两者的失败模式不同：输出端错在目标空间选得不合适（该检索却去回归、该用中间层却用最终层），输入端错在 token 的几何与预训练权重被训练时不一致。

#### 规律二：「被试差异」是一个低维变量

| 方法 | 怎么处理被试差异 | 代价 |
|---|---|---|
| **ENIGMA** | 每被试一个线性层 | <1% 参数量（165× 减少） |
| **SAMGA** | 被试残差路由 + 被试 dropout | 可忽略 |

解法不同，但都在说同一件事：被试间的系统性差异是低维的。可检验的预测是，"每被试一个小模块 + 共享大骨干"应当严格优于"每被试一个大模型"。

#### 规律三：检索质量是重建质量的上限

CognitionCapturer 的多专家检索、ATM 的两阶段管线、NVOL 的检索/生成耦合——三个独立工作指向同一件事，而 §2.4 与 §2.5 的消融是这条规律在本项目内的直接测量：**去掉检索，Inception 从 0.7197 掉到 0.5843、FID 从 175.77 涨到 209.88**；反过来，语义条件的质量越好，生成指标越好。这说明重建的上限由语义侧决定，结构侧只负责把这个上限兑现在空间保真度上。
