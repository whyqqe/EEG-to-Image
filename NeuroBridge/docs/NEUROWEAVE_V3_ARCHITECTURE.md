# NeuroWeave v3 — Task-Factorized Dual-Pathway Architecture

> 目标：在 THINGS-EEG2 官方七指标上实现对现有 SOTA 的 **Pareto 支配**（非 7/7 全赢）。
> 本文档同时是**判据依据**：任何后续实验若与本文件的 kill criteria 冲突，以本文件为准。

---

## 0. 一个决定性的实测事实（本架构的全部出发点）

`uck_train.py` 导出的 EEG→VAE 空间头预测（`outputs/uck/sub-08/full/spatial/pred_lowlevel_rgb_512`）
经 SDXL VAE 解码后的图像，在**官方协议**（gray@425 gaussian）下测：

| | PixCorr | SSIM |
|---|---|---|
| **空间通路 init（EEG-only，leak-free）** | **0.2998** | **0.4997** |
| 我们生成图最好（干净臂） | 0.1729 | 0.3880 |
| **BrainAE (ICLR'26) 最终输出** | 0.211 | 0.432 |
| ATM (NeurIPS'24) 最终输出 | 0.160 | 0.345 |

**合法性核查**（`scripts/nda/uck_train.py`）：
- 梯度只用 `fit` 划分；checkpoint 选择只用 `val_b`（`outputs/leakfree/split.json`）
- gallery = 1654 **训练**概念，脚本内**断言**与 200 测试概念交集为 0
- `vae_head` 零初始化；损失 `L1(o["vae"], vn)`，`vn` 取自 **train** VAE 潜变量
- **测试 VAE 潜变量从未作为训练目标**，仅用于导出

### 结论（三条公理）

> **A1. 空间通路的信息量已经超过所有 SOTA 的最终输出**（0.2998/0.4997 vs 0.211/0.432）。
> **A2. 瓶颈不在"信息不足"，而在生成阶段的信息销毁。**
> **A3. 该指标族系统性偏好低频保真度**（PixCorr 是 Pearson，对仿射不变；SSIM 由低频结构主导），
> 因此"模糊但空间对齐"的 init 天然占优——这正是 ATM 低层分支有效的原理。

### 由此得到的定量靶子

| 指标 | init 上限 | 当前保留率 | 击败 BrainAE 所需保留率 | 缺口 |
|---|---|---|---|---|
| PixCorr | 0.2998 | **57.7%** | **70%** | +12.3 pp |
| SSIM | 0.4997 | **77.6%** | **86%** | +8.4 pp |

**这两个数字就是整个架构要攻的靶子。** 它们很小——不需要新范式，需要的是**保真**。

## 1. 设计公理

| 编号 | 内容 | 来源 |
|---|---|---|
| N1 | 条件必须携带**类内方差** \(S\)，不能只携带身份 \(Y\) | NCE 的最优解是 \(Y\) 的近似最小充分统计量，\(S\) 被当作噪声主动销毁 |
| N2 | 条件坐标必须**锚定**（需要回归项，不只有排序损失） | NCE 只约束相似度序，解是框架自由的等价类；检索不敏感、生成敏感 |
| N3 | 条件必须落在**图像嵌入流形**上 | 否则 IP-Adapter/ControlNet 收到分布外输入（支持失配） |
| N4 | 至少两条**物理分离**的容量池 | 单通道 ⟹ 约束 \(f(q_s)+g(q_p)=C\) ⟹ 一升必一降 |
| N5 | 语义子条件之间必须**互相约束**（融合） | 3 分支并联互不知情，无法互相去噪；这是相对 CogCapPro 的 0.09 语义缺口主因 |

**N1–N4 必要，N5 是充分性补丁。**

## 2. 缺陷清单与模块映射

### 2.1 我们架构的缺陷

| ID | 缺陷 | 理论形式 | 修复模块 |
|---|---|---|---|
| A | 目标与任务反对齐（信息赤字） | NCE 销毁类内方差 | **M2** 任务因子化 |
| B | 坐标框架未锚定 | 等价类未被固定 | **M2** 回归项 |
| C | 条件在流形外 | \(\mathrm{supp}(q)\not\subseteq\mathrm{supp}(p)\) | **M3** 先验精炼 |
| D | 单通道率失真错配 | 一条通道承载两类高熵信息 | **M2 + M5** 双通路 |
| E | 层注入不能扩前沿 | \(u=\sum_\ell s_\ell A_\ell V_\ell c\) 的系数重排 | **M5**（降级为分配策略） |
| F | 生成损失不回流编码器 | 代理目标错配 | 用 **M3** 替代（更稳） |
| G | CLIP 空间 cycle 可证退化 | \(E\) 对低层不变 ⟹ 梯度平坦 | **M8** 空间 cycle |
| H | 检索记忆库需可交换 gallery | 协议冲突 | **删除** |
| I | 选择偏置 + 度量偏差 | winner's curse；SSIM −0.035 | **协议锁定**（P0） |

### 2.2 SOTA 的缺陷（我们要打的缺口）

| SOTA | 取胜机制 | **它缺什么** |
|---|---|---|
| **CogCapPro** | 4 模态 CLIP 条件 + 跨模态注意力融合 → Incep 0.831 / SwAV 0.489 | **完全无空间通路**（无 CN、无 img2img init）⟹ SSIM 0.409 是从 CLIP 摘要里榨出来的极限 |
| **BrainAE** | EEG 重建损失 ⟹ 潜变量保留神经信息、防塌缩 → SSIM 0.432 / PixCorr 0.211 | 语义弱（Incep 0.753 / CLIP 0.816）；无融合 |
| **ATM** | Stage-I 先验扩散 \(p(z_I\mid z_E)\) + 模糊图 img2img | 语义弱（Incep 0.734 / CLIP 0.786） |

> **没有任何 SOTA 同时具备「可教的空间通路 + 多模态语义 + 融合」。**
> 且 CogCapPro 距全支配仅差 0.023 SSIM / 0.045 PixCorr。

## 3. 架构：NeuroWeave v3

```
EEG x (C×T)
  │
  ├─ M1 Signal Canonicalizer（保留：MVNN + 被试归一化）
  │
  ├─ M2 Task-Factorized Encoder  ← 核心新机制（修 A/B/D）
  │     ├─ 语义流  f_θ : x → z_sem         目标: InfoNCE(train gallery) + MSE→概念均值CLIP
  │     └─ 空间流  g_ψ : x → z_spa (4×64×64) 目标: L1→GT SDXL VAE latent
  │                                            + D_ψ: z_spa → x̂ (EEG 重建，防塌缩)
  │                                            + depth head: → 64×64（供 ControlNet）
  │
  ├─ M3 Per-Modality Prior Refinement  ← 修 C
  │     ε_m(z_I^t, t, z_sem) → 采样 z_I^m，m ∈ {img, txt, depth, edge}
  │     （采样而非回归 ⇒ 输出落在真实 CLIP 图像流形上）
  │
  ├─ M4 Cross-Modal Semantic Fusion  ← 修 N5
  │     跨模态注意力 {z_I^img, z_I^txt, z_I^depth, z_I^edge} → z_fused
  │     输出 5 个 IP 条件 = 4 单模态 + 1 融合
  │
  ├─ M5 Fidelity-Preserving Dual-Pathway Generation  ← 修 D/E，攻 A2 靶子
  │     SDXL + ControlNet(depth, timed) + Img2Img Init(VAE.decode(z_spa)) + IP-Adapter(fused+4)
  │     ┌ 步 [0, t1] : CN(depth) + init 主导 → 结构锁定（低 strength）
  │     └ 步 [t1, 1] : IP-Adapter 主导（late-layer 注入）→ 语义精炼
  │     ※ 层位置在此**才**成为真实的资源分配（两通路信息不同）
  │
  ├─ M6 Uncertainty Multi-Hypothesis + Render-Verify
  │     q(z_sem|x) 采样 M 候选 → 验证器选择（保留，NeuroWeave 唯一理论正确项）
  │
  ├─ M7 Score-Level Route Fusion（保留：我们独有资产）
  │     composite 多层级目标 + 路由 bank + CSLS；Sinkhorn 仅作转导式次要指标
  │
  └─ M8 Spatial Cycle Consistency  ← 修 G
        生成图 → VAE encode → 与 z_spa 比较（等价类小 ⇒ min cycle 与保真同向）
        用途：**验证/选择**，不作损失
```

### 删除项（附理由）

| 删除 | 理由 |
|---|---|
| 层级因果时序编码器 | 无理论依据，不触及 N1–N5 |
| 检索记忆库 | 缺陷 H：协议冲突 |
| CLIP 空间 cycle 作损失 | 缺陷 G：可证退化，方向反对齐 |
| 层位置作独立贡献 | 缺陷 E：span 内重参数化（实测 ±0.018/±0.027） |
| `hier_aux` 层级监督 | 两轮实验均证伪 |

## 4. 训练阶段

| 阶段 | 内容 | 目标函数 | 依赖 |
|---|---|---|---|
| S1 | 任务因子化编码器 | \(\mathcal L=\lambda_1\mathcal L_{\text{InfoNCE}}(z_{\text{sem}})+\lambda_2\|\hat z_{\text{sem}}-\bar c\|^2+\lambda_3\|z_{\text{spa}}-z_{\text{VAE}}\|_1+\lambda_4\|\hat x-x\|^2\) | `fit`/`val_b` |
| S2 | 各模态先验精炼 | 潜嵌入空间扩散：\(\|\epsilon-\epsilon_\theta(z_I^t,t,z_{\text{sem}})\|^2\) | **训练概念** |
| S3 | 跨模态融合 | SCM-Loss（相似度 top-k 掩码 + 类别掩码） | 训练概念 |
| S4 | 生成接口 | strength / CN timing 扫描 → 可选 LoRA + **保真损失** \(\lambda\|{\rm LPF}(I_{\text{gen}})-I_{\text{low}}\|\) | S1–S3 冻结 |
| S5 | 测试时 | M 候选 + render-verify 选择；空间 cycle 作验证项 | 全部冻结 |

## 5. 分阶段验证与 Kill Criteria

**每一步都可独立判死，且前两步几乎零成本。**

| 步骤 | 动作 | 通过判据 | Kill 条件 |
|---|---|---|---|
| **V0** | 测 init 模糊图的**语义**指标（Incep/CLIP/SwAV/Alex2/5） | 得到保真-语义权衡曲线的下端点 | 无需 kill，纯信息 |
| **V1** | strength / CN timing 扫描（1 个作业） | 存在点使 PixCorr ≥0.211 **且** SSIM ≥0.432 | 保真-语义前沿无法同时越过两条线 ⟹ M5 单独不足，必须靠 M2 |
| **V2** | 先验精炼落流形（测量 MMD 距离下降） | 条件到真实 CLIP 图像嵌入的 MMD 下降 ≥50%，Incep ≥+0.05 | MMD 不降 ⟹ M3 无效，IP 条件维持原始嵌入 |
| **V3** | 跨模态融合 | Incep ≥0.80 且 SwAV ≤0.52 | 无增益 ⟹ 缺口不来自 N5，重估 |
| **V4** | 任务因子化（z_spa 的 EEG 重建 + 回归锚定） | 检索 raw Top-1 不降 **且** 保真保留率 +10pp | 检索下降 ⟹ 因子化损害语义，退回单流 |
| **V5** | 联合（M2+M3+M4+M5） | **Pareto 支配**：≥5/7 项不劣于所有 SOTA，且 ≥3 项严格优 | 未达 ⟹ 重新评估支配目标 |

**全局 Kill（项目级）**：若 V1 + V2 + V3 全部通过但 V5 仍非支配，则说明缺口来自我们未识别的第三类机制，应停止增量调优、重做归因。

## 9. 论文主张（不需要 7/7 全赢）

> **主张**：注入侧干预（层位置、分层、一致性、记忆库）在理论上被界定为**重参数化**——
> 由我们自己的预登记实验定量（±0.018/±0.027，远小于机制级 ±0.109/±0.200），
> 且表现为**一升必一降**（ Pareto 前沿指纹）。
> **推论**：前沿扩张的**必要条件**是提升条件的信息量与维数，而非改变其使用方式。
> **实例化**：任务因子化潜变量 + 语义/结构**双物理通路** + 逐模态先验精炼 + 跨模态融合，
> 在保持低层保真度的同时补齐语义，实现**Pareto 支配**。
> **副产品**：语义通道 oracle 上界测量（含类名条件达 Incep 0.912 / CLIP 0.945）、
> 未被利用的空间通路容量界（0.2998/0.4997）与生成阶段的销毁率量化。

**最强的部分是负结果的定量界 —— 不要丢弃被证伪的假设。**
