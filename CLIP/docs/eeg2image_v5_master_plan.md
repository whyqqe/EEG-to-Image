> 本文是**唯一有效的行动方案**，取代 `eeg2image_v5_plan.md` 的 §3–§4 路线部分。
> 依据：本项目全部实测（v3.2 → v4 → v5 G0/G1b），以及检索 SOTA（SCORE / SVTL / SAMGA）
> 被验证过的设计经验。凡与本文冲突的旧文档结论，以本文为准。

## 0. TL;DR

**最重要的结论**：v5 的支柱 A（"可微部署算子入环"）**已被验证有效**——
raw cosine `21.17 ± 1.26 → 26.67 ± 1.15`（**+5.50pp**，**3/3 seeds 逐 seed +5.0/+5.5/+6.0**）。
这是本项目第一个可信的大幅增益，且已**超过 SAMGA 官方 sub-08 基线**（final 22.00 / best 25.00）。

**但它的机制与我预登记的不同**（§2.4）：它不是"把校准训进网络从而不再需要校准"
（后验 CSLS 余量反而从 +1.83 放大到 +2.67），也不是"降低被试特异性"
（训练/留出被试差反而从 +22.83 放大到 **+31.22pp**）。它让**见过的被试**大涨 +13.4pp、
留出被试只涨 +5.0pp——即**整体成为更好的概念解码器，迁移只兑现一部分**。

**因此最优路径不是换架构，而是**：
1. 沿**已验证**的"可微算子入环"族纵深（A1 → **A2**），因为 SCORE 用同一招把 26.22 做到 53.23；
2. 攻**唯一没被任何杠杆动过、且被 A 放大**的瓶颈——被试差 +31.22pp（支柱 B 与 D2）；
3. 攻**第一限制项**——单试次噪声（支柱 C）；
4. 最后才 10 折，且在此之前不锁死任何旋钮。

## 2. 靶子、协议边界与叙事纪律

### 2.1 两个赛道，**不许混谈**

| 赛道 | 定义 | 对标 |
|---|---|---|
| **T1 编码器** | 不依赖目标被试任何数据；只报 raw cosine | SAMGA 34.4 / SVTL 无适配 35.3（**10 折**） |
| **T2 transductive** | 用目标被试**无标签试次**统计量（SMN / SAW / CSLS / 坐标恢复 / SVTL 式精修） | SVTL+精修 48.1 / **SCORE 53.23** |

SMN、CSLS、白化、恢复、精修**全部属 T2**：不违反严格 LOSO（不用标签、不用身份），
但**不违反 ≠ 可以混报**。T1 数字必须单独给，且必须写进论文。

### 2.2 标尺纪律

* **本折诚实标尺 = 22/25**（SAMGA 官方 sub-08），不是 34.4，更不是 53.23。
  后两者是 **10 折**数字，单折数字**不得**与之并列。
* **最终可比性只能由 10 折 × 3 seeds 提供**（§4 G3）。在此之前所有结论都是单折的。
* **低于 2pp 视为噪声**（3 seeds × 1 折 × 200 query，SD 1.2–3.3pp）。
  不要报 1 trial = 0.5pp 的"改进"。

### 2.3 叙事纪律（G1b 的直接后果）

A1 有效，但**不能**用它讲"训练/部署度量对齐"。两条机制预测都被证伪（§0）。
论文里必须写成：

> "在 CSLS 修正后的相似度上训练，起到**抑制 hub 捷径、迫使编码器学习更具判别性的特征**
> 的作用；它同时提升了所有被试的可解码性，但**迁移收益小于同被试收益**，因此
> **不构成被试不变性机制**。"

这个措辞是数据支持的；反之的措辞是数据否定的。

### 2.4 预测证伪记录（保留，作为方法纪律）

| 预登记 | 实测 | 判定 |
|---|---|---|
| A 使 raw 上升 | 21.17 → 26.67 | 成立 |
| A 使后验 `+CSLS` 余量 →0 | +1.83 → **+2.67** | **证伪** |
| A 使训练/留出被试差缩小 | +22.83 → **+31.22** | **证伪** |

**教训**：G1b 的价值一半在于 +5.50pp，另一半在于它**否证了**"度量对齐"这一叙事，
从而把资源指向真正的缺口（被试差）。预登记 + 探针这套机制是有效的，继续用。

## 3. 最优组件栈（按证据分级）

### 3.1 保留（已测量有效，构成本方案主干）

| 组件 | 配置 | 依据 |
|---|---|---|
| **SMN**（C2） | `smn.enabled: true, init_gate: 0.0` | 唯一承重的传统组件；关掉 raw 12.5 |
| **A1：CSLS 入环** | `recovery_aware: {enabled: true, block_per_subject: false, csls_k: 10, terms: [img, cross]}` | **+5.50pp，3/3 seeds** |
| **训练协议** | `lr: 1e-3`、`schedule.freeze_encoder_stage2: false`、50 epoch、coarse-to-fine 0.9→0.5 | **+5.34pp** |
| **目标准则** | `img 1.0 / cross 0.7 / mmd 1.0 / router 0.05`，其余 0 | `img`+`cross` 占梯度 44.8%/32.3%；`cross` 文献 +2.23pp |
| **对齐宽度** | `d_latent: 64, d_align: 64` | 概念流形实测 16 维；64 是 4× 余量 |
| **目标栈** | 5 层 `routed` + 负熵 router 奖励 | 防退化成单层（实测会塌到 [0.74,0.13,0.04,0.01,0.07]） |
| **前端** | MVNN `train` | 协议基线 |

**主臂配置已存在**：`configs/loso_sub08_v5_rat_csls.yaml`。

### 3.2 删除（已测量无效/有害，不要带进主臂）

`share_head_hidden: 0`（C1）、`loss_weights.spec: 0.0`、`recovery_aware.block_per_subject: false`、
`dec / proto / rkd / adv / reg` 全 0、post-hoc `coordinate_recovery`（T2 里也不开）。

### 3.3 新增（按**期望价值 / 成本**排序，这是路线图的依据）

| 优先级 | 组件 | 针对 | 为什么值 | 成本 |
|---|---|---|---|---|
| **P1** | **A2：完整 recovery-aware（可微坐标恢复入环）** | 度量错配 | SCORE 用**同一招**把 26.22 → **53.23**；我们刚验证了该族有效（A1 +5.5），A2 是它的**完整版**。这是**文献里最大的单个杠杆** | 中高（Procrustes/互近邻需可微化） |
| **P2** | **D2：卷积前端**（`Conv2d(1,40,(1,25))+AvgPool(1,51),(1,5)`） | **被试差** | `Linear(250→200)` = 每通道 5 万参数、**无局部性先验 → 易拟合被试特有模式**（v4 §3.8 自己的判断）。换成显式低通+下采样是**移动假设类**（P3 原则），直接攻主导缺口 | **低**（改一层） |
| **P3** | **B：逐被试 Gram 结构性对齐** | **被试差** | `cross` 是软的，解集合里仍含被试特异结构（pre-SMN 被试识别率 **40.25%**）。改为把每个被试的概念 Gram 匹配到**同一个冻结图像 Gram**——有锚，**不会塌缩** | 中（复用 `gram_distill_loss`） |
| **P4** | **C：多试次视图** | **噪声（第 1 瓶颈）** | `CrossSubjectBatchSampler.images_per_pair>1` 已支持；把重复试次变成正样本。**基础设施**：全量缓存 R=4 维需 37.5GB——`/project` 实测 **2.7PB 可用**，可缓存 | 中（数据管线） |
| **P5** | **A1 的 listwise/排序扩展** | 度量错配 | A1 本质是"hub 加权难负样本"；显式 ranking loss（SoftTop1/ListNet）是把同一洞察写到极致 | 中 |
| **P6** | **T2：SVTL 式免训练精修** | 部署 | 文献 35.3 → **48.1（+12.8pp）**，本项目**完全未使用**的 ≥10pp 量级杠杆 | 中 |

### 3.4 明确**不做**（附理由，防止反复）

* **换骨干**（SAMGA DBConformer / ViEEG / CSBrain）：v4 §3.8 实测骨干非瓶颈（两云 16 维子空间
  重合 94%、源端 loss 已解出、加宽聚合器掉分）。**唯一例外是 D2**（前端**归纳偏置**，不是容量）。
* **加宽容量 / 更强增广**：已测为负。
* **post-hoc 坐标恢复**：上界 ≤ 仅中心化。

## 4. 执行路线图与闸门

> **每个闸门是"是否继续"的判据，不是进度报告。** 每阶段**只改一个组件**（v4 的教训：
> lr+冻结+spec 三条同动 → 无法归因，多花了一轮 2×2）。先跑 sub-08 单折 **3 seeds**。

| 阶段 | 内容 | 通过判据 | 不通过 |
|---|---|---|---|
| **P0**（已完） | G0 卫生 + G1b（A1） | raw ≥ 22 → **26.67 ✓** | — |
| **P1** | **A2 完整 recovery-aware** | raw ≥ **30** 且 T2 内 `+recovery` 余量收缩 | 记录负结果，A 停在 A1 |
| **P2** | **D2 卷积前端**（叠在 A1 上） | raw ≥ **28**；**且 pre-SMN 被试识别率下降** | 记录，回退前端 |
| **P3** | **B 逐被试 Gram**（叠在 A1 上） | raw ≥ **28** 且 **被试差从 +31.22 下降** | B 降级，转 B2（Sinkhorn/OT） |
| **P4** | **C 多试次视图** | 试次数效应可见；raw 上升 | 记录 |
| **P5** | P1–P4 通过者**合并** | raw ≥ **32** | 停在本折 |
| **G3** | **10 折 × 3 seeds**（final + best 同报） | 与 34.4 / 35.3 **同口径**可比 | — |
| **G4** | **T2 赛道**：SMN + CSLS + 精修 + A2 | 向 48.1 / 53.23 | 明确声明只在 T2 竞争 |

**三项回归探针必须在每个臂上跑**（本轮已写好）：
① 逐被试 raw（训练 vs 留出之差）；② pre-SMN 被试识别率；③ 跨被试概念几何（500-way）。
**它们比单一 Top-1 更能定位回归**——G1b 就是靠 ② 才发现"涨了但不是靠不变性"。

**硬性纪律**
1. 每阶段**一个**组件。
2. < 2pp 视为噪声。
3. **失败必须记录**，不许静默删掉（A 的两条证伪已写进 §2.4）。
4. **改任何 config 默认值，必须钉住所有已记录的臂**（v5 G0 差点让 7 个臂静默换架构）。
5. 训练脚本必须打印完整 config；checkpoint 走 `prune_epoch_checkpoints`。

## 5. 为什么是这个顺序（杠杆排序的推导）

```
已测量有效:
  G0 卫生            +5.34pp   ← 已吃满，无空间
  A1 CSLS 入环        +5.50pp   ← 已吃满；A2 是它的完整版
未动过、且是最大缺口:
  被试差 +31.22pp    ← 全部杠杆都动不了它（A 甚至放大它）
  单试次噪声（2×）    ← 没人碰过
```

**推论**：
* 继续在"度量对齐"上加深（A2）是**便宜的**，因为 A1 已证明该族有效，且 SCORE 已证明上限很高。
* 但**SOTA 差距的主体在被试差**，而它**从未被任何杠杆动过**。因此 P2/P3 必须做，
  且预登记读数要直接看被试差/被试识别率，而不是只看 Top-1。
* **C（噪声）是第 1 瓶颈**却排在 P4，只因为它需要数据管线改动；它是**唯一能同时改善
  所有被试**的杠杆（噪声对留出被试同样存在），所以长期价值最高。

**预期组合**：A2 + D2 + B 三者机制互补（度量 / 假设类 / 目标），C 独立作用。
若 P1–P4 都过，raw ≥ 32 是可达的，届时 T1 赛道的 10 折数字才有资格与 34.4/35.3 并列。

## 6. 风险

| 风险 | 应对 |
|---|---|
| **A2 的坐标恢复不可微 / 不稳** | 分档实现：Procrustes(identity init) 可微 → 互近邻伪标签用 stop-grad → 逐轮更新。先只对 T2 生效，T1 数字不受污染 |
| **A1 的 +5.5pp 在 10 折上不成立** | sub-08 是特定难度折。**P5 后立刻 G3**，不要 P1 完就投 10 折 |
| **D2 掉点**（卷积先验在 63×250 上可能过强） | 保留残差旁路；作为**单项消融**，掉了就回退 |
| **B 的 Gram 匹配被 `img` 吸收**（两者本就同向） | 预登记读数 ②（被试识别率降但 raw 不涨）即为该情形 → B 降级 |
| **C 的显存/IO** | `/project` 2.7PB 可缓存 37.5GB；但**先量 `--mem`**，`images_per_pair>1` 会放大 batch |
| **又一次"4.5pp 级 bug"** | G0 的 smoke test + 探针已固化；新组件都要加保真度断言（照 `csls_correct` 的做法） |
| **QOS 超投** | 上限 8 运行 / 10 提交。每阶段 ≤ 3 臂 × 3 seeds 时分批提交 |

## 7. 与 SOTA 对齐：如何**合法**地声称

1. **本折先说本折的话**：在 sub-08 单折，raw 26.67 ± 1.15 **已超** SAMGA 官方 sub-08（22.00/25.00）。
   这是一句**可以**说的话，但必须限定"单折、非文献口径"。
2. **T1 的正式声称必须等 G3**（10 折 × 3 seeds，final + best 同报）。
3. **T2 单列**，且逐项列出用了哪些 transductive 算子。
4. **绝不**把 53.23 当作我们单折的目标；它是 SCORE 在 10 折 + recovery-aware 训练下的数字。
5. **失败与证伪也进论文**（§2.4）——这是本方案与"调参记录"的区别。

## 8. 立即可执行的第一步

`P1 (A2)` 之前有一个**必须先做**的便宜前提（否则 A2 的方向是猜的）：

**A1 的最小归因消融**（4 臂 × 1 seed，8 job，一轮跑完）：

| 臂 | 配置 | 要回答 |
|---|---|---|
| a | `enabled: true, csls_k: 10, terms: [img, cross]` | 基线（= 已知 26.00） |
| b | `terms: [img]` | 效果来自 img 还是 cross？ |
| c | `terms: [cross]` | 同上，互补 |
| d | `csls_k: 5` / `20` | k 是否敏感（决定 A2 是否要自适应 k） |

**为什么必须**：A2 是把**更多**算子放进环里。如果 A1 的效果其实来自某一项或对 k 极端敏感，
那么 A2 的设计（哪些算子、什么邻域大小）就必须据此调整，否则会在错误的方向上加码。

**判据**：若 b/c 中某项单独就能复现大部分 +5.5pp，A2 只需沿那一项扩展且更便宜；
若对 k 敏感（|Δ| > 3pp），A2 必须内置自适应 k。

> 说明**领域内有 ~5pp 的复现落差**。本表只用于定位机制缺口，不用于声称排名。

### 10.2 最重要的发现：**SCORE = 我们的 v5 方案，但我们只做了一半**

SCORE 的构成：
1. **训练端**：recovery-aware 源域训练 + **source-only 回合**（把某个源被试临时当作目标，**隐藏其 EEG–图像配对，
   先施加部署时的恢复流程，再揭晓标签算 loss**）；
2. **部署端**：CSLS hubness 校正匹配 → 加权伪地标 → **正则化正交坐标映射**，两个编码器冻结。

我们做了什么：**只有 (1) 的一半**——可微 CSLS 入环（A1，+5.50pp）。
我们 **没有** 做 source-only 回合，也 **没有** 做部署端正交坐标恢复。

**这解释了我们的 D1 为什么失败。** 我们早先试过 post-hoc 坐标恢复（无效，上界 ≤ 仅中心化）。
按 SCORE 的设计，**恢复算子必须与编码器联合训练**；在没有为此训练的编码器上事后套一个，
正是 SCORE 的消融会预测失败的用法。**我们不是方向错了，是执行方式错了。**

**SCORE 的洞见与我们独立测到的完全一致**：SCORE 说"不同被试保留相似的概念关系，但沿不同坐标方向表达"；
我们在 `probe_cross_subject_geometry.py` 独立测到跨被试概念几何 21.4% vs chance 0.20%，
在 `probe_per_subject_accuracy.py` 测到被试差 +22.83/+31.22pp。**同一个诊断，但 SCORE 动手了。**

**缺口量级**：SCORE 相对其未适配基线 +17.45pp；我们从训练端只拿到 +5.50pp。**差的 ~12pp 就是"恢复被联合训练"。**

### 10.6 一条重要的方法学教训

我们在**不知道 SCORE 存在**的情况下，独立测出了它的核心前提（相似概念关系 + 不同坐标方向），
也独立走上了它训练端的半条路（可微 CSLS 入环）。这说明**我们的诊断能力是够的**——
缺的不是洞察，而是**把恢复算子与编码器联合训练**这一步的执行。

**因此本阶段的搜索成本应主要花在"SOTA 是怎么把一件事做完整的"，而不是"还有什么新点子"。**

## 11. 部署栈实测（2026-10-04）——**恢复是主升杠杆，结构专家不成立**

### 11.1 核心结果：SCORE 的部署端恢复，在**未联合训练**的模型上就有效

`--recovery` 此前从未在任何 v5 评估里开过。补测两个最佳 checkpoint（sub-08 单折，final epoch）：

| rung | v5-rat-csls | **v5-a1-k20** |
|---|---|---|
| raw cosine | 26.00 | 27.00 |
| + CSLS | 31.00 | 34.00 |
| + centre + CSLS | 31.00 | 32.50 |
| + whiten + CSLS | 28.50 | 31.50 |
| **+ whiten + CSLS + recovery** | **30.50** | **35.50** |

`v5-a1-k20 + recovery = **35.50**`（相对 raw +8.50pp，**完全不需要重训**）。

**对标**：

| | Top-1 |
|---|---|
| SAMGA 官方 LOSO | 34.4 |
| SVTL 无适配 | 35.3 |
| **v5-a1-k20 + recovery（本折）** | **35.50** |

恢复 diag：`n_mutual_pairs 110/115`、`landmark_rate 0.55/0.58`、`abstained false`。
**没有触发弃权门，说明伪对应地标是可信的。**

> 这**证实 §10.2 的判断**：SCORE 的部署端恢复就是缺的那一半。
> 而且它比预期更强——**无需联合训练就已生效**（联合训练应再叠加，见 §12 P1）。

### 11.2 结构专家（SATTC）：**实测不成立，放弃**

实现于 `calibration.structural_scores`（互近邻 + 双向 top-k + 热度惩罚，z-score 加权融合）。
首次无权重融合**灾难性掉分**（35.50 → 18.00）：两个专家的数值尺度不可比，
改 z-score 后暴露真实信号强度：

| 帧 | base | λ=0.02 | λ=0.05 | λ=0.1 | λ=0.15 | λ=0.3 |
|---|---|---|---|---|---|---|
| v5-a1-k20 whiten | 31.5 | 32.0 | **32.5** | 31.5 | 30.0 | 25.5 |
| v5-a1-k20 recovery | **35.5** | 35.5 | 35.0 | 33.5 | 32.5 | 31.0 |
| v5-rat-csls whiten | 28.5 | 28.5 | 27.5 | 27.0 | 27.5 | 25.5 |
| v5-rat-csls recovery | 30.5 | 31.5 | **32.5** | 31.5 | 31.0 | 24.5 |

**判定**：最大增益 +1.0pp，**在 ±1.75pp 噪声带内**；且在**最强臂上无增益**（35.5→35.5）。

**原因（诊断）**：`mutual_topk_enrichment` 只有 **6.7–8.2×** chance
（率 0.0168–0.0214 vs chance 0.0025）。即 200 个真配对对应约 800 个互近邻候选，
精确率约 25%——比随机好，但不足以压过几何项。

**结论**：`lam=0`（纯几何 + 恢复）为最优。**SATTC 的增益在我们的折和 checkpoint 上不复现**，
与「<2pp 视为噪声」的纪律一致。保留 `structural_scores(lam=...)` 作为可复现的负结果，
**不进主臂**。

## 12. 最终方案：三条已验证杠杆 + 我们的创新点

> 本节是**行动方案定稿**，取代 §4 的 P1–P6 与 §10.5 的修订优先级。

### 12.1 一条被实验扭转的科学结论（这是我们的核心创新）

本项目早先测过 post-hoc 坐标恢复并判定"无效"，理由是
`probe_signal_weights.py` 测到**带着标签**的 oracle 逐维 SNR 最优加权
（21.0/20.0/19.5）**落在或低于**仅中心化（20.0/22.0/20.5）。
由此推断"整个坐标家族的上界 ≤ 平移"，并写进了 `calibration.py` 的文档头。

**这个推断被 §11.1 推翻。** 同一个坐标家族（含 CSLS 与正交恢复）在
`v5-a1-k20` 上把 27.00 抬到 **35.50（+8.50pp）**。

**为什么两者都成立**：oracle 上界是在一个**从未为可恢复性训练过的编码器**上测的。
那样的编码器的概念方向是**任意**的，任何正交映射都无法把它对齐到目标——所以上界低，
是**编码器的性质**，不是**坐标家族的极限**。

> **结论（可写进论文）**：**"post-hoc 校准的 oracle 上界"不是"联合训练下的上界"。**
> 一个坐标变换家族的收益取决于编码器是否被训练成可恢复的；在未训练的编码器上测出的
> 上界会**系统性低估**该家族在恢复感知训练下的价值。这是一条可复现、可证伪、且
> 与我们自己的失败记录一致的发现。

### 12.2 三条已验证的杠杆（都带 3 seeds 或机制证据）

| **L3 训练协议修正**（lr 1e-3 + 不冻结） | 15.83 → 21.17（**+5.34pp**） | v4 消融矩阵 |

### 12.4 我们的创新点（相对 SOTA 的差异化）

**① 可微部署栈入环（generalized recovery-aware training）**
SCORE 把 CSLS + 恢复放进训练环。我们已有**逐位一致于部署实现**的可微 CSLS
（max|Δ| 4.0e-7，转置一致），现在又加上**可微正交恢复 + source-only 回合**
（`samclip.losses.recovery`，7 项机制断言全绿）。下一步是把**整条无标签部署栈**
（白化 + CSLS + 恢复）都做成可微模块——SATTC 与 SCORE 都把手设计的那部分留在测试时。

**② 诊断驱动协议（三项回归探针）——我们的方法学贡献**
`probe_per_subject_accuracy`（训练 vs 留出被试差）、
`probe_concept_vs_subject_variance`（pre-SMN 被试可辨识性）、
`probe_cross_subject_geometry`（跨被试概念几何 vs chance，500-way）。
**这套探针是发现"L1 的 +5.50pp 不是被试不变性"的唯一手段**（被试差反而 +22.83→+31.22）。
多数论文只报一个 Top-1；我们用探针把"表示质量"与"被试迁移"分开，
**这是本方案能与"调参记录"区分开的地方**。

**③ 对"上界"的方法学批判（§12.1）**
一条可复现的科学结论，且由我们自己的失败记录导出。
