# EEG→Image v4：架构诊断与重新设计（Subject-as-Modality）

> 立项依据：v3.2 三臂 × 三种子实验的结论是"瓶颈是泛化差距，不是容量"。
> 本文回答更进一步的问题：**这个泛化差距是架构性的吗？如果是，哪种架构能真正冲击 SOTA？**
> 约束：只保留一条思想——**把不同被试当作不同模态来对齐**。骨干、目标、损失、协议都可重设计。
> 日期：2026-10-03。测量脚本：`scripts/probe_subspace_alignment.py`、`scripts/probe_signal_weights.py`、`scripts/probe_embedding_scale.py`。

---

## 0. TL;DR

**是，架构有问题。** 而且不是"调参不够"——是三个**可测量、有机制**的结构性缺陷。同时，项目当前的组织性信念（"最大杠杆在测试时坐标变换"）被测量推翻。

四个决定性测量（全部在 sub-08 折、三个种子上重复）：

| # | 测量 | 结果 | 含义 |
|---|---|---|---|
| A | 子空间扫描 | r=16 已含 93–96% 方差；EEG 与图像两个 16 维子空间重合 90–94% | **不是维度不够**，检索所需的几何在 16 维里，而且是对齐的 |
| B | 对角度量族 oracle（用标签求 SNR 最优逐维权重） | **21.0 / 20.0 / 19.5** | 白化 / CSLS / 坐标恢复 / 任何学习式映射的**整个家族**的**上界** |
| C | 该族内免标签的最简成员：仅"减查询均值" | **20.0 / 22.0 / 20.5** | **oracle ≤ 减均值**（3 个种子里 2 个）。二阶结构里**已经没有可利用的东西** |
| D | 全局对齐 oracle（给 199/200 个标签） | 线性 LOO 峰值 **17.0**；MLP LOO **6.0 / 4.5**；拟合点 **100%** | 任何全局对齐头（线性或非线性）都是纯过拟合，**Axis 2 已被彻底关闭** |

三个缺陷：

- **D1（位移）** EEG 嵌入云存在一个**几乎与 gallery 位移正交**的被试位移：`‖mean(q)‖/mean‖q‖ = 0.27–0.42`，而图像云只有 0.21–0.24，且 `cos(mean_q, mean_g) ≈ +0.1`。移除它是**单个最大的已测杠杆**（+6.5/+4.5/+2.5 pp）。参考架构结构上不会产生它（其最终映射**跨模态权重共享**，见 §2.5），我们的架构结构上必然产生它（`eeg_head` / `img_head` 是**两个独立**的带 bias 线性层，且 EEG 通路上**没有任何归一化**）。
- **D2（度量家族已空）** 测试时几何校准这条路**已经走完**。这直接修正项目文档里那句话——"最大杠杆是坐标变换，不是架构"。正确说法是：最大杠杆是**平移**，而平移是架构**本来就不该需要的**东西；而坐标变换家族（白化、CSLS、Procrustes、任何映射）在**当前表示**里**没有剩余空间**。
- **D3（目标太容易被满足）** 源端 `img` loss 已"解出"（3.54 < 参考的 3.87），而 raw 测试 Top-1 只有 16%。同时 VICReg 的 variance 铰链在**全部 512 维上均匀施压**（0/512 维达到 std 1.0，逐维 std 的 cv = 0.127），即对一个信号只占 16 维的表示施加永久的、均匀的"向外充气"力——它永远赢不了（范数有界），却持续占着编码器 18.8% 的梯度。

**重新设计的三条原则**（§3）：① 让位移/风格成为**显式的、构造上概念盲的**统计量并在**前向通路内**移除，而不是靠软不变性惩罚；② **训练时就在部署度量里**（后验映射已被 D 关闭）；③ **移除目标不需要的自由度**（16 维信号不该有 512 维去藏）。

## 1. 判定：架构确实有问题

### 1.1 测量 A — 容量与维度都不是瓶颈

`probe_subspace_alignment.py` 对查询集做无标签 PCA：

| r | EEG 方差占比 | 图像方差占比 | 图像方差落在 EEG 基里 | EEG 方差落在图像基里 |
|---|---|---|---|---|
| 8 | 0.78–0.80 | 0.77–0.79 | 0.63–0.65 | 0.64–0.66 |
| **16** | **0.93–0.96** | **0.98** | **0.94** | **0.91–0.93** |
| 32 | 0.98–0.99 | 1.00 | 0.98 | 0.95–0.99 |
| 199 | 1.000 | 1.000 | 0.999 | 0.99 |

**两个云的支配子空间都是 16 维，而且相互重合约 94%。** 这一点必须先确认，否则后面的推断会错：我最初的担心是"用查询集主方向投影 gallery 会毁掉 gallery"，那样低分会被误读成"表示差"。测出来重合 0.94，所以这个担心不成立，投影是合法的，而且它顺带证明**对齐本身没坏**——EEG 的 16 个主方向确实指向图像的 16 个主方向。

结合 v3.2 已测的：有效秩 9.5（dims@99% = 24）、聚合器秩上限只用掉 18.8%、**加宽聚合器（`cap` 臂）反而 −4.83 pp**——容量与维度都排除了。

### 1.2 测量 B/C — "测试时几何校准"这条路已经走完（且被误述）

这是最重要的一节，因为它推翻项目文档的组织性信念。

`calibration.saw_whiten` 做两件事：**减均值** 与 **按协方差逆平方根缩放**。项目的叙述把 +5 pp 全部归给后者（"subject-adaptive whitening"，docstring 通篇讲协方差秩亏）。两者从未被分离测过。分离后（`probe_signal_weights.py`，三个种子）：

| 度量 | 2025 | 2026 | 2027 |
|---|---|---|---|
| raw cosine | 13.50 | 17.50 | 18.00 |
| 仅中心化**查询** | **20.00** | **22.00** | **20.50** |
| 仅中心化 gallery | — | 16.50 | 17.00 |
| 中心化两者 | 20.50 | 21.00 | 22.00 |
| `saw_whiten` shrink 扫描最优 | 19.50 | 21.50 | 24.50 |
| **oracle：`w_j = ρ_j²/λ_j`（用标签）** | **21.00** | **20.00** | **19.50** |

三条件事实：

1. **仅减查询均值就拿到了几乎全部增益**（+6.5 / +4.5 / +2.5 pp）。
2. **协方差部分最多再加 ~1 pp**，且在 3 个种子里 2 个上最优 shrink 只是打平或更差。真正的白化（`w=1/√λ`）本身是**破坏性**的——是 `shrink`/`max_cond` 在救它。
3. **oracle 最优对角权重 ≤ 仅减均值**（2/3 个种子）。`w_j = ρ_j²/λ_j` 是逐维信噪比最优权重，白化 `1/λ_j` 是"假设每维 ρ_j² 相同"的特例。所以 oracle 界定了**整个对角重加权家族**——白化、CSLS 的局部缩放、基于协方差的一切被试适配——的上界。**这个上界不比"减个均值"高。**

> **修正**：`calibration.py` 开头那句 "The largest single lever in this problem is a change of coordinates, not an architecture" 是**错的**。最大杠杆是**平移**，而平移是架构不该需要的东西。坐标变换家族在当前表示里**没有剩余空间**。这条修正决定了重新设计的方向：不是"做更好的校准"，而是"让架构不需要校准"。

顺带一个正面结果（`probe_signal_weights.py` 的分带表）：**38.9–41.2% 的查询方差是概念共变的**，且分带很干净——

| 分带 | λ 占比 | ρ² 均值 | λ·ρ² 占比 |
|---|---|---|---|
| dims 1–4 | 0.54–0.56 | **0.51–0.57** | 0.30–0.33 |
| dims 5–16 | 0.39–0.41 | 0.14–0.15 | 0.08 |
| dims 17–64 | 0.04–0.06 | ~0.006 | ~0.001 |
| dims 65+ | ~0 | ~0.005 | ~0 |

**高方差方向就是概念方向**（前 4 维 ρ²≈0.5：该方向上一半方差由对应图像目标的坐标解释）。所以问题**不是**"方差排序与信号排序错位"。这也解释了为什么 1.2 里那种"白化放大尾部"的直觉是错的。

### 1.3 测量 D — Axis 2（映射）已被彻底关闭

`probe_subspace_alignment.py` 第三节。给**其余 199 个查询的真实标签**，拟合 `z_q → z_g`：

| r | 线性 LOO | 线性 拟合点 | MLP LOO |
|---|---|---|---|
| 8 | 12.00 | 15.00 | — |
| **16** | **17.00 / 16.50** | **29.50 / 33.00** | **6.00** |
| 32 | 14.00 / 12.50 | 44.50 / 42.00 | **4.50** |
| 64 | 9.50 / 13.00 | 70.50 / 65.00 | — |
| 199 | 6.50 / 5.50 | **100.00 / 98.50** | — |

读法：**r=199 时全局线性映射把 200 对完美拟合（100%），换一个 query 就掉到 6.5%——低于 raw cosine 的 13.5%。** r=16 时线性 LOO 峰值 17.0，**低于免标签的 20.0–22.0**；MLP（非线性）LOO 只有 6.0/4.5，比线性更差。

自由度账：d_embed² ≈ 262k 个参数 vs 200 个样本；而信号在 16 维里只有约 256 个真实自由度。**估计问题被过度参数化约 1000 倍**，任何映射估计器的方差都压过信号。这也解释了项目此前的记录：坐标恢复在本地是**掉分**的（29 → 28）。文献里 SCORE 的 53.23 来自 **recovery-aware 训练**，不是 post-hoc recovery —— 这个区别是决定性的（见 §2.3、§3.5）。

### 1.4 测量 D1 — 位移的量级与正交性

| | 2025 | 2026 | 2027 |
|---|---|---|---|
| `‖mean(q)‖ / mean‖q‖` | 0.415 | 0.265 | 0.298 |
| `‖mean(g)‖ / mean‖g‖` | 0.205 | 0.235 | 0.218 |
| `cos(mean_q, mean_g)` | +0.098 | +0.144 | +0.115 |

**EEG 云的位移是行范数的 27–42%，而图像云只有 21–24%，且两者近乎正交。** 距离 200-way 检索的绝对尺度：cosine 上恒定的不匹配位移会给每个 gallery 项加一个**只依赖 j 的偏置**——这正是 hubness。所以"减查询均值"和 CSLS 是同一件事的两个视角，而前者更强（CSLS 只给 +3 pp）。

### 1.5 参考基线的真实水平（必须先校准期望）

`eeg-retrieval` 里是 SAMGA 官方代码（`third_party/SAMGA`）。`run_samga_official_baseline.sh` 用其 `inter.sh` 的完整参数列表、只跑 sub-08 折，在**我们的数据**上：

结论：**加上校准后我们已经落在参考线上（21.5 vs 22.0）**；差距全部在 "raw 就够好" 这件事上——参考 raw 22.0，我们 raw 16.33，而我们需要一次平移才到 20.5。

## 2. 理论：为什么现有架构**必然**失败

### 2.1 形式化

设概念 `c ∈ [C]`、被试 `s ∈ [S]`、图像槽 `j ∈ [10]`。数据 `x_{c,j,s}`。假设生成过程

```
x_{c,j,s} = T_s( φ(c, j) ) + n_{c,j,s}
```

`φ` 是跨被试共享的概念信息映射，`T_s` 是被试特有的观测算子。我们要 `f` 使 `f(x) ≈ ψ(c)`，部署时用 cosine 对冻结的图像目标 `g(c)`。

两个**独立**的失败轴：

- **Axis 1（分解）**：`f(x)` 必须把 `c` 从 `(s, j)` 里分出来。
- **Axis 2（可辨识）**：即使源端完美分解，也要知道目标被试的 `T_t` 把哪个方向映到哪里。

### 2.2 为什么软不变性惩罚解决不了 Axis 1

现有做法是往目标里加 `λ·MMD(f(X_s), f(X_s'))` 与 `λ'·HSIC(f, s)`。理论上它赢不了，原因是梯度的**竞争结构**，不是权重没调好：

- 对齐项（`img` InfoNCE，权重 1.0）对**任何**与类相关方向的梯度在源端都不为零，只要还有可分性可赚。
- 不变性项的梯度正比于 `λ`。一个"在源端 9 个被试上碰巧与类相关、但本质是被试特有"的方向，被对齐项**奖励**、被不变性项**惩罚**。源端有 9 被试 × 1654 概念，这种伪相关方向的数量极大，而权重比是 1.0 : 0.05–0.2。
- 更根本地：**软惩罚约束的是优化过程，不约束解集合**。它可以把某个方向压低，但不能从结构上禁止编码器使用它。

**实测确认**：训练后查询云的位移仍是行范数的 27–42%、且与 gallery 正交（§1.4）——即软惩罚+后验白化没有把被试结构去掉，只是把一部分搬到了可被一个线性平移消掉的形式。

### 2.3 为什么后验映射解决不了 Axis 2（自由度论证 + oracle）

任何 `z ↦ Az`（或非线性 `h(z)`）都在 512 维里估计一个约 262k 自由度的对象，样本量 200。线性 LOO 的峰值出现在 r=16（17.0），随 r 增大单调恶化（r=199 时 6.5），而拟合点是 100%。**这是估计器的方差主导区，不是偏差主导区。**

关键推论：**post-hoc 校准与"训练时就按该度量优化"不是同一件事**。
- post-hoc：编码器在度量 A（cosine）下训练，部署时换成度量 B（白化）。解码器从没见过 B，所以它可以选择一个在 A 下最优、在 B 下被破坏的表示。这正是"坐标恢复在本地掉分"的原因。
- 训练时入环：编码器在 B 下优化，于是它**必须**让 `Σ^{-1/2}z` 携带概念结构，即在 B 下有用的方向上放信息。
- 文献佐证：SCORE 的 26.22 → 53.23 来自 "无标签坐标恢复 **+ recovery-aware 训练**"，且用的是**同一个冻结的 SAMGA 编码器**。这是本任务文献里最大的单点增益，而它来自训练目标与部署度量的**一致性**，不是来自更强的后验算子。

### 2.4 为什么"更大容量"和"更强增广"必然失败（回顾）

- `cap` 臂（聚合器 128 → 512）在 3/3 种子失败（−4.83 pp）：多出来的秩被用来拟合源被试特有的空间模式。与 §2.3 同源——**目标可以在不迁移的子空间里被满足**。
- `aug` 臂在 3/3 种子失败（raw 15.00，`img` loss 停在 4.07–4.99）：强增广把**源端可分性**本身破坏掉了，模型连"解出"训练集都做不到，泛化无从谈起。
- 增广的教训是**顺序性**的：先让源端解出、再让解出的东西可迁移。参考实现用了增广（`smooth` k=5 p=0.3），但它的编码器有 `Dropout(0.5)` 和明确的低自由度前端，不需要靠增广去补。

### 2.5 为什么 D1 的位移是**架构性**的（机制）

参考实现的最终映射是 **`share_encoder` —— 同一个 `Linear(512,512)` 同时作用在 EEG 与图像两条通路上**（`train.py`: `eeg_feature_batch = share_encoder(eeg_projector(...))` 与 `build_image_teacher` 内 `mixed = share_encoder(mixed)`）。带 bias 的仿射映射会把**同一个**常向量加到两个云上，所以**它在结构上无法制造"云间位移"**。

我们的实现：

```327:331:src/samclip/models/samclip.py
        raw = self.eeg_head(self.trunk(eeg))
        z_e = F.normalize(raw, dim=-1)
        z_i = self.encode_target(target, subject_ids, training)
```

`self.eeg_head` 与 `self.img_head` 是**两个独立**的 `_head(...)`（各自带 bias，见 `_mlp`），且 EEG 通路上**没有任何归一化**。部署前的 softmax/InfoNCE 在 L2 归一化之后计算，对"整云平移"不敏感（cosine 对每行尺度不变，但对**跨行共享的**平移不是——它变成 j-only 偏置）。所以：

**架构没有任何机制阻止一个被试位移，而目标函数也不惩罚它；参考架构有（共享仿射），因此它 raw 就够好、不需要校准。** 这是 D1 的机制，也是 §3.3 的动机。

## 3. 重新设计：Subject-as-Modality v4

### 3.1 三条原则

**P1（可辨识性 / 构造性而非惩罚性）。** 不要让共享编码器去"发现"一个软惩罚管不住的无关变量。**给无关变量一个显式的、构造上概念盲的估计器，并在构造上移除它。**

一次性把 v1 的失败讲清楚，因为这决定了新设计为什么不是重蹈覆辙：v1 的 `z_s` 是一个**自由学习的被试嵌入**，目标里**没有任何东西**奖励它携带被试信息，于是"`z_s` 塌成常数"是那个子问题的**最优解**（实测同被试间 cosine 0.9999）。而**跨约 128–200 个不同试次汇总的二阶统计量**在**构造上**无法编码"单个试次属于哪个概念"——它是概念盲的**因为它是数据统计量**，不是因为它在被激励。这就是"被试是模态"这句话真正的理论内容：**模态由观测统计量定义，而不是由身份定义。**

**P2（训练即部署度量）。** §1.3 与 §2.3 说后验映射家族已空。所以二阶校正必须在**训练时的前向通路内**，编码器必须在它将被部署的度量里优化。

**P3（移除目标不需要的自由度）。** 信号在 16 维里（§1.1）。不要提供 512 维让 InfoNCE 在非迁移子空间里被轻易满足（§2.4 的两次失败同源）。

### 3.2 总览

```
                 ┌─ 被试侧（概念盲统计量，构造上移除无关变量）────────────────┐
x (B,63,250) ──► EEGTrunk ──► h (B,200) ──► share_head ──┐                    │
                                                          │  z (B, d_align)    │
                                              SMN(z, s) ───┘  ← 减被试均值(+可选逐维缩放)
                                                          │
                                                          ▼  L2norm
                                               z_e ─────────────┐
                                                                ├─ L_img: InfoNCE(z_e, z_i)
目标 (B,K,3200) ─► LayerRouter ─► Linear ──► share_head ──► z_i ─┤─ L_xs : 跨被试 multi-positive
                     （权重共享的同一个 Linear，D1 的修复）      └─ L_mmd: MMD(z_e 云, z_i 云)
                                                                   L_spec: 谱集中（替代 VICReg）
   ✗ mmd_subject  ✗ VICReg-var  ✗ HSIC/dec  ✗ proto  ✗ rkd  ✗ adv
```

### 3.3 C1 — 跨模态权重共享头（`share_head`）：修 D1 的机制

> ⚠️ **已被实测证伪，见 §7.2。** 2×2 消融（C1×C2 开关）显示 D1 的功劳 **100% 归 C2（SMN）、
> 0% 归 C1**：中心化增益只由 SMN 开关决定，与 `share_head` 是否非线性无关；非线性臂在两个
> 列里都是更差的 raw。本节余下内容保留为**设计推理的记录**，不再是生效的机制。
> `share_head_hidden` 默认已改为 `0`。

EEG 与图像两条通路的**最后一个映射是同一个模块**，两侧先各自降到同一宽度 `d_latent`（EEG: 200→d_latent；图像: 3200→d_latent），再走共享映射。共享映射的 **bias 对两个云相同**，因此它只能把两个云**整体平移**，无法把一个云相对另一个云推开。

实现：把 `_head` 的 `eeg_head` / `img_head` 替换为一个 `share_head`。

#### 3.3.1 一个必须写下来的证伪：线性共享头是**零约束**

设计初稿里 `share_head` 是 `nn.Linear(d_latent, d_align)`，当时写下的理由是"bias 共享 ⇒ 云间位移不可能由该映射产生"。**这个理由是错的**，而且不是"不够强"，是**完全无效**：

`img_head: linear` ⇒ `img_pre` 是线性；`share_head` 也是线性 ⇒ 两者复合是**一个**线性映射。图像侧要复现任意一个有效映射 $M$ 而把 `share_head` 的权重 $W$ 冻在 EEG 分支想要的任意位置，只需取

$$A_{\text{img}} = W^{+} M$$

$W$ 只要行满秩就存在。而 $A_{\text{img}}$ 有 $768 \times 64 \approx 49\text{k}$ 个自由度，被"施加"的约束 $W$ 只有 $64 \times 64 = 4\text{k}$——**图像侧参数的富余量远大于被共享的东西**。于是共享模型与不共享模型**可达函数类完全相同**，`share_head` 只是一个重参数化，**约束不了任何东西**（实测：冻结随机 $W$ + 最小二乘拟合 `img_pre`，复现目标 PCA 映射的相对残差 $8.3\times10^{-7}$，即精确复现）。

后果很实际：若按初稿提交，D1 的位移只可能是 **C2（SMN）** 除掉的，而报告里会把它记成 C1 的功劳——这正是本项目最警惕的那类静默错误（"占着一个它并不使用的机制"）。

#### 3.3.2 修正：把非线性放进**共享**映射内部

```python
share_head = nn.Sequential(nn.Linear(d_latent, h), nn.GELU(), nn.Linear(h, d_align))
# h = 2 * d_align = 128；share_head_hidden: 0 可退回纯线性（作为消融臂，而非默认）
```

这样图像分支被迫**在和 EEG 分支相同的位置**穿过同一个 `GELU`，一个私有的**线性** `img_pre` 在代数上无法吸收它（同一拟合的相对残差从 $10^{-7}$ 升到 $0.75$）。共享才成为对**假设类**的真实约束。参数代价 16.6k，相对 trunk 的 869k 可忽略。

两条设计约束决定了具体形状：

1. **最后一个算子必须保持线性。** `z_eeg_raw` 是 D1 诊断量的载体，也是 `L_spec`／VICReg 的作用对象。若在末尾加 LayerNorm，每一行会被自己的统计量重新缩放，恰好把该诊断要测的**被试级偏移**糊掉。所以非线性放在**中间**：`Linear/GELU/Linear`。
2. **初始化要接近等距。** 两层都用 `orthogonal_`，第二层带增益 $1/\sqrt{0.425} = 1.534$ 补偿 GELU 的方差衰减（$E[\mathrm{gelu}(z)^2] = 0.425$ 实测于 $z\sim N(0,1)$，$4\times10^6$ 样本）。否则 64→128→64 的头在初始化时就随机收缩一遍，把 16 个有信息的方向和 48 个无信息的方向混在一起，训练前期还得先把这个混合解回去。

#### 3.3.3 C1 与 C2 是互补的，不是重复的

实测（`smoke_test.py` §12）给出两者分工的确切边界：

| 事实 | 含义 |
|---|---|
| `share_head` 的 bias 使两条通路的 **pre-SMN** 嵌入平移同一向量（$\Delta_{\text{eeg}} = \Delta_{\text{img}}$，差 $6\times10^{-8}$） | 共享 bias 只能平移、不能相对位移 |
| SMN **在 EEG 侧把这个 bias 完全抵消**（差 $8.5\times10^{-8}$） | 所以 head 的 bias **永远无法**用来给 EEG 云加偏移；唯一的对齐途径是把**图像**云的均值拉到原点，而这正是 `L_mmd` 做的事 |

因此 C1 阻止的是**学出来的**模态间分歧（两条通路各自漂移），C2 移除的是**输入驱动的**被试偏移（数据里的），**谁也做不了对方的活**。而由于 SMN 把 EEG 云钉在原点，`L_mmd`（C4）必须靠移动图像云来对齐——C4 在这里不是"参考也这么做"，而是 C1+C2 的直接推论。

**可证伪预测 P2**：`‖mean(q)‖/mean‖q‖` 显著下降，且 `center QUERY only` 不再有效（增益 < 1 pp）。判据升级为：若 P2 成立而 `share_head_hidden: 0` 的消融臂（§7 已列为独立臂）结果相同，则 D1 由 C2 单独完成，C1 应被删除而不是保留为装饰。

### 3.4 C2 — 被试模态归一化（SMN）：把 +6 pp 变成架构的，而不是测试时的

```python
mu_s    = 同被试行均值(z)                # train: batch 内该被试的 128 行; test: 200 queries
z_c     = z - mu_s
# 可选：逐维缩放，用可学习门控 g（初始 0，即先只做均值）避免二阶部分强行介入
scale   = (sigma_s / sigma_s.mean(-1, keepdim=True)).pow(g)   # g 可学习, 初值 0
z_norm  = normalize(z_c / scale)
```

三点设计理由：

1. **它是 §1.4 测到的那个杠杆本身**（+6.5/+4.5/+2.5 pp），只是从测试时搬进前向通路，于是编码器在**中心化后的度量**里训练，可以把腾出来的容量用在概念结构上。
2. **构造上概念盲**（P1）：train 时 `mu_s` 汇总 128 个不同概念，test 时汇总 200 个。两者统计含义一致——"该被试在一个随机概念样本上的均值"。这里 train/test 是**匹配**的，不是 train 用真值、test 用估计。
3. **不会塌缩**：没有可学习的被试表，统计量来自数据。v1 的塌缩需要一个自由参数去塌，这里没有这个东西。
4. `g` 初始为 0 是刻意的：测量说二阶部分最多 +1 pp 且可能为负（§1.2），所以默认只做均值，二阶作为可学习臂，由数据决定是否打开。

**协议合法性**：只用无标签 EEG，不用"某个试次属于哪个刺激"，与 `saw_whiten` 同类；是 LOSO 严格协议允许的 transductive 操作。

### 3.5 C3 — 低秩对齐头 + 谱集中正则：修 D3，替代 VICReg

**低秩**：`d_align` 从 512 降到 **64**（消融 {64,128,256}）。理由三条：
- §1.1：信号在 16 维 → 64 是 4× 余量。
- **让 InfoNCE 不再能被平凡满足**：128 个概念在 64 维里无法互相近似正交，所以目标函数**必须**用概念方向，否则损失下不去。损失因此重新变成**有信息量**的信号（源端 loss 不再"已解出"而测试崩）。这是对 D3 的直接治理。
- 任何协方差/度量估计在 64 维里是良定的（64² 参数 vs 200 样本），彻底消除 `saw_whiten` docstring 里那个"199 个非零特征值 + 313 个数值零"的病态。

**谱集中正则替代 VICReg-variance**：VICReg 的铰链对**每一维**施压（`relu(1-σ_d)`），在 512 维上均匀充气（实测 0/512 达到 1.0，cv 0.127），它赢不了、却持续消耗 18.8% 的梯度并稀释概念方向。替换为**鼓励集中**的正则，例如对 batch 协方差谱 `{λ_j}` 惩罚尾部能量占比：

```
L_spec = Σ_{j>r0} λ_j / Σ_j λ_j            （r0 ≈ d_align/4，鼓励谱集中在头部）
```

即把"均匀充气"换成"向头部集中"，与任务需要的几何同向。

**VICReg 的 covariance（去相关）项在 v4 上被删除，而不是保留。** 初稿写的是"保留，权重 ≤ 0.1"，这是**错的**，依据来自第一次 GPU 冒烟：日志里 `cov: 0.0`，而 v3 的同一项是 `0.13`。

根因不是权重，是它吃的东西的**尺度**：v4 的头是 `Linear/GELU/Linear`（§3.3.2），`z_eeg_raw` 的行范数均值 **0.26**，而 v3 是 O(1)；而 VICReg 的 `(off**2).sum()/d` 随 $\lVert z\rVert^4$ 缩放，于是 4 倍的尺度差变成 $4^4=256$ 倍的惩罚差，实测项值 $4.6\times10^{-9}$，比 v3 低**七个数量级**。

换成"先归一化"（使其尺度无关）**不能救它**，因为真正的问题是这一项**分不清自己想惩罚的结构与噪声**。在 384×64 的 batch 上，对照一个"某条轴被精确复制"的表示：

| 形式 | 随机输入 | 一条轴精确复制 |
|---|---|---|
| 原样（v3 写法） | 6.93e-03 | 7.86e-03 |
| 行归一化（尺度无关） | 1.63e-06 | 1.87e-06 |

两种形式都只移动 **14%**；行归一化还会把每个协方差元素压到 $\sim 1/d$，使项值变成任何冗余都无法撼动的常数 ~1e-6。原样形式另有一个致命性质：它随尺度变化（0.04× 尺度下是 1.8e-08），即**惩罚强度由一个任意的头初始化尺度决定**。

因此 `objective: v4` 现在**拒绝** `reg > 0`（与 `dec`/`proto`/`rkd`/`adv` 同等对待），把它从"一个带权重的正则"变成"一个守卫拒绝的死项"。`L_spec` 已经是同一诉求（谱集中）的**可达**版本，且构造上尺度无关。v3 的写法一字未改，已记录的结果保持可复现。

### 3.6 C4 — 恢复参考的"粗到细"机制（我们跑的不是它）

读两边代码确认：参考的 stage 1 是

```
loss = w_mmd * MMD(z_eeg 云, z_image 云) + (1 - w_mmd) * InfoNCE,   w_mmd: 0.9 → 0.5
```

`mmd_rbf` 的 `unbiased=True`，`sigmas=(0.1,0.2,0.5,1,2)` 固定。而我们的 `mmd_subject`（`losses/invariance.py`）是**被试之间**的分布匹配，ramp 也不同，且 `img` InfoNCE 从第 0 步就是全权重。**"粗到细"这个名字在我们的实现里对应的是另一个项。**

改为：stage 1 用 **EEG 云 ↔ 图像云** 的分布对齐（0.9 → 0.5）做**分布级热启动**，stage 2 只用对比。

### 3.7 C5 — 目标函数删到 4 项

保留：`L_img`（对比）、`L_xs`（跨被试 multi-positive）、`L_mmd`（EEG↔图像分布，C4）、`L_spec`（C3）。
删除依据：

| 项 | 处置 | 依据 |
|---|---|---|
| VICReg-var | 删（→ `L_spec`） | §1.1 + 逐维 std 测量：均匀充气，与 16 维信号矛盾，占 18.8% 梯度 |
| VICReg-cov | **删**（`reg: 0.04 → 0`，`objective: v4` 拒绝非零） | §3.5 末：在此拓扑上项值 4.6e-09，且"随机表示 vs 一条轴精确复制"只差 14%，即分不清目标与噪声 |
| `mmd_subject` | 删（→ `L_mmd` EEG↔图像） | §3.6：它不是参考的机制；且 §2.2 说被试间软匹配赢不了 |
| HSIC `dec` | 删（0.05 → 0） | §2.2；且"抑制被试身份不涨点、对抗式抑制会掉点"已是既有结论 |
| `proto` | 删 | 打开后未显示增益；对称/非对称锚定的文献结论不迁移到本任务 |
| `rkd` | 删（本已降为消融） | 证据来自 LLM 蒸馏类比，不来自 EEG |
| `adv` | 保持关闭 | 会移除信号 |

保留两项的确认依据：`img` 与 `cross` 是梯度占比最大的两项（44.8% / 32.3%），且 `cross`（跨被试同刺激"拉近"）是既有多被试研究里唯一有正增益的机制。

### 3.8 骨干：**暂时不动**（这是一个有依据的决定，不是保守）

测量说骨干不是瓶颈：两云 16 维子空间重合 94%（对齐没坏）、源端 loss 已解出、加宽聚合器掉分。**在度量被修好之前换骨干，测不出任何东西**——更好的骨干放进一个会被 D1 位移污染的度量里，只会得到噪声。

列为**后续**单项消融（不是本轮）：
- **前端结构**：`Linear(250→200)`（每通道 5 万参数的、无局部性先验的时间全连接）vs 参考的 `Conv2d(1,40,(1,25)) + AvgPool2d((1,51),(1,5))`（显式低通+下采样，强平移/局部性先验）。前者更容易拟合被试特有的时间模式。
- **双分支骨干**：参考的 `DBConformer` 形态（时间 transformer + 通道 transformer + 通道注意力池化）；以及 STAMBRIDGE / ViEEG / CSBrain。

### 3.9 训练协议

| 项 | 我们（v3.2） | v4 |
|---|---|---|
| batch | 128 概念 × 3 被试 | 不变（但要保证同被试行数足够稳地估计 `mu_s`） |
| lr | 1e-3 | **1e-4**（参考值；我们高 10×） |
| encoder dropout | 0.1 | **0.5**（参考值） |
| stage 1 | 20 epoch，`mmd_subject` 0.9→0.2 / cross 0.1→0.7 | `w_mmd` 0.9→0.5，`img` 与 `cross` 按 `1-w_mmd` 缩放 |
| stage 2 | 继续联合训练，lr 5e-5 | **冻结编码器**，lr 5e-5（参考做法） |
| 校准 | SAW + CSLS + recovery | **raw cosine 为主**；CSLS 可选；recovery 关闭（§1.2 说它在此表示里掉分） |

stage 2 冻结编码器值得单独说：我们记录过 "dip-then-recover" 曲线（stage 2 开始掉分再回升）。参考的做法是 stage 1 结束后**冻结编码器**、只用 5e-5 微调 projectors/router。在一个度量已经对齐的表示上，stage 2 的联合训练只会把表示重新推离部署度量。

## 5. 风险

1. **低秩过度**：`d_align=64` 可能欠拟合。故 `d_align` 是消融旋钮，且以"源端 loss 出现下界但不高于 ln(#concepts)+margin"为健康判据；若 loss 下不去且 Top-1 也下不去，说明 64 太小。
2. **SMN 的 batch 统计**：batch 内每被试 128 行。若某被试行数过少，`mu_s` 方差大。需要 `rows-per-subject` 下限保护（参考实现 `routed_sr` 的 `subject_dropout=0.3` 是同一顾虑的另一解法）。
3. **transductive 的边界**：SMN 在 test 用 200 个 query 的统计量。这与 `saw_whiten` 同性质、同协议；但**必须在论文里明确写出**，且不能使用任何标签或 gallery 信息。
4. **单折证据**：sub-08 一折、3 个种子。所有结论应先在同一折内复现，`d_align` 这类旋钮在 10 折前不要定死。
5. **本折的 SOTA 标尺是 25.0 而不是 34.4**（§1.5）。不要为了一个不可复现的数字牺牲可复现性。

### 7.1 更正我自己的两处口径错误（先读，因为它们解释了为什么下面的判决与 §3 相反）

**错误一：拿错了正常值。** §3.3 用 `‖mean(q)‖/mean‖q‖` 作为 C1 的读数。该量**必须在 pre-SMN 处
测**——SMN 之后按构造为 0，测它没有意义——而它的**正常值本来就大**（SMN 的职责就是把它减掉）。
把 v4 的 pre-SMN 值去比 v3 的 shipped 值，结论必然错。正确口径：

| | shipped `offset_ratio` | gallery 自身 |
|---|---|---|
| v3.2-base（无 SMN） | **0.4154** | 0.2055 |
| v4（as shipped） | 0.0756 | 0.2302 |
| v4（`nospec+nofreeze+lr1e-3`） | **0.0489** | 0.2026 |
| （SMN 输出、L2 归一化前） | **6.9e-08** | — |

**错误二：读错了阶梯行。** §3 说"需要 +3.84pp 的测试时平移"。那个数字是
`+ centre + CSLS`，而 **CSLS 是 hubness 校正，与偏移无关**。真正的偏移杠杆是 `+ centre`：
v3.2 的该行增益为 +4.5pp（均值），v4（lr1e-3）为 **+1.67pp**。所以"平移缺口"是**缩小了**，不是存在。

### 7.3 回归的**真正**原因是两个超参错误，不是架构

| 臂 | 相对出厂 v4 | p |
|---|---|---|
| 只删 `spec` | **−0.00pp** | 1.00 |
| 再取消 Stage-2 冻结 | +1.50pp | 0.43 |
| 再把 lr 1e-4 改回 1e-3 | **+4.50pp** | 0.077 |
| （合计）相对 v3.2-base | **+4.00pp** | **0.000**，3/3 seeds |

**"照搬参考的 lr 1e-4" + "参考的 Stage-2 冻结"= 编码器只训了 20 epoch。** 这与架构无关。

### 7.4 三个新探针（v5 的回归读数）

`scripts/probe_per_subject_accuracy.py`、`probe_cross_subject_geometry.py`、
`probe_concept_vs_subject_variance.py`。关键发现：

| 测量 | 结果 |
|---|---|
| 同模型同 200 概念，**训练过**的 9 被试 | **45.67 ± 5.63** |
| 同模型同 200 概念，**留出** sub-08 | **17.50**（精确复现已记录的 seed-2025） |
| **被试差** | **+28.17pp** |
| 同模型，训练概念 vs 测试概念（sub-01） | 58.60 → 47.50，即**概念新颖性只值 ~11pp** |
| 跨被试概念几何（500-way，无训练） | 21.4% vs **chance 0.20%** —— **几何确实对齐** |
| 被试识别率（chance 10%）：pre-SMN / shipped | **40.25 ± 2.04%** / 8.65% |
| 试次数 n=5→n=10（同一被试同一概念） | 10.80 → **21.40** |

**结论（这是 §3 缺失的一条）**：瓶颈排序是
**① 单试次噪声 > ② 被试特异概念方向错位（+28pp） > ③ 度量错配 > ④ 概念新颖性**。
`subject == modality` 这一假设的**可证伪预测成立**（留出被试的几何对齐），失败在优化与度量。
