## 0. 一句话总结

**把每个被试看成一个独立的"观测模态"，用一条共享的投影把 EEG 与图像投影进同一个 64 维低秩对齐空间，
在"部署时真正被评分的那个度量"（CSLS 校正后的余弦）里做对比学习，并在测试时用无标签几何把新被试的
坐标系恢复过来。** 已验证：单折 sub-08 上部署后 **35.50 Top-1**（超过 SAMGA 34.4 / SVTL 无适配 35.3），
且**没有重训**。

## 1. 任务与协议边界

| 项 | 取值 | 说明 |
|---|---|---|
| 任务 | THINGS-EEG2 图像检索，**200-way** | query 与 gallery 都是 200 条测试试次 |
| 指标 | Top-1 / Top-5 / mean rank | 余弦相似度，`rank <= k`，与 SAMGA 实现逐位一致（`evaluate.retrieval_report`） |
| 协议 | **LOSO**（留一被试） | sub-08 为目标；源 = `[1,2,3,4,5,6,7,9,10]` |
| 划分 | 训练侧 **1654 概念 × 10 图**；测试侧 **200 概念 × 1 图** | 训练试次与测试试次完全分离 |
| 输入 | `(63, 250)` = 63 通道 × 250 时间点 | 全 63 通道（跨被试协议） |
| 视觉目标 | InternViT-6B-448px-V2_5，层 **20/24/28/32/36**，每层 **3200-d** | **与 SAMGA/SCORE/SVTL 完全同源**——这是数字可与文献直接对比的前提 |
| 输出 | 部署端检索分数矩阵 `(200, 200)` | 只做检索，不做生成（生成是后续独立阶段） |
| 选点 | **末轮 checkpoint**（`last.pt`），无验证集 | SOTA 协议（`PROTOCOL_INTER.md §3`），`n_val = 0` |

### 两条赛道（决定"和谁比"）

* **T1（纯归纳）**：训练时看不到目标被试任何数据。只有 raw cosine 算数。
* **T2（transductive / 无标签目标域自适应）**：允许用**目标被试自己的 EEG**（不含标签、不含 gallery 身份）
  在测试时精修表示——SMN、SAW 白化、CSLS、坐标恢复都属此类。
  **SCORE 53.23 与 SVTL 48.1 都是 T2 数字**，必须单列声明，不能混进 T1。

> 这条边界不是形式主义：本项目一轮误判（把 `+centre` 与 `+centre+CSLS` 混读）就是因为它没被钉死。

## 3. 组件设计

### 3.1 视觉目标：5 层 InternViT + `LayerRouter`

**为什么不是单层全局向量。** 用**多个**冻结视觉层监督 EEG，而不是一个全局图像嵌入，
在已发表对照里值 **~5.7 Top-1**（29.6 → 35.3），**大于大多数 EEG 骨干之间的差**。

`LayerRouter` 把 `K=5` 层融成一个向量，三种模式：

| 模式 | 行为 | 用途 |
|---|---|---|
| `mean` | 固定均匀权重 | "这些层是否互补"的基线 |
| `routed` | 学习的全局层权重 `w ∈ R^K` | **出厂设置** |
| `routed_sr` | 全局权重 + **逐被试残差，推理时丢弃** | SAMGA 机制，消融臂 |

**两个防塌缩旋钮**（直接借自 SAMGA 发布配方，因为实测学过权重会塌到最浅层 ≈`[0.74,0.13,...]`）：

* `router_temperature = 2.0`：softmax 前除以它，>1 把分布推向均匀，让 5 层都活着；
* `router_layer_dropout = 0.1`：随机置零部分层权重再归一化；
* `loss_weights.router = 0.05`：对**干净 softmax**（不是 dropout 后）加负熵 `-H(w)`，只抵抗"塌向一角"，
  初始化时梯度恰为 0。

> `routed_sr` 默认关闭是**有实测理由的**：把训练目标变成"该行的被试"的函数，会给编码器**编码被试身份**的激励，
> 与去相关项直接对立（v1 目标下实测把被试依赖项从 0.22 推到 0.48）。

### 3.2 EEG 主干 `EEGTrunk`（ATM-S 族，**无被试条件化**）

```
(B,C=63,T=250)
  └─ depthwise 时间卷积 Conv1d(63,63,k=25,groups=63) + BN + ELU   局部波形
  └─ embed: Linear(250 → 200)  逐通道                                 通道 token
  └─ + channel_pos (1,63,200)                                       通道位置
  └─ 2 × EncoderLayer(d_model=200, n_heads=4, dim_ff=512)           pre-norm 注意力块
  └─ TemporalSpatialAggregator(width=16, pool_tokens=8)
         (B,63,200) → transpose → (B,1,200,63)
         → Conv2d(1,16,(1,63))      "spatial": 跨通道混合
         → Conv2d(16,16,(16,1))     "temporal": 跨 token-时间混合
         → AdaptiveAvgPool2d((8,1)) → flatten (B,128)
  └─ LayerNorm(128)
  └─ projector: Linear(128,200)+GELU+Dropout+Linear(200,200) → (B,200)
```

**三个设计要点，每个都有过代价：**

1. **没有条件化接缝。** 没有 `z_s`、没有 FiLM/LoRA、没有 support-set 前向。
   编码器是 EEG 的**一个共享函数**——训练被试与未见被试一视同仁。
   证据：学到的 `z_s` 塌成常数（不同被试间余弦 **0.9999**），显式条件化相对 id-table 对照无增益。
   被试适配移到**目标函数**与**测试时几何**里。
2. **聚合器的轴顺序是承重的。** 早期版本把 `temporal_kernel` 放在轴上大小=1 的位置（等于标量乘），
   再去平均正好是 `norm` 刚置零的那根轴，结果头得到常数表征。
3. **最后的 LayerNorm 必须落在池化后的特征上，不能在 `(B,C,d)` token 上**——token 级 `LayerNorm` 沿 `d_model`
   零均值，而 `agg` 正好池化这根轴，编码器会变成输入的常数函数。

**没有 BatchNorm 冻结机制**——但如果将来引入冻结：`requires_grad=False` **不冻结 BatchNorm**，
`momentum>0` 时它每次前向都写 `running_mean/var`，实测把一个 `running_var` 从 1.2e2 推到 1.4e23，
eval 模式除下去把 Top-1 从 9.5% 砸到 0.5%。

### 3.3 被试即模态：`eeg_pre` / `img_pre` / `share_head` / `SMN`

这是整份架构的核心语义，也是相对 v3 的**唯一结构性改动**。

**问题（实测）。** v3 有两条**独立、偏置不受约束**的头。目标里没有任何东西把它们系在一起，
后果是 EEG 云被一个**逐被试位移**推走：
`||mean(q)||/mean||q|| = 0.27–0.42`，而图像云自己的偏移只有 `0.21–0.24`，
且两者**近似正交**（`cos(mean_q, mean_g) = +0.10..+0.14`）。
在余弦度量下，一个常数、不匹配的偏移 = **逐 gallery 项的偏置 = hubness**。
单独把它中心化就值 **+6.5 / +4.5 / +2.5 Top-1**（三个 checkpoint），
**超过整个坐标变换家族**（含给定标签的 SNR 最优对角重加权）。

**解法（构造性，不是惩罚项）。**

```
eeg    ─[trunk]─► ─[eeg_pre]─┐
                              ├─► ─[share_head]─► ─[SMN]─► z_eeg
target ─[router]─► ─[img_pre]─┘
```

* **一条共享的 `share_head` 作用在两个模态上**：EEG 分支注入的被试偏置会**被同一个映射也作用到图像分支**，
  于是落在两朵云里的**同一方向**、相互抵消，而不是把一朵云相对另一朵推走。参考架构正是因此
  **完全不需要测试时中心化**。
* **容量放在模态私有投影里**（`eeg_pre` / `img_pre`），这样共享映射可以保持**单层线性**——这就是 C1 的含义。
* **`d_align = 64` 是刻意的。** 子空间探针把任务概念流形定在 **~16 维**
  （query 方差 93–96%、target 98% 落在前 16 主成分）。512 维对齐空间会让 InfoNCE 有 ~496 个
  **不迁移的被试特异方向**去分开训练类；64 维把主体压在那一区间以下，同时仍留出重新加权那 16 个
  有信息方向的余地。

**关于共享头必须非线性（一条被自己证伪、再修正的结论）。**
若 `share_head` 是线性的，而 `img_pre` 也是线性的，则二者复合是**一个线性映射**，C1 变成**恒等重参数化、完全失效**：
图像侧有远多于此的参数（3200×64 ≈ 205k）去安置它，而共享映射只有 64×64 = 4k 行；
要让 `share_head` 停在 EEG 分支想要的任何位置，同时实现任意图像映射 `M`，只需取
`img_pre = W⁺ M`（只要 `W` 行满秩就存在）。实测：冻结随机 `W` + 拟合 `img_pre`
能以 **8.3e-07 相对残差**复现目标 PCA 映射。
插入非线性后（`share_head` 默认 `hidden = 2*d_align`），私有线性 `img_pre` **可证明无法吸收**
（同一拟合剩 **0.75 相对残差**）。

> **当前出厂配置的一个诚实标注**：`v5-a1-k20` 的 `share_head_hidden = 0`，即**共享头仍是线性**，
> 所以 C1 在当前最好臂上**实际是惰性的**，被移除的被试位移由 **SMN 独立承担**。
> 这不是架构目标状态，是一次"C1 收益 0%"的实测结果（见 §7 状态表）。**目标状态是 `hidden = 128` 的非线性共享头。**

**`SMN`（Subject-Modality Normalisation）——本任务最大的单杠杆。**

一句话：**每个被试是同一概念空间的一个不同观测模态，于是把该模态自身的无标签统计量喂给架构，
减掉它所能解释的那部分嵌入**——而不是指望一个惩罚项去逼出它无法强制的那个不变性。

* **为什么是数据统计量、不是学出来的被试向量**：在 ~128–200 条跨概念试次上池化的统计量，
  **构造上就是概念盲的**（128 个概念的均值说不出任一单次试次属于哪个概念）。这是与"损失惩罚使用它"
  完全不同的一种保证，也是唯一活下来的那种——它**不需要激励，也没有可塌缩的自由参数**。
* **两种模式是同一次操作**：训练时 batch 里有几个被试，按 `subject_ids` 分组求统计量；
  部署时 query 集就是**一个**被试的 200 条试次，`subject_ids=None`，整批一组。
  两者都是"一个被试的许多概念的随机样本的均值"——所以训练时的估计是部署时的**匹配代理，不是泄漏**。
  这也是 SMN **必须跑在训练前向路径内部**的原因：只在测试时中心化，会让编码器在部署不使用的度量里被优化。
* **gate 用 `clamp(0,1)` 而非 sigmoid**：sigmoid 会把初始 gate 放在 0.5，即出厂就带上一半**证据不足**的二阶矩；
  `clamp` 让 0 精确可达，两端是硬边界。证据：二阶矩那一半在三个 seed 上贡献 **−0.5 … +4.0**（符号都不确定），
  所以起点必须是纯中心化，只在目标付钱时才打开。
* **`min_rows` 是安全底线**：一组只有 1 行时它会减掉自己得到零向量，静默摧毁该行梯度并使检索矩阵依赖 batch 组成；
  低于阈值保持原样（退化为"该行不做 SMN"而不是"没有该行"）。
* **协议地位**：部署端 SMN 只用被评分被试**自己的 EEG**，从不使用某条试次属于哪个刺激，
  与 `saw_whiten` 同类（transductive、无标签），**必须在论文中显式声明**。
  它**不可**与"学出来的映射"互换——有监督线性对齐（给定 200 个标签中的 199 个）峰值只有 17.0 leave-one-out，
  而把这 200 对**拟合**到 100%：**估计出的统计量会泛化，拟合的映射不会**。

## 4. 目标函数与课程

### 4.1 总目标（`objective: v4`）

```
L = w_img · L_img  +  w_cross · L_cross  +  w_mmd · L_mmd  +  w_router · (-H(w))
```

| 项 | 形式 | 权重 | 职责 |
|---|---|---|---|
| `L_img` | 对称 InfoNCE，`z_eeg ↔ z_img`，可学习温度（softplus，有下限） | 1.0 | 概念级对齐（主项） |
| `L_cross` | 对称 InfoNCE，**同刺激跨被试**多正样本 | 0.7 | 跨被试一致性（独立文献 +2.23pp） |
| `L_mmd` | EEG 云 ↔ **图像云**的分布匹配 | 1.0 | 粗相位：让两朵云占同一区域 |
| `-H(w)` | 层权重的负熵 | 0.05 | 阻止 router 塌到单层 |

**为什么 `L_img` 用对角形式就恰好正确（这是个证明，不是经验）。**
跨被试 batch 把**一个**刺激发给 `g` 个被试，于是 `g` 行携带**同一个**目标向量。
写单组块 `A[i,j] = <z_e[i], t_j>`；共刺激列是相等向量，所以组内 `A[i,j] = f(i)` 不依赖 `j`。于是：

* `eeg→image`：`g` 个相等正列各占组内 softmax 质量的 `1/g`，`Σ_j (1/g)·dlogit_j = df(i)` 恰好抵消 `−df(i)`，
  **共享目标贡献的梯度为零**；
* `image→eeg`：`Σ_{j∈G} mean_{i∈G} A[i,j] = Σ_{j∈G} f(j) = Σ_{j∈G} A[j,j]`，与逐行取对角相同。

所以分组损失与对角损失的**两半完全相等**（不是近似）。`smoke_test.py 9f` 钉住这个等式。
一旦它报警，说明 layout 变了，mask 必须重新考虑。

**一个 mask 掩不掉的后果**：`g` 个等价正样本下，两半都触底在 `ln g`，温度**不可能**靠锐化改善——
这正是温度必须**设下限而不是允许跑到零**的原因。

| `proto` / `anchor`（EMA 原型） | v4 下不读 | 移除 |

### 4.3 课程 `CoarseToFine`（两相位）

逐字转写自 SAMGA 发布代码，因为"先粗后细"的方向是有道理的：

| 相位 | epoch | `L_mmd` 系数 | `L_cross` 系数 | lr |
|---|---|---|---|---|
| Stage 1 | 0–19 | 0.9 → 0.5 | 0.1 → 0.5 | 1e-3 |
| Stage 2 | 20–49 | **0.0** | **1.0** | 5e-5 |

* 插值 `t = epoch/(stage1_epochs − 1)`，与 SAMGA 打印值三位小数一致（其 epoch 11 → mmd 0.689）。
* **方向承重**：粗项是**分布匹配**，负责让两朵云占据同一区域；细项是**对比**，负责在已对齐的框架里锐化概念结构。
  先做细项会把编码器容量花在两框架还不一致的时候。
* **两个系数是凸拆分**（v4）：`mmd = 0.9→0.5`，`cross = 1 − mmd`，所以 Stage 2 是"纯对比"。
* **Stage 2 冻结编码器**（`freeze_encoder_stage2`）在 v3 下实测是"下跌再恢复"（21.0→17.5→20.5），
  即相位边界吃掉三分之一的进度又还回去——因为在一个**已经在部署度量里**的表征上继续联合训练，
  只会把它推回去。**当前 v5 臂为 `false`（未冻结）**，是待复核项，不是定论。

## 5. 支柱 A：恢复感知训练（Recovery-Aware Training）

**动机（本项目最硬的因果链）。** post-hoc 坐标家族的上界已被测到 ≤ 仅中心化（v4 §1.2）；
而 SCORE 用**同一个冻结编码器**把 26.22 → 53.23，差别**全在** "recovery-aware **训练**"。
所以收益不在算子更强，而在**目标与部署度量一致**。

### 5.1 A1：可微 CSLS 入环

部署端 CSLS：`s'_ij = 2 s_ij − r_q(i) − r_g(j)`，`r_q(i)` 是第 `i` 行 top-k 相似度均值，`r_g(j)` 同理。
把它写成 torch 模块 `csls_correct`（与部署 numpy 实现**逐位一致，max|Δ| 4.0e-7**，且
`csls_correct(S).T == csls_correct(S.T)`，所以对称 InfoNCE 里**不能也不需要**二次校正）。

`topk` 的选择是**次梯度**（梯度流到被选中项，如 `max`），这是标准处理，也正是让
**hubness 本身成为可微量**的原因：一个"人人都是它邻居"的 target 有高 `r_g`，降低它的校正 logit
就是把编码器推离对 hub 结构的依赖。

**两项可选旋钮，默认都关，关时与所有已记录 run 逐位一致（是不取分支，不是空操作分支）：**

* `csls_k`：把 logits 换成 CSLS 校正后的（要在温度**之前**，CSLS 定义在余弦上）；
* `block_per_subject`：**逐被试块**打分。这不是装饰——CSLS 移除的量是**检索集**的属性。
  部署永远是**一个**被试的 200 query 对共享 gallery，`r_q/r_g` 恰在那 200 行上算；
  一个混合 3 被试的矩阵算出的邻域密度**没有任何部署见过**，在那上面优化 = 为错误密度优化。
  块 = `n_s`-way 检索，与部署**同难度类**。

### 5.2 A2：SCORE 的 source-only 回合

每步把**一个源被试**当作临时目标，隐藏其 EEG–图像配对，**先施加部署时的恢复**，再揭晓配对算 loss。
编码器于是在一个**它真能恢复**的坐标系里被优化。

```
对每个 batch：
  选 s* ← 源被试（计数器轮转，不是随机 → 每个源被试当目标的次数相同，run 可由 seed 复现）
  取该被试的 EEG 块 z_e[mask]（≥4 行），gallery = z_i
  1. L2 归一化两朵云
  2. 用部署同一个 CSLS 校正余弦矩阵
  3. 取**互相最近邻**为伪地标（detached）
  4. 从这些对拟合**正则化正交映射 R**（ρ 拉向恒等）并施加
  只替换 s* 的行；其余行保持原坐标
  （→ 模拟"一个被试未见"，而不是"所有被试同时未见"，后者是另一个更容易的问题）
```

**`R` 的求解与一条被记录下来的坑。**
目标 `max tr(Rᵀ(xᵀy + ρI))` 的解是 `M = xᵀy + ρI` 的**正交极因子**。
第一版用 `R = UVᵀ`（SVD），它在第 50 步把训练 loss 变成 NaN——
因为 `M` 由 **L 个地标**在 **d 维**构造，而 **L < d 是常态**（42 地标、`d=64`），
嵌入本身还低秩（本项目的概念流形实测 16 维）。于是 `xᵀy` 有大量**重复奇异值**，
`ρI` 把精确重复的 0 搬成**近似重复**的 `ρ`（更糟），而 SVD/eigh 的反向要除以
`(s_i²−s_j²)` / `(λ_i−λ_j)` → NaN。
**关键：只有梯度是 NaN，前向值在每个失败样例里都完全正常**——任何"检查前向有限"的守卫都看不见。

修复：求解**前向-only 并 `detach`**（`orthogonal_procrustes`），用对称特征分解 + 3 步 Newton-Schulz
（把 float32 的 7.4e-3 正交误差压到 3e-7；正交性承重，因为检索是余弦，非正交 `R` 会悄悄改变几何）。
这不是妥协，而是**让回合与部署一致**：部署时 `R` 估计出来**直接应用**，没有梯度穿过它；
训练时对 `R` 求导，优化的是部署图里不存在的计算。梯度仍只穿过应用 `z_eeg @ R`。
相邻防线：训练循环现在**同时检查 loss 和梯度范数**并原地抛错（梯度那一项才抓得住这个 bug）。
**这不是角落情形——`L < d` + 低秩是默认情形。** 回归测试见 `smoke_test.py §12h/12i`。

### 5.3 预登记读数（不是只看 Top-1）

1. raw cosine **上升**（当前 27.00）；
2. `+CSLS` 的**后验增益收缩**（当前 +4.0：从 +whiten+CSLS 的 31.50 到 35.50）——若真"训进网络"，余量就该变小；
3. 训练/留出被试的 raw 差 **下降**（当前 +29.78pp）。

## 6. 部署栈（测试时，无参数、无标签）

```
raw cosine
   └─ (+center)          减掉 query 云均值        —— 平移
   └─ (+whiten/SAW)      shrink 收缩白化          —— 协方差
   └─ (+recovery)        Procrustes 坐标恢复      —— 旋转
   └─ (+CSLS)            重打分                   —— hubness
```

**顺序不是任意的**，也是被写错过一次的地方（文档说 CSLS 先，代码一直 recovery 先）：

* `center` / `whiten` 都是 **query 坐标变换**，必须在任何在这些坐标里测角度的东西**之前**；
* `recovery`（SCORE `epd.recover`）从互相最近邻伪对拟合 Procrustes，**内部会重算 CSLS**，
  所以先跑 CSLS 会被丢掉；
* 最后的 CSLS 是对**恢复后**相似矩阵的**重新打分**，只有坐标定了才有意义。

`center` 与 `whiten` 是**两件不同的事**（前者=平移，后者=协方差），评测阶梯必须分开标注——
本项目一轮误判就是因为它俩被混读。

**已测得的部署阶梯（`v5-a1-k20`，200-way，sub-08）：**

| 阶梯 | Top-1 | Top-5 | mean rank |
|---|---|---|---|
| raw cosine | 27.00 | 60.0 | 8.66 |
| **+ CSLS** | **34.00** | 67.5 | 7.42 |
| + centre | 26.50 | 59.5 | 8.88 |
| + centre + CSLS | 32.50 | 67.0 | 7.59 |
| + SAW whiten | 30.00 | 64.0 | 9.79 |
| + whiten + CSLS | 31.50 | 63.5 | 9.60 |
| **+ whiten + CSLS + recovery** | **35.50** | 66.0 | 7.70 |
| + whiten + CSLS + structural | 15.00 | 60.5 | 10.21 |
| + whiten + CSLS + recovery + structural | 18.00 | 62.5 | 8.37 |

**两条判决：**
* **恢复 +4.0pp（31.50 → 35.50）是主升杠杆**，且**免重训**。
* **SATTC 结构专家不成立**（15.00/18.00；即便 z-score 加权，最强臂增益为 0）——**放弃，不要重开**。

A 根本没碰到。B 的直接读数（pre-SMN 被试识别率 40.25% → chance 10%）不受 SMN 构造性干扰。

**B1 为什么不塌缩（关键）**：纯跨被试 Gram 会塌；锚是**冻结的图像 Gram**，
而 `L_img` 本来就要求 EEG 去匹配它——"所有 `Z_s` 变常数"会让 Gram 塌缩，**直接与 `L_img` 冲突**。

## 9. 为什么这套能冲 SOTA：增益预算

**已验证（单折 sub-08，2026-10-04）：**

| 来源 | 增量 | 口径 |
|---|---|---|
| 基线（v5 前） | 21.00 | T1 raw |
| 支柱 A1（可微 CSLS 入环） | **+5.50**（26.00 → 27.00 raw，含 seed 方差 ±1.15，3/3 seeds） | T1 raw |
| 部署 CSLS（免重训） | +7.00（27.00 → 34.00） | T2 |
| 部署恢复（免重训） | **+4.00**（31.50 → 35.50） | T2 |
| **合计当前** | **35.50** | T2 |

**对标（THINGS-EEG2, 200-way, LOSO）：**

| 方法 | Top-1 | 口径 |
|---|---|---|
| SAMGA | 34.4（复现 29.6） | T1 |
| SVTL（无适配） | 35.3 | T1 |
| **本项目（单折）** | **35.50** | T2（center+whiten+CSLS+recovery） |
| SVTL + 免训练精修 | 48.1 | T2（用重复试次） |
| **SCORE** | **53.23** | T2（恢复感知训练 + 部署恢复） |
| 本项目目标 T2 | **≥ 40 → 向 48** | T2 |

**预算（诚实口径）：**
1. **T1 缺口**：raw 27.00 → 需 ≥ 30。来源：支柱 B（最大、被 A 放大的缺口）+ 非线性共享头（C1 恢复）。
2. **T2 缺口**：35.50 → 40+。来源：**支柱 C2（重复试次精修，≥10pp，完全未用）** + 支柱 A2（回合）
   + B1 的跨被试几何。
3. **到 48/53**：需要 A2 真正闭合（把 `+recovery` 的后验增益**收缩**、raw 本身上去），
   以及 C2 全开。SCORE 的 53.23 正是"训练端与部署端做完整"的结果——我们**只做了一半**（部署端）。

**相对 SOTA 的差异化创新点：**
1. **可微无标签部署栈入环**（generalized recovery-aware training）：SCORE 把 CSLS+恢复放进训练环，
   但把白化等手设计部分留在测试时；我们把**整条无标签栈**（SMN + 白化 + CSLS + 恢复）做成可微模块。
2. **诊断驱动协议（三项回归探针）**：`probe_per_subject_accuracy` / `probe_concept_vs_subject_variance` /
   `probe_cross_subject_geometry`。**这是发现"L1 的 +5.50pp 不是被试不变性"的唯一手段**——
   多数论文只报一个 Top-1；我们把"表示质量"与"被试迁移"分开。
3. **对"上界"的方法学批判**：由我们自己的失败记录导出的可复现结论。

## 11. 风险与明确不做

**风险**
1. **单折外推**：所有数字是 sub-08 单折；seed SD 2.5–3.3pp，<2pp 视为噪声。投 10 折前不声称 SOTA。
2. **T2 协议**：SMN/whiten/recovery/CSLS 都是 transductive，必须单列，不能与 T1 混报。
3. **恢复的边际增益可能收缩而非消失**：A2 的正确判据是"raw 上去 + 后验余量变小"，只看 Top-1 会误读。
4. **非线性共享头未验证**：C1"收益 0%"是线性版本；非线性版本的结论是**开**（可证明不可吸收），但没跑过。

**明确不做**
* **SATTC 结构专家**（15.0/18.0，已证伪，最强臂增益 0）。
* **冻结 `img_pre`**（12.50，已证伪）。
* **被试条件化**（`z_s` 塌成常数 0.9999）。
* **`reg`（VICReg）**（v4 下实测 4.6e-09，对目标结构近乎无响应）。
* **`L_spec`（谱集中 tail 形式）**（全局最优 = 塌缩，实测惰性）。
* **在 `terms` 上继续做 k=10 的单点归因**（已被 k=20 证伪）。
