# EEG→Image 跨被试检索 v6：完整架构（冲击 SOTA）

> 本文是**架构规格**：模型长什么样、每块为什么这么长、为什么这么长能越过 SOTA。
> 依据：(a) 本项目 v3.2 → v4 → v5 的全部**实测**；(b) 2026 检索 SOTA 调研
> （`eeg2image_v5_master_plan.md §10/§14`：SCORE / SVTL / SAMGA / CORTIVA / HVF-Brain-HIVE / ENIGMA / EEGiT）。

## 0. 判决（一句话）

**不再"让一个编码器去逼近一个目标空间"，而是让同一条共享 EEG 编码器被多个异质视觉目标
从不同角度同时约束，在分数级保留各自证据，并把整条无标签部署栈逐位复现地放进训练环。**

编码器容量**不增**（主干 1.13M 不变）；增长的是**监督几何的丰富度**（目标）与**协议忠实度**（训练/部署一致性）。
这三个词——**异质目标 / 分数级融合 / 忠实恢复**——就是本架构的全部赌注，也是三条互相独立的增益通路。

## 1. 六条设计公理

| # | 公理 | 来源（证据） |
|---|---|---|
| A1 | **构造性 > 软惩罚**：要"移除"的东西，要么给显式估计器，要么用受限假设类排除 | v4 §2.2 实测：软项约束优化过程，不约束解集合 |
| A2 | **训练度量 = 部署度量，且逐位一致** | SCORE 用同一族把 26.22→53.23；我们 A1 +5.50pp（3/3 seeds） |
| A3 | **移除不需要的自由度**：信号在 16 维，多余容量有害 | 概念流形实测 16 维；加宽聚合器 −4.83pp |
| A4 | **目标定上界**：编码器不可能超过其监督目标的几何丰富度 | SVTL 仅换目标 +5.7pp；HVF "堆语义无用、加 VAE 才有效"；NeuroGlyph "超越固定层" |
| A5 | **分数级保留证据 > 嵌入级合并** | CORTIVA：多路分数融合 within +10.3pp；Kittler sum-rule |
| A6 | **规模不是本任务的杠杆** | ENIGMA <1% 参数达 SOTA 且 transformer 在多被试**有害**；神经解码 scaling law 不随被试数 scale |

> A4 与 A5 是 v6 相对 v5 的**唯一新公理**。A6 是对"更大骨架"问题的判决（§14）。
> A1–A3 已被本项目自己的失败记录反复验证。

### 2.2 三条监督通路（**这是 v6 的核心新增**）

| 通路 | 视觉源 | 维度 `D_r` | 它补充的几何 | 依据 |
|---|---|---|---|---|
| **α 语义** | InternViT-6B 层 20/24/28/32/36 → **空间多视图 + 因子化深度路由** | 5×3200 | 概念级语义（当前唯一通路） | 现 v5 已验证；SVTL/NeuroGlyph 证明"目标的结构化"值 +5.7pp |
| **β 低层** | **SDXL-VAE 潜变量** `[4,56,56]`（H/8） | 3136 | **局部/像素级细节**：颜色、纹理、布局 | **HVF/ICLR 2026 的核心发现**："语义编码器抓不到细粒度局部信息；堆叠语义编码器收益极小；加入 VAE 像素潜变量才显著提升检索" |
| **γ 自监督** | SynCLR ViT-B/16（+DINOv2 ViT-B/14 可选） | 768 | **与 CLIP 正交的表征几何**（不同视觉预训练目标） | CORTIVA 的 CVR 通路用 SynCLR；HVF 官方推荐 SynCLR 组合 |

**为什么必须三条、而不是加深一条。**
- 我们的目标是 **5 层 InternViT**——**全部是语义**。HVF 明确说"堆叠语义编码器收益极小"，
  这直接解释了本项目"从 1 层加到 5 层后边际递减"的现象：不是加得不够多，是**加错了种类**。
- CLIP/InternViT 类目标**系统性地不含低层信息**。EEG 里"颜色/纹理"这类早成分（CORTIVA 实测
  100–200ms 窗口 RSA 最高）**没有对应的监督方向**，只能靠噪声拟合。
- 三条通路的**几何互不相同**（语义/低层/自监督），因此在**分数级**融合才能保住互补证据
  （A5）；早期合并成一个嵌入会**强加单一相似度几何**并抹掉分歧。

### 2.3 共享编码器 + 逐被试模态投影（不变量）

```
                ┌─────────────── 每个通路 r 各一套（参数私有）───────────────┐
   h (B,200) ──►│ eeg_pre_r: Linear(200→64)                                   │──► (B,64)
   v_r (B,D_r) ─►│ img_pre_r: Linear(D_r→64)                                   │──► (B,64)
                │ share_head_r: 64 → 128 → 64（GELU，非线性 · C1 生效）          │
                │ SMN_r: 逐被试中心化（gate 从 0 起步）                          │
                └─────────────────────────────────────────────────────────────┘
```

* **`share_head_r` 必须跨模态共享且必须非线性。** 共享是为了让 EEG 分支注入的被试偏置
  在同一个映射下作用于图像分支、落在两朵云的同一方向而**相互抵消**；非线性是为了让
  C1 **可证明不可被 `img_pre` 吸收**（线性时 `img_pre = W⁺M` 可以 8.3e-07 残差复现，C1 恒等失效）。
  v5 出厂是**线性**，所以 C1 一直是**惰性**的——v6 把它**打开**（`share_head_hidden = 128`）。
* **`d_align = 64`**（三通路一致）。信号在 16 维，64 是 4× 余量；**分数级融合允许各通路维度不同**，
  但 v6 先统一 64，遵守单变量纪律（维度是后续可打开的旋钮）。

## 3. 组件设计

### 3.1 通路 α：语义目标的**结构化**升级（A4 的直接落地）

现 v5：`LayerRouter` 把 5 层**全局向量**融成一个 3200 维目标。
v6 升级为**空间多视图 + 因子化深度分配**（取自 SVTL / NeuroGlyph 被验证的设计）：

1. **空间多视图池化**：把每层的 `H×W` 空间特征图用 `Q` 个可学习 query **池成 Q 个视图**
   （而非单一 CLS/全局平均）。SVTL 证明"多视图分组 + 块结构 router"是 35.3 的来源。
2. **因子化深度分配**：`NeuroGlyph` 的机制——**子空间按深度因子化**，并让**图像条件**决定
   每张图在各深度上的权重。这修掉了 v5 的一个已知病：全局层权重会**塌到最浅层**
   （实测 `[0.74,0.13,...]`），我们只能用温度 + dropout + 负熵**硬撑**。图像条件化让
   "该看哪层"成为**每张图的函数**，而不是一个全局常数。
3. **保留 `routed` 的防塌缩旋钮**（温度 2.0 / 层 dropout 0.1 / 负熵 0.05）作为兜底。

### 3.2 通路 β：低层 VAE 分支（v6 补上的结构性缺口）

* `SDXL-VAE` 编码图像 → 潜变量 `[4,56,56]`（H/8）。
* `AvgPool2d(2)` → `[4,28,28]` → flatten（3136）→ `Linear(3136,64)`。
* **为什么要它**：HVF 的结论是"堆语义无用、加 VAE 才有效"，且**它才是显著提升检索的那一项**。
  我们此前卡在 "5 层 InternViT 边际递减"，根因就在这里。
* **成本**：一次 VAE 前向 + 3136×64 的投影头；`/project` 容量充裕（2.7 PB），
  缓存一次 image-level 即可，不进入训练循环的重复计算。

### 3.3 通路 γ：自监督几何

* `SynCLR ViT-B/16`（CLIP 类但用合成字幕自监督训练，几何与 LAION-CLIP 不同）。
* 可选叠加 `DINOv2 ViT-B/14`（纯自监督，CORTIVA 用它做**独立几何验证**）。
* **作用**：提供一条**与 α 语义不完全共线**的相似度几何（A5 的互补性来源）。

### 3.4 分数级融合（A5 落地，**参数无关为默认**）

```
S_fused = Σ_r  w_r · S_r          # 索引对齐的 200-way 分数向量，在 softmax/ranking 前合并
```

* **默认 `w = uniform`**。理由充分且可引用：CORTIVA 的四种权重控制里**均匀权重给了最高点估计**
  （74.22 vs query-aligned 73.5，区间跨零）；Kittler sum-rule 说明均匀求和对方差一阶不敏感。
* **备选**：源域验证选出的**固定**权重向量（不随 query / 被试变化）——避免重新引入
  已被证伪的**被试条件化**（`z_s` 塌成常数 0.9999）。
* **训练**：融合矩阵上做**对称 CE**（`L_fuse` = CORTIVA 的 `L_rce`）+ 各通路自身的对比/蒸馏。
  这使三个投影头**互相校准**（一个通路在**另一个通路答对的 query** 上被拉近其分布）。

### 3.5 忠实恢复感知训练（Generalized RAT）★ 创新点 ①

**这是 v5 支柱 A 的完整版，也是本项目最硬的因果链。**
v5 的 `v5-ep2` 已证明"回合"的**机制 3/3 全对**（raw +3.0、恢复边际 +4.0→+2.0、被试差 +29.78→+24.11），
但**部署净退化 −2.0pp**——因为入环的回合**没有忠实复现部署栈**：

| 入环（旧） | 部署（真实） | 后果 |
|---|---|---|
| 只做 recovery | `whiten → recovery` | 编码器被优化成"在**未白化**坐标里可恢复" |
| `k = csls_k = 20` | `calibration.csls_k = 10` | 地标集在**不同邻域**下选出 |

**v6 修正（单变量，逐位对齐）**：
1. **入环做完整栈**：`SMN → whiten(shrink) → CSLS(k=10) → 正交恢复(k=10)`，
   与 `calibration.py` 中部署实现共享**同一个模块**（同一函数、同一 k），
   并由 smoke test 断言 **`in_loop(x) == deploy(x)`（max|Δ| < 1e-6）**——照 `csls_correct` 的做法。
2. **source-only 回合逐通路执行**：对通路 `r`，临时把一个源被试当目标，隐藏其配对，
   施加该通路的部署栈，再揭晓配对算 loss。**注意**：每通路的恢复 `R_r` 在**各自的几何**里估计
   （见 3.6）。
3. **求解保持前向-only + `detach`**（v5 §13.1 的 SVD 反向 NaN 教训；`L<d` 且低秩是**默认情形**）。
4. **同一条防线**：训练循环同时检查 **loss 与梯度范数**（前者看不见 NaN 梯度）。

### 3.6 逐通路坐标恢复（Per-Route Recovery）★ 创新点 ②

**文献里没人做过这个组合。**
SCORE：单编码器 + 单坐标恢复。CORTIVA：多通路**分数**融合，但**不做**坐标恢复。

v6：**每条通路在自己的几何里估计并施加一次恢复，然后才融合分数。**

* 理由（构造性）：坐标恢复解决的是**该通路自己的**相似度几何里的被试方向错位。
  α（语义）、β（低层）、γ（自监督）的被试方向错位**不是同一个旋转**——用一个共享 `R`
  去修三套几何在数学上没有依据。
* 实现：对通路 `r`，用该通路的 CSLS 校正矩阵取互近邻伪地标 → `orthogonal_procrustes(x_r, y_r, ρ)`
  （库中已有）→ `z_eeg_r @ R_r` → `S_r`。
* 融合后**不再**做全局恢复（否则等于用一个旋转覆盖三套几何）。

### 3.7 多试次免训练精修（T2，支柱 C2，**≥10pp 杠杆，至今未用**）

* 训练集 `(1654,10,R=4,63,250)`：现 `_average_reps` 把 R 维**抹平**了。
* **缓存全 R 维**：`1654·10·4·63·250·4B ≈ 4.17 GB/被试` → 9 被试 **~37.5 GB**。
  `/project` 实测 **2.7 PB 可用**（AGENTS.md 旧版"仅 59 GB"已过期且错误），**可缓存**。
* **部署精修**（SVTL 式，免训练、无标签）：矩匹配 → CSLS 伪对应 → 正则化正交对齐。
  文献 35.3 → **48.1（+12.8pp）**。我们**完全未使用**过。
* **协议地位**：transductive（用目标被试自己的重复试次，不用标签、不用 gallery 身份）——
  **必须单列 T2**，与 SMN/whiten/CSLS/recovery 同档声明。

### 3.8 是否应拆成两段（概念编码器 → 图像投影）并顺序训练？——**判决：不冻结 part 1、不设第二个空间**

这是最初 v1 的设计，也是被 v2/v4 移除的设计（"NO SEPARATE MAPPING STAGE"）。
用户重新提出后，必须给出**基于实测**的判决，而不是靠"我们以前试过"搪塞。**分成"两个模块"对，分成"两个先后冻结的阶段"错。**

先把提议拆成两个**互相独立**的问题（它们常被混为一谈）：

* **Q1（空间）**：是否要一个**中间"概念空间"**，再把它的嵌入映到**图像 CLIP 空间**？
* **Q2（顺序）**：part 1（EEG 编码器）是否应先训好并**冻结**，再训 part 2（投影）？

#### Q2：不能冻结 part 1 —— 它会杀死我们最硬的两个杠杆

本项目**已经实测过这个失败**。坐标恢复在**为它训练过**的编码器上值 **+8.50pp**（27.0→35.5）；
在**没为它训练过**的编码器上（v4 的 post-hoc 尝试）上界 **≤ 仅中心化**（`probe_signal_weights.py`）。
可微 CSLS 入环同理：值 **+5.50pp（3/3 seeds）**，条件是编码器**在部署度量里**被优化。

这不是经验巧合，是构造性的：**坐标恢复作用在 EEG↔图像 的相似度矩阵上**——
它要求 EEG 嵌入已经落在**检索空间**里，互近邻地标才有意义；
且编码器必须被优化成"**它的坐标是可恢复的**"——这正是 SCORE 的 source-only 回合的全部意义。

所以：**part 1 一旦冻结，part 2 无论怎么训，都退化回 v4 那个已被证伪的 post-hoc 恢复。**
这不是"可能变差"，是**重演已有负结果**。

#### Q1：不需要第二个空间 —— 它只会多一道鸿沟

v4 的核心结构性结论：用**同一条共享头**把 EEG 与图像放进**同一个**空间，
于是 EEG 分支注入的被试偏置会**同向**作用到两朵云上而**相互抵消**（C1）。

若 part 1 对齐到一个**中间概念空间**、part 2 再映到图像空间，就人为插入：
1. **第二道模态鸿沟**（part 2 要跨的）；
2. 一个 **part 1 无法验证其目标**的局面（"概念空间"对不对，要看它下游能不能映到图像空间）；
3. 而"概念结构"**本来就是图像空间里的那个 16 维流形**（实测：query 93–96%、target 98% 方差在前 16 主成分）。
   另设概念空间不新增信息，只是把它**再参数化一次**，并给 part 2 一个**可过拟合的拟合目标**——
   而"源被试上拟合的映射不泛化到目标"我们**也测过**：监督线性对齐（给出 200 个标签中的 199 个）
   leave-one-out 峰值只有 **17.0**，而把这 200 对**拟合**到 100%（`models/smn.py` 的协议讨论）。

#### 那"两段"到底对不对？—— 对，但要这么切

**合法的两部分是"两个模块"，不是"两个冻结阶段"：**

| | part 1：被试不变表示 | part 2：视觉语义投影 |
|---|---|---|
| 模块 | `EEGTrunk` + `SMN` | `eeg_pre_r` + `share_head_r` + 多通路 |
| 学什么 | "什么该不变" | 跨模态鸿沟 |
| 训练 | **联合**（同一次反向） | **联合** |

关键论据：**"不变性"只有在目标几何定了之后才有定义**——对检索任务，不变性 = "对**不影响检索的方向**不变"。
一个不知道目标空间的 part 1 无法定义它该对什么不变。
我们的探针已证明这层耦合是真的：L1 的 +5.50pp **不是**被试不变性（被试差反而 +22.83→**+31.22**），
它是**整体表示质量**的提升——说明"不变"与"表示好"**不能切开训**。

**顺序训练（warm-start）可以，冻结不行。** 这正是 SOTA 的普遍做法：
* **CORTIVA**：Stage 1 单目标对齐 → Stage 2 **联合**优化（冻结的是**视觉 target/reference**，**不是脑编码器**）；
* **HVF**：冻结的是**预训练的视觉 Fusion Prior**，只更新脑编码器；
* 我们本来就把**视觉侧全部冻结**（InternViT / VAE / SynCLR 都是冻结特征）——**已经在做 HVF 那一半**。

所以 v6 的课程只是**单阶段内的 coarse-to-fine**（`L_mmd` 粗相位 → 对比细相位），**不是**跨阶段的"冻死一半"。

#### 唯一真正"顺序"的部分（且它属于部署）

**C2 重复试次精修是 post-hoc 的**（在冻结表示上、无标签、不改模型）——它**才是**该顺序做的那一段，
与 part 1/part 2 的划分无关，属于部署栈（§5）。

#### 若要检验"两段冻结"，如何让它可证伪（预登记，纪律要求）

不能只说"不"。若确实要检验，跑 **V0.5 消融**：

* **臂 A**：v6 单阶段联合（本方案）；
* **臂 B**：part 1 只训"概念对齐"（**无** CSLS/恢复入环）→ **冻结** → part 2 训带恢复的投影。

预登记判据：
1. 臂 B 的 **`+recovery` 后验增益应坍缩到 ≈ 0**（预测：冻结 part 1 使其不可恢复）；
2. 臂 B 的 **raw** 应 ≤ 臂 A；
3. 臂 B 若在源被试上过拟合，**被试差应更大**。

若 1–3 全中，"两段冻结"被正式证伪并记录；**若 1 不中，说明我对恢复的机制判断错了，必须重估 v5/v6 的整条 A 支柱**。

## 4. 目标函数与课程

```
L = Σ_r [ w_img · L_img^(r) + w_cross · L_cross^(r) + w_mmd · L_mmd^(r) ]
      + w_fuse · L_fuse            (融合矩阵对称 CE)
      + w_router · ( −H(w_α) )     (仅通路 α 的层权重负熵)
```

| 项 | 形式 | 权重 | 职责 |
|---|---|---|---|
| `L_img^(r)` | 对称 InfoNCE，`z_eeg_r ↔ z_img_r`，**入环做完整部署栈**（3.5） | 1.0 | 概念级对齐（逐通路） |
| `L_cross^(r)` | 对称 InfoNCE，**同刺激跨被试**多正样本 | 0.7 | 跨被试一致性（+2.23pp 文献；k=20 下 `cross` 承担大量 CSLS 增益） |
| `L_mmd^(r)` | EEG 云 ↔ 图像云分布匹配 | 1.0 | 粗相位 |
| `L_fuse` | 融合分数矩阵的对称 CE（EEG→img 与 img→EEG） | 0.05 | **通路互校准**（CORTIVA `L_rce`） |
| `−H(w_α)` | 层权重负熵 | 0.05 | 阻止层塌缩（v6 主修由 3.1 的图像条件化承担） |

**课程 `CoarseToFine`（沿用，方向已由 SAMGA 逐字验证）**：
`L_mmd` 0.9→0.5、`L_cross` 0.1→0.5、Stage 2 为纯对比；`lr` 1e-3 → 5e-5；
`freeze_encoder_stage2: false`（冻结已被实测证伪：下跌再恢复，吃掉三分之一进度）。

**同刺激多正样本的一个证明性后果（保留）**：跨被试 batch 把同一刺激发给 `g` 个被试时，
分组损失与对角损失的两半**完全相等**（不是近似）——`smoke_test.py §9f` 钉住；
`g` 个等价正样本下两半都触底在 `ln g`，所以**温度必须设下限**。

## 5. 部署栈（T2，无参数、无标签）

```
corpus (per route r):
   z_eeg_r ─► SMN_r（逐被试中心化）
            ─► whiten_r（shrink SAW）                 ← 协方差
            ─► CSLS_r(k=10)                           ← hubness
            ─► R_r = orthogonal_procrustes(...)       ← 逐通路坐标恢复（创新②）
            ─► S_r
fusion:
   S_fused = Σ_r w_r · S_r        (w = uniform 默认；或源验证固定权重)
```

**顺序不是任意的**（曾写错过一次）：
`center`/`whiten` 是 **query 坐标变换**，必须在任何"在坐标里测角度"之前；
`recovery` **内部重算 CSLS**，所以 CSLS 必须在它之前（否则被丢弃）；
最后的 CSLS 是对**恢复后**矩阵的**重新打分**。

**已实测的部署阶梯（必须继续逐档标注）**：

| 阶梯 | `v5-a1-k20` | `v5-ep2`（旧 RAT） |
|---|---|---|
| raw cosine | 27.0 | **30.0** |
| + CSLS | 34.0 | 33.5 |
| + whiten + CSLS | 31.5 | 30.0 |
| + whiten + CSLS + recovery | **35.5** | 32.0 |

> v6 的假设：把回合改成**逐位复现**后，`v5-ep2` 的 raw 30.0 **加上**被找回的校准边际
> （现掉 5.5pp），部署应从 32.0 **回到 35.5 之上**，并因逐通路恢复再抬一档。

### 6.4 新测到：复读云**统计量**的分数级融合（取代 M4 的原形态）

| 对照 | Top-1 | 它排除什么 |
|---|---|---|
| `fuse(T1best, T1best)` | **35.50** | "平均两个同算子估计"本身的零假设 —— 必须等于 35.50，实测精确等于 |

| R | 1 | 2 | 5 | 10 | 20 | 40 | **80** |

non-transductive 地用了同一批 test 的统计量（与 CSLS/白化/恢复同族，本任务的通行做法）。

#### 6.4.1 已接线（2026-10-04）—— 在此之前 `--reps` 在单折 checkpoint 上是**静默空操作**

两个必须先修的实现问题，否则上面这条杠杆在 10 折扫描里会**根本测不出来**：

1. **`--reps` 对单折 checkpoint 不产生任何行。** C2 只写在 `run_eval._evaluate_v6`
   （多路由）里，而每个 LOSO fold 都是**单路由** v4 模型 —— 所以"带 `--reps` 跑一遍"
   与"不带"的报告**逐行相同**，且退出码为 0。一个被接受、却不产生任何输出的开关，是本项目
   反复付代价的失败模式（参见 `episode_whiten`、`spec` 的历史）。单折路径现在也有这三行：
   `+ T2 reps`，以及两条 T1×T2 融合行。
2. **算子有两份拷贝。** `probe_c2_levers.py` 内联了一份，`probe_rep_dose.rep_estimate`
   又抄了一份（注释写着 "verbatim from `probe_c2_levers`"）。已提升为
   `calibration.rep_cloud_scores`，两个探针与 `run_eval` 都调用它。回归是**逐字节**的：
   修复后 `probe_rep_dose` 的输出与 banked `rep_dose_v5a1k20.json`（剔除 `cache` 路径字段）
   比较 `==` 为真，含剂量曲线与全部四个对照。**注意它与 `refine_with_reps` 不是同一个算子**
   （33.50 vs 29.50）：差别在后者**设 agreement 门控**，而本 fold 的复读一致度只有 0.09，
   门一开几乎全拒。两者并列报，不互相顶替。

**融合对象的选择本身是测量，不是假设。** 探针当时只把复读云与 `whiten+CSLS+recovery`
（35.50/66.00）融合，得 39.50/73.00。但同一 fold 上 `+ CSLS + recovery`（SCORE 自己的组合）
Top-1 相同而 Top-5 **高 7.5pp**（73.50）。两条都融合后：

| 行（`v5-a1-k20`，fold 8，final epoch） | Top-1 | Top-5 |
|---|---|---|
| `+ CSLS + recovery`（SCORE 组合） | 35.50 | 73.50 |
| `+ T2 reps`（复读云单独） | 33.50 | 73.00 |
| `+ T1(whiten + CSLS + recovery) + T2 reps` | 39.50 | 73.00 |
| **`+ T1(CSLS + recovery) + T2 reps`** | **41.50** | **78.00** |

即 **+6.00 Top-1 / +4.50 Top-5** 于 35.50/73.50 之上，**+7.50/+10.50** 于裸 `+ CSLS` 之上。
所以 `run_eval` 里**两条 T1 rung 都写死**，不让一个位置上的选择替另一个说话。

#### 9.4.2 归因：剩下的缺口不在"更好的无标签几何"里（`probe_whiten_variants.py`）

G3 把问题定位到了一个算子。逐折看，**recovery 的增益是平的（+1.83…+5.00，均值 +3.62），
且与地标率无关（corr = −0.21）；全部折间方差来自 T2 复读云（+0.17…+21.33）**，而 T2 的
增益只与**它自己那次拟合的质量**相关（`weight_entropy` +0.49、`weight_share_top1` −0.49），
与 raw Top-1（−0.04）无关。fold 8 是那个拟合退化的折（三个 seed 一致：+0.00/−0.50/+1.00）。

于是提出并**证伪**了"退化 = 病态方向被放大"这一假设：现在的算子是全秩 64×64 协方差、
固定 shrink 0.1、`max_cond=1e3`。在 10 折（seed 2025）上比较：

| 变体 | fold 8 | fold 10 | 10 折均值 |
|---|---|---|---|
| **`full_asym`（现算子）** | **34.5** | **62.5** | **46.6** |
| `cond{3,10,30,100}_asym`（收紧条件数上限） | 33.5–36.0 | 61.0–62.5 | 46.1–46.7 |
| `lw_asym`（Ledoit-Wolf 收缩取代固定 0.1） | 33.0 | 57.5 | 44.8 |
| `factor16_sym`（秩 16 因子模型） | 20.5 | 49.0 | 35.9 |
| `full_sym`（两侧都白化） | 28.5 | 46.5 | 38.6 |
| `noise_asym`（用复读估的*组内噪声*协方差白化 query） | 34.0 | 60.5 | 46.3 |

**三个结论，都要记死：**

1. **条件数上限、收缩强度、秩、噪声协方差，全都不是病因。** 收紧 clamp 无一致改善，
   Ledoit-Wolf 一致更差，秩 16 大幅更差。**"更好的无标签几何估计器"这条路已经被探尽**，
   别再往这里投实验。
2. **非对称是承重的，不是笔误。** 现算子只白化 **query**（含噪的一侧）、保持 **gallery
   原始**；把同一个映射也施加到 gallery 上要**掉 6–16pp**（`full_sym`）。原因清楚：query
   是 trial 平均、带噪，gallery 是干净的目标；对干净一侧做白化是在扭曲要恢复的目标几何。
   这条同时解释了此前"full-covariance SAW 白化掉 2.5pp"的旧记录——**问题不在协方差，
   在于它被施加到了 gallery 上**。
3. **复读云的信息优势是真的、且是"修正测量误差"层面的。** 逐折实测（seed 2025）：
   200 个平均 query 的协方差**条件数 2.1e5–6.7e5**（近乎奇异），而 16000 个复读的
   条件数 1.1e4–2.0e4（好 20–50×）。概念信号的有效秩（participation ratio）只有
   **4.9–7.1**，组内噪声是 **14.3–16.0**，总云 12.5–14.0。**信号比项目此前假设的 16 维
   还要低**（`spec_r0=16`），而噪声维度和它同量级。

第 3 条指出了唯一还没被动过的杠杆：`Cov(query 云) = A Σ_c Aᵀ + Σ_n/R`。SCORE 把复读
**平均掉**，所以它的协方差估计里永远混着 `Σ_n/R` 而**无法分离**；我们保留复读，所以
`Σ_n` 是**可以直接估的**，于是 `A Σ_c Aᵀ` 可以被**减出来**。这是"用 R 次测量修正测量误差"，
不是调参——也是下一节架构设计的支点。

## 12. 与 SOTA 的差异化创新点

1. **Generalized Recovery-Aware Training —— 整条无标签部署栈入环，且逐位一致。**
   SCORE 把 CSLS + 恢复放进训练环，但**把手设计的部分（白化）留在测试时**；
   SATTC 干脆全留在测试时。我们把 `SMN + whiten + CSLS + recovery` **整条栈**做成可微模块，
   并用断言钉死 `in_loop ≡ deploy`。★

2. **逐通路坐标恢复 + 分数级融合（Per-Route Recovery ⊕ Score Fusion）。**
   SCORE 单通路恢复；CORTIVA 多通路但**不做**恢复。**两者从未被组合**——
   而三套几何的被试方向错位**不是同一个旋转**，这是构造性的、可证伪的组合。★

3. **补上目标的结构性缺口（低层 VAE 分支 + 图像条件化深度分配）。**
   文献（HVF）指出"堆语义无用、加 VAE 才有效"，而我们的目标是 2024 的纯语义设计。
   这不是"更大的骨架"，是**更正确的监督几何**（A4）。

4. **诊断驱动协议（三项回归探针）**——把"表示质量"与"被试迁移"分开。
   这是发现"L1 的 +5.50pp 不是被试不变性"的唯一手段，也是本架构与"调参记录"的分界。

5. **方法学批判：post-hoc 校准的 oracle 上界 ≠ 联合训练下的上界。**
   由我们自己的失败记录导出：在未为可恢复性训练过的编码器上测上界，会**系统性低估**
   该坐标家族在恢复感知训练下的价值。

## 13. 一句话收束

**我们没有换更大的骨架，因为问题从来不是容量。**
v6 把三件被文献验证、而我们要么没做、要么做了一半的事做完整：
**异质目标**（补上低层分支与图像条件化深度）、**分数级融合**（保住三套几何的互补证据）、
**忠实恢复**（把部署栈逐位搬进训练环）。
在共享编码器**一个参数不加**的前提下，这三条通路互不共线，指向同一个目标：
**T1 raw ≥ 35、T2 ≥ 48 → 53**。
