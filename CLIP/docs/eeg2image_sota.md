# COMMET — 当前 SOTA 模型：原理、架构与实验结果

> 任务：**跨被试 EEG→图像检索**（cross-subject，200-way，THINGS-EEG2，10 折 LOSO）。
> 部署结果（3 seed，10 折）：**Top-1 54.83 / Top-5 83.45**。
> 本文只写三件事：原理、架构、实验结果。所有数字都可在 `outputs/` 中复算。
> 相关文档：`eeg2image_commet_plan.md`（定位 + E1/E2）、`eeg2image_commet_architecture.md`（完整设计）、
> `eeg2image_v11_unified_architecture.md`（逐层测量依据）、`eeg2image_v13_croma.md`（证伪记录）。

## 1. 原理

### 1.1 一句话

> 跨被试 EEG→图像检索不是 **order-1 的对齐问题**（估计一个映射并求逆），
> 而是 **order-2 的估计问题**：query 是一个被 R 次含噪采样观测到的分布，
> 正确的对象是 **概念级度量矩阵** \(D_q \in \mathbb{R}^{C\times C}\)——
> 由各次采样给出的独立度量视角做**可靠性加权融合**得到——再用 **结构化传输** 与图库度量耦合。

### 1.2 为什么不是对齐（这是原理的立足点，全部为实测）

十个测量（M1–M12，见 `eeg2image_v11_unified_architecture.md` §0）中，四条独立地关闭了"估映射再求逆"这一整族方法：

| 测量 | 值 | 含义 |
|---|---|---|
| **M6** 最优全局正交映射的解释方差 | **+2.4%** | SCORE / Riemannian / ITSA / Procrustes 都在估这个对象，它只占 2.4% 方差 |
| **M7** 映射的闭合性缺口 | **+5.7%**，t=140，10/10 | 被试项**不是群作用**，任何先验固定群（O(d)/SPD/等距）都在固定错的对象 |
| **M8** 局部映射 vs 全局映射 | 局部 **差 15%** | 被试项也**不是**光滑位置场（且对照能检出注入的场，是有效负结果） |
| **M9** 残差空间相干性 | 0.089 vs 随机 0.001 | 只剩一点微小光滑成分，骑在大量的异质成分上 |

**结论：被试残差不是待逆的结构，而是待平均掉的噪声。**

### 1.3 信号在 order-2，不在 order-1

| 测量 | 值 | 含义 |
|---|---|---|
| **M1** 跨被试概念度量一致性 | \( \mathrm{corr}(D_{eeg,s}, D_{eeg,t}) = \mathbf{+0.565} \)（chance −0.003） | 共享**度量**是真实的，尽管一阶特征是空的 |
| **M2** EEG↔图像概念度量一致性 | **0.593**（白化后，全表最大） | 图库是共享结构**最强**的一个视角 |
| **M5** query↔gallery **拓扑**一致性 | Jaccard **0.269** | 不是独立事实，而是 M2=0.593 在阈值化下的**算术后果** |
| **M11** 结构项自身的价值 | **+3.85pp** | 度量对象是唯一被实测证明携带信号的 order-2 对象 |
| **M12** 恢复环节的贡献 | **≈ +25pp** | 测试时 label-free 对应恢复是最大单一来源 |

M5 的含义是决定性的：**度量本身的 SNR 低（~0.58），任何比度量更非线性的泛函（拓扑/图/谱截断）都会以可预测的速率丢 SNR**。这用一个机制解释了 P1、P2、A4 三族的失败。

### 1.4 两个被浪费的资源

1. **重复次数是集成，却只被当作均值。** R≤80 次重复定义了嵌入上的一个分布，其散度直接度量 query 可靠性；所有 SOTA（SCORE / SATTC）都先把它平均成一个点。
2. **图库是同一 200 概念的第二个独立视角**（M2=0.593），却只当检索目标用。

### 1.5 因此的推理目标

设 \(\{D_k\}_{k=1..K}\) 为 K 个视角对共享结构给出的含噪度量估计，则

```
D*  =  Σ_k  w_k · D_k          （结构估计：可靠性加权融合）
s_i =  score(concept i | D*, 每视角可靠性)   （对应关系从 D* 读出，而非从拟合的映射读出）
```

关键：\(w_k\) 来自**实测的**每视角可靠性（重复一致性 / leave-one-out 残差），不是调出来的标量；融合**不删任何方向**（谱截断被证伪三次，见 §4）。

## 2. 架构

三阶段。**Stage A 刻意保持不变**（六次训练侧尝试均被证伪），novelty 在 Stage B / C，且与部署路径隔离。

### 2.1 Stage A — 编码器（冻结、已验证）

`z = SMN(embed_θ(EEG))`，即"被试即模态"（Subject-as-Modality）主干。

| 组件 | 规格 |
|---|---|
| EEG 主干 | ATM-S / iTransformer 风格：depthwise 时间卷积 → 逐通道 token 嵌入 `Linear(250→200)` → + 通道位置编码 → **2 × pre-norm Transformer block**（`d_model=200`, 4 heads, `dim_ff=512`, dropout 0.5）→ 时空聚合 → MLP 投影 → 64 维 |
| 输入 | 63 通道 × 250 时间点（`channel_set: all63`） |
| **SMN** | 被试模态归一化：逐被试均值扣除 + **门控**逐方向重标定（gate 初值 0，即初始恰为纯中心化，只有目标函数付费才打开）。+6pp 由架构承担而非测试时 |
| 对齐头 | **两模态共享的单个线性头**，`d_align = 64`（不是 512：概念流形实测约 16 维，大空间让 InfoNCE 用在不可泛化的被试特异方向上） |
| 图像侧 | 冻结 **InternViT-6B** 多层特征（层 `[20,24,28,32,36]`，`l2norm`），5 视角经 `routed` 融合（负熵 bonus 0.05） |
| 可训练参数量 | ≈ **1.13 M** |
| 目标函数 | `L_img`（EEG↔多层图像目标）+ `L_cross`（同刺激跨被试多正样本 InfoNCE）+ `L_mmd` + `soft_plan`（算子对齐的 Sinkhorn 软计划，weight 0.5, `tau=0.1`, `csls_k=20`）；`reg/spec/dec/proto/rkd/adv` 全部为 0（实测惰性或有害） |
| 训练协议 | 50 epoch，coarse-to-fine：stage1 20 epoch @ lr 1e-3，stage2 lr 5e-5；`mvnn=train`；每折 9 个源被试 |

Stage A 的 3-seed 10 折单均值度量（`fuse=0`）Top-1 = **53.80**。

### 2.2 Stage B — 度量估计器（核心 novelty）

部署对象：query 在 C=200 概念上的概念度量 \(D_q\)。

1. **逐重复视角。** R=80 云给出每概念的 80 个嵌入；切成 B 个连续块，每块的均值给出一个独立度量估计 \(D_b = \text{standardised\_sq\_chordal}(\text{block}_b)\)。
2. **可靠性加权融合。** \(D_q = \sum_b w_b D_b\)，其中 \(w_b = \text{inv\_resid}_b / \sum \text{inv\_resid}\)，`inv_resid_b` 是块 b 相对其他块的 leave-one-out 残差。融合在共享特征基里做，**对概念顺序置换不变**（这条性质关掉 M1 的 index 泄漏通道）。
3. **度量适配器**（`φ: R^d → R^{d'}`，源被试训练、硬秩下限守卫）。在**冻结主干**上训练，因此结构上无法复现 v12 的坍缩。实测被 G0 关闭（适配器打不过 identity，−1.20pp）。

`fuse=0` 是 shipped 单均值度量，是每个融合单元**唯一的**成对孪生。

### 2.3 Stage C — 耦合算子（部署）

**融合 Gromov–Wasserstein（FGW）**，两侧都用结构：

```
T* = argmin_T  ⟨C, T⟩ + α · ⟨L(D_q, D_g), T ⊗ T⟩,     分数从 T* 读出
```

- \(C\)：φ 投影嵌入上的跨模态代价；\(D_q\) query 结构化度量；\(D_g\) 图库度量（200×200）。
- 使用的结构：`D_q`（query 侧）、`D_g`（gallery 侧）。`α=0.75` 是结构项权重，`τ=0.03`。

### 2.4 部署算子参数（shipped）

| 项 | 值 |
|---|---|
| 重复次数 | R = 80（测试云），训练云为 R=4 |
| 云算子 | `rep_cloud_scores`，`rep-shrink 0.1`（standardised sq-chordal 度量） |
| CSLS | `k = 10`，`rho = 0.1` |
| 恢复算子 | FGW，`tau = 0.03`，`alpha = 0.75` |
| 结构融合 | `fuse = 16`（R=80 切 16 块，可靠性加权） |
| 每条单元 | 同时输出 `fuse=B` 与 `fuse=B (structural-off)` 两个孪生 |

**复现（10 折 × 3 seed 的主结果）：**

```bash
# 编码器：outputs/stage1/v8/subNN_k20_seed{2025,2026,2027}/last.pt
python scripts/run_eval.py --ckpts <ckpt> --target-subject <s> --out <ev> \
  --recovery --reps --csls-k 10 --rho 0.1 \
  --recovery-operator fgw --recovery-tau 0.03 --recovery-alpha 0.75 \
  --rep-shrink 0.1 --fgw-struct-fuse 16
# 提交脚本：slurm/v11_struct_fuse.sbatch（E1 主结果）
```

## 3. 实验结果

### 3.1 主结果（10 折 × 3 seed，n=30 paired）

| Cell | Top-1 | Top-5 |
|---|---|---|
| `fuse=0`（shipped 单均值度量） | 53.80 | 82.55 |
| **`fuse=16`（本模型，COMMET）** | **54.83** | **83.45** |
| `fuse=16 (structural-off)` | 50.72 | 82.28 |

**融合自身的配对贡献（n=30）：**

| 指标 | Δ | t | 折为正 |
|---|---|---|---|
| Top-1（`fuse=16` − `fuse=0`） | **+1.03pp** | **3.49** | 20/30 |
| Top-5 | **+0.90pp** | **3.75** | 19/30 |
| structural-off 族 | **0.00pp** | — | 0/30（逐位不变） |

structural-off 逐位不变 ⇒ 融合**只**通过结构项进入分数，不经跨模态代价泄漏。

**融合曲线（1 seed，n=10）：**

| R=80 | fuse=0 | fuse=2 | fuse=4 | fuse=8 | fuse=16 |
|---|---|---|---|---|---|
| Top-1 | 54.25 | 54.25 | 54.65 | 54.95 | **55.10** |
| Δ vs twin | — | +0.00 | +0.40 | +0.70 | **+0.85** |
| 结构项自身价值（on − off） | +3.85 | +3.85 | +4.25 | +4.55 | **+4.70** |

融合在 B 上单调；`B=2` 是**精确 no-op**（两块互为 LOO 参照 ⇒ 权重相等 ⇒ 退化为均值），这本身是一个有用的 null，证明 `fuse=0` 是诚实孪生。

### 3.2 云 vs 点（内部消融，10 折 × 1 seed）

| Cell | Top-1 | Top-5 |
|---|---|---|
| point + CSLS + recovery（无结构校准） | 39.95 | 73.00 |
| point + **SATTC** 结构专家（该领域最强点校准） | 40.40 | 73.35 |
| **cloud**（shipped T2, `fuse=0`） | 54.25 | 81.75 |
| **cloud + fusion（COMMET, `fuse=16`）** | **55.10** | **83.15** |
| cloud + fusion, structural-off | 50.40 | 82.05 |

相对最强点方法（40.40）：**+14.70pp，10/10 折，t=7.39**。

**必须如实拆解（Top-1）：**

| 步骤 | Δ | 含义 |
|---|---|---|
| cloud vs point（point → shipped T2 `fuse=0`） | **+14.30pp** | 使用 R=80 逐试次云而非均值嵌入 |
| SATTC 结构校准用在点上 | +0.45pp | 领域最强的点侧校准，用我们的编码器 |
| **COMMET 的融合**（云之上） | **+0.85pp**（1s）/ **+1.03pp**（3s） | order-2 度量估计器 |

即 +14.70pp 的主体是 **cloud-vs-point**（+14.30pp），不是融合；融合的独立贡献是 +0.85/+1.03pp，显著且经配对验证。

### 3.3 与 SOTA 的定位（跨论文，非配对）

| 方法 | Top-1 | Top-5 | 对象 | 跨被试 |
|---|---|---|---|---|
| leaderboard inter-subject 平均 | 28.5 | 62.0 | point | 是 |
| SAMGA（我们复测） | 26.22 | 57.98 | point | 是 |
| SVTL | 48.1 | 77.1 | point + transductive | 是 |
| **SCORE** | **53.23** | **83.55** | order-1 映射 | 是 |
| SATTC | —（校准） | — | 相似度矩阵 | 是 |
| **本模型（3 seed, `fuse=16`）** | **54.83** | **83.45** | **order-2 度量 + FGW** | **是** |

**相对 SCORE：Top-1 +1.60pp，Top-5 打平（−0.10pp）。** 该比较是跨论文的，不是配对实验。

### 3.4 机制证据（为什么增益是共享结构，不是 pooling 假象）

- **对应破坏对照。** 探针（job 645697）：在 K=1..8 上池化独立结构估计，与留出视角的一致性 **单调上升**（跨模态 0.209→0.247，10/10，t=+42.4），而概念轴打乱的对照**恒在 ±0.001**。→ 增益来自共享结构，不是平均本身。
- **structural-off 孪生恒平。** 每个融合单元都带一个结构项关闭的孪生，必须逐位不变（实测 Δ=0.00）。
- **置换对照（M1 通道）。** 任何融合增益若在概念轴置换下消失即为泄漏；M1 曾发生 +15.4pp → −14.5pp，因此每条单元都带这条对照。

### 3.5 已测得的机制更正（重要）

v11 文档原把融合增益归因于"可靠性加权"，**实测更正**（`eeg2image_v13_croma.md` §3.4）：

- 每视角权重的跨度只有 **0.0057**（近乎全平），因为逐视角的重复误差**互不相关**（\(\rho \le 0\) 在 10/10 折成立）——没有可靠性差异可供加权。
- 增益来源是 **块结构 / 度量锐化**，**不是**可靠性加权池化。

权重仍是一个有效**算子**（合成两级噪声测试 0.175 vs 0.075 成立）；被更正的是真实数据上的**归因**。

## 4. 边界与不可引用的 cell（引用本结果时必须携带）

1. **`CORTIVA` 的 73.5 Top-1 远高于 SCORE 的 53.23**，其协议（候选集大小、适配）尚未核实，不得在我们未核实前引用比较。
2. **`m=1` "概念帧转导" cell（+15.37pp / +14.03pp，60/60）已撤回**。裁决（job 647505）证明它是**评测协议可利用性**，不是神经泄漏：把公共图库度量当作 FGW 的参考度量，会让结构代价在 **identity** 耦合处为零，而该评测是 index 对齐的、identity 就是答案。诊断量 `plan_acc` 随 Top-1 单调（0.450→0.796→0.998）。**本模型的 54.83/83.45 不依赖它。**
3. **E2 的 +14.70pp 是内部 cloud-vs-point 消融**，不是"我们比 SCORE 高 14.7pp"。
4. **训练云 R=4，测试云 R=80**：编码器从未在算子真正消费的输入分布下训练过。R-curve 在 R=80 仍以 +3.33pp/octave 上升，估计器未饱和。
5. 训练侧各次尝试（T2′、T2″、SCORE-episode、G-a、v12、v13、v14）**全部被证伪**，其中 v14 证明"把 order-2 损失搬进白化帧"会使编码器**坍缩到秩 1**——**novelty 在测试时估计器，不在训练项**。
